# 낚시 작업본 — 세트·호루스

사용자 요청으로 main의 메인1 폴더에 보관한 미완성 작업본입니다. 채택이나 게임 적용을 뜻하지 않습니다.

- 세트·호루스 정면 낚시 각 2프레임, 총 4장. 0 기다리기, 1 당기기.
- 공용 양동이 3장: bucket-0 빈 상태, bucket-1 소량, bucket-2 가득.
- 모든 PNG는 620×720 투명 RGBA. 기준점과 SHA256은 fishing-manifest.json.
- 소망 이미지와 소망이 포함된 비교 시트·GIF는 포함하지 않았습니다.
- 기존 작업본과 픽셀 수정 없이 동일한 파일입니다. 얼굴·머리 비율, 색 차이와 호루스 목 주변 잔선 문제가 남아 있습니다.
- fishing-review.md는 기존 검사에서 해당 캐릭터 항목만 발췌한 보고서입니다. 가이드 스크립트를 작화 전에 사용하지 못한 작업이며 완성본으로 표시하지 않습니다.
