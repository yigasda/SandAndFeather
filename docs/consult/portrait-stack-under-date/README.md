# 세로 HUD 묶음을 날짜 아래로 올림 (미발행)

예전 전투HP 예약 높이 `hud-top +164px`를 제거했다. 날짜판 실제하단+6px에서 수치줄이 시작하고 이벤트,전투HP가 각각6px간격으로 이어진다. 날짜판 ResizeObserver를 추가하여 날짜 높이가 바뀌어도 따라간다. 가로는 이 변수로 위치를 정하지 않으며 메뉴/기능 로직은 변경하지 않았다.

5테마×390/320 세로에서 날짜→수치6px, 수치→안내6px, 안내→HP6px, 수치/안내/HP 좌우오차0px. 날짜중심·가로회전복귀·확대글자줄바꿈 검사도통과. 실제390전체화면을 열어 날짜아래 빈공간제거, 오른쪽미니맵/버튼과겹치지않음, 하단조작과게임영역을 시각검수했다. 관련단일검사 date-hp-layout 통과, 변경JS2개 문법통과. 원격발행 없음.
