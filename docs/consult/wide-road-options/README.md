# 도보만 수정한 넓은 길 시안 3개

기존 지도에 도보 수정 영역만 합성한 비교용 시안입니다. 편집 영역 밖 픽셀은 원본과 동일하며 게임에는 적용하지 않았습니다.

## ① 넉넉한 큰길

여러 줄의 판석이 놓인 큰길이 완만하게 이어지는 안입니다.

![① 넉넉한 큰길](road-only-1.png)

## ② 앞마당이 넓은 길

시장과 건물 앞의 포장 면적을 넓혀 큰길과 연결한 안입니다.

![② 앞마당이 넓은 길](road-only-2.png)

## ③ 갈림길이 넓게 퍼지는 길

세로길이 큰길로 들어오는 부분과 갈림길을 넓힌 안입니다.

![③ 갈림길이 넓게 퍼지는 길](road-only-3.png)
