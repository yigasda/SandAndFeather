# 0.9.2 프레임과 가방 상세 수정

0.9.1에서 원본 시안의 배경까지 사각형으로 잘라낸 버튼 프레임이 밝은 패널 위에서 검은 모서리를 드러냈다. 또한 가방 오른쪽은 원본 5번의 내부 아이콘 프레임과 설명 프레임 없이 `살펴보기` 버튼을 추가한 다른 구성이었다.

- 원본 PNG의 RGB를 유지하면서 프레임 외곽 배경을 알파 마스크로 제외했다. 밝은 배경/어두운 배경에서 다섯 테마의 기본·강조 버튼을 각각 렌더링해 확인했다.
- 클래식 선택 프레임의 왼쪽 변에서 원본 선택 화살표가 섞인 샘플을 옮겼다. 여행수첩 버튼의 누락된 왼쪽 테두리, 포근한 테마 상세 패널의 크롭 경계도 보정했다.
- 가방 오른쪽은 아이콘 전용 프레임 + 이름/수량, 아래 독립된 설명 프레임으로 구성한다. 1/5번 내부 프레임은 해당 원본의 실제 칸에서 추가 추출했다. 나머지는 각 테마 원본의 프레임을 사용한다.
- 가방 요약 패널에서 `살펴보기`와 입수 날짜를 제거했다. 선택된 슬롯을 다시 누르면 기존 `itemCard`가 열린다. 날짜·출처·열기·지금 꺼내기 등 기존 상세 기능과 개별 UID는 유지한다. 다른 슬롯을 누르면 먼저 선택만 바뀐다.
- 아이템 크롭에 딸려 있던 원본 수량 글자/인접 슬롯 선은 분리된 잔여 픽셀을 제거해 정리했다. 실제 수량은 런타임 데이터로 한 번만 표시한다.
- 맵, 초미니, 정밀 미니를 수정하거나 새로 생성하지 않았다.
