# 0.9.2 프레임과 가방 상세 수정

0.9.1에서 원본 시안의 배경까지 사각형으로 잘라낸 버튼 프레임이 밝은 패널 위에서 검은 모서리를 드러냈다. 또한 가방 오른쪽은 원본 5번의 내부 아이콘 프레임과 설명 프레임 없이 `살펴보기` 버튼을 추가한 다른 구성이었다.

- 원본 PNG의 RGB를 유지하면서 프레임 외곽 배경을 알파 마스크로 제외했다. 밝은 배경/어두운 배경에서 다섯 테마의 기본·강조 버튼을 각각 렌더링해 확인했다.
- 클래식 선택 프레임의 왼쪽 변에서 원본 선택 화살표가 섞인 샘플을 옮겼다. 여행수첩 버튼의 누락된 왼쪽 테두리, 포근한 테마 상세 패널의 크롭 경계도 보정했다.
- 가방 오른쪽은 아이콘 전용 프레임 + 이름/수량, 아래 독립된 설명 프레임으로 구성한다. 1/5번 내부 프레임은 해당 원본의 실제 칸에서 추가 추출했다. 나머지는 각 테마 원본의 프레임을 사용한다.
- 가방 요약 패널에서 `살펴보기`와 입수 날짜를 제거했다. 선택된 슬롯을 다시 누르면 기존 `itemCard`가 열린다. 날짜·출처·열기·지금 꺼내기 등 기존 상세 기능과 개별 UID는 유지한다. 다른 슬롯을 누르면 먼저 선택만 바뀐다.
- 아이템 크롭에 딸려 있던 원본 수량 글자/인접 슬롯 선은 분리된 잔여 픽셀을 제거해 정리했다. 실제 수량은 런타임 데이터로 한 번만 표시한다.
- 맵, 초미니, 정밀 미니를 수정하거나 새로 생성하지 않았다.

## 검증

- `verify-ui-source-pixels.cjs`: 187개 에셋의 남아 있는 원본 RGB 일치. 알파 마스크와 기존 제목 글자 제거 영역은 별도 취급한다. 전체 화면의 픽셀 일치를 주장하는 검증은 아니다.
- `verify-ui-themes.cjs`: 다섯 테마, 320/412/1280 폭의 가방·파티·대화, 테마 전환/키보드/저장/재로딩/어두운 모드. 새 상세의 아이콘·이름·설명 배치 및 프레임 존재, 버튼/날짜 제거까지 검사. AI 생성 요청 0회.

## 0.9.3 깨진 프레임 전수 수리

사용자 요청: 말 걸기와 가방처럼 프레임이 깨지고 늘어난 곳(초록 테두리)을 모든 테마에서 다 찾아 고치기. 다섯 테마의 화면·탭·창을 2배로 찍어 하나씩 대조했다. 이미지 생성은 쓰지 않았고, 보이는 픽셀은 원본 시안 그대로다.

**가방·말 걸기 (5테마 10장).** 원본 크롭에 맵 풀밭이 사각형째 들어 있었고, CSS가 그걸 100%×100%로 늘린 뒤 타원으로 잘라 초록 테두리가 남았다. `tools/art/cut-action-buttons.py`가 원형은 테두리선에 맞춘 원, 포근한 테마 팔각형은 풀밭과 겨룬 팔각형으로 바깥을 투명하게 자른다. 테두리 바로 위에 걸친 풀 픽셀만 그 버튼 테두리선 색으로 바꾸고 좌표를 provenance에 남긴다. CSS는 잘라내기 없이 `contain`으로 비율 그대로 그린다.

**다른 그림이 섞인 9분할 프레임은 같은 테마의 깨끗한 프레임으로.** 원본 크롭이 옆 패널이나 맵까지 물어서 늘이면 조각이 보이던 것들:

| 자리 | 테마 | 바꾼 것 |
|---|---|---|
| 지도 창 테두리 | 1·2·3·5 | 그 테마 날짜판 프레임 |
| 지도 창, 날짜판, 칩 | 4 | 4번 버튼 프레임 (원본 날짜판 크롭에 1/2 숫자와 나뭇잎) |
| 화면·창 바깥 틀 | 4 | 4번 패널 프레임 (원본 크롭이 상자 그림이었음) |
| 하단 탭 바 | 1 | 1번 패널 프레임 (왼쪽 주황 조각) |
| 하단 탭 바 | 2·3 | 그 테마 날짜판 프레임 |
| 선택된 탭 | 2 | 테두리 없이 밑줄만, 5번과 같은 방식 |
| 선택된 탭·가방 줄 | 3 | 3번 강조 프레임. 탭 아이콘은 밝게 |

**그림 자체 정리.** `tools/art/repair-ui-skins.py`, 작업마다 provenance `repairs`에 기록.

- 4번 연꽃·두루마리 아이템: 원본 수량 "2"와 그 바탕을 투명하게.
- 3번 연꽃 아이템: 선택 줄의 주황 바탕을 가장자리부터 투명하게.
- 2번 선택 칸: 바깥 흰 종이를 투명하게.
- 4번 제목줄: 글자 지운 자리의 어두운 네모를 바로 옆 같은 줄의 종이로 채움.

**닫기 ✕ 위치.** 1번 가방 창은 ✕가 모서리 위에 18px로 눌려 있었다. 분류 탭을 왼쪽으로 옮기고 ✕를 제목줄 안으로 넣었다. 2번은 ✕가 오른쪽 끝 장식과 겹쳐서 장식 앞으로 옮겼다. 4번은 ✕가 오른쪽 모서리 문양을 덮어서 날개와 연꽃 사이 빈 종이로 옮겼다. 3번 넓은 화면은 오른쪽 위 말림 장식을 피했다.
