# 아스트라 문서 구조 대응표

## 현재 구조 (2026-10-14)

실행 경로는 START → STATE → 캐릭터 REF → DRAW-CHECK 하나다. 상세 문서는 해당 작업에 필요한 부분을 찾아보는 기준서이며, 순서대로 통과해야 하는 사다리가 아니다.

| 이전 | 현재 |
|---|---|
| START의 문서 순회 | 현재 작업 / 원본·가이드 / 작화·비교 세 단계 |
| 흩어진 캐릭터 원본·가이드 | REF-HORUS / REF-SET / REF-SOMANG에서 직접 링크 |
| DRAW-CHECK의 시작표·확인서·작업 카드·기록 양식 중복 | 세 단계와 단일 작업 기록 |
| 생성 조건·프레임 주의사항·검수 도구·가이드 한계·첫 샘플 판정 | DRAW-REFERENCE에 상세 내용 보존 |
| 외형·눈 표·머리 설명·실수 표 | SPRITE 유지 |
| 동작·표정 표와 향후 명세 | PLAN 유지 |
| 상태·다음 행동 | STATE 유지 |
| 공통 규칙·저장·전달 | HANDOFF 유지 |

확인서의 개별 항목은 삭제한 요구가 아니다. 대상·방향·프레임·시점·핵심 자세·표정·보존 범위는 단일 기록의 대상/근거/생성에, 머리 위치·각도·배율·기준점은 근거/생성에, 비교·검수·남은 차이는 비교/판정에 기록한다. 실제 요청과 파일을 연결해 중복 서술하지 않는다.
