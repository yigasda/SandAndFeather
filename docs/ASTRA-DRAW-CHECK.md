# 작화·비교 — 이 세 단계만 순서대로

## 최우선: 호루스 재작화 입력 제한 (2026-10-14)

- 호루스는 처음부터 다시 그린다. 이전 전투 시안의 동세·표정도 참고하거나 추출·재사용하지 않는다. 기존 전투 출처표는 보관 기록일 뿐 이번 작화 참고가 아니다.
- 생성에 넣을 수 있는 이미지는 채택된 뒷머리 제거 대기 0, 원본 걷기·정지·잠자기, 이 원본들에 근거한 오푸스 전신·머리 가이드뿐이다. 이전 전투 PNG·크롭·비교판·그것을 따라 만든 동세 가이드는 넣지 않는다.
- 동세·표정은 GitHub `ASTRA-PLAN.md`의 호루스 동작별 자세·표정 표 그대로 따른다. 임의로 새 동세·감정을 구성하지 않는다. 이전 전투 그림을 눈으로 보고 재현하지 않는다. 대기 0의 채택 외형은 보존한다.
- 가이드 첨부 자체는 합격 근거가 아니다. 첫 새 그림을 원본과 같은 캐릭터 배율로 비교하고 머리·몸·팔다리 비율, 색, 외곽선, 하이라이트 양이 어긋나면 다음 장을 생성하지 않는다. 실패한 기준으로 묶음을 끝까지 만들지 않는다.
- 실제 생성 참고 경로를 기록하고 호출 직전에 허용 목록과 대조한다. 구 전투 참고를 허용한다는 이전 문구보다 이 지시가 우선한다.


## 1. 이번에 그릴 것

[현재 작업](ASTRA-DRAW-STATE.md)에서 캐릭터·동작·수정 범위와 다음 한 단계를 확인한다. 이미 승인된 범위는 반복 승인받지 않는다. 동세 채택과 외형 채택을 구분한다.

## 2. 원본·가이드를 열고 그리기

**[호루스](ASTRA-REF-HORUS.md) · [세트](ASTRA-REF-SET.md) · [소망](ASTRA-REF-SOMANG.md)** 중 해당 캐릭터 페이지를 연다. 거기에 정지·걷기·색·눈·머리·전신/머리 가이드·동작 명세가 모여 있다.

실제 이미지를 보고 가이드를 밑그림으로 사용한다. 처음 맡는 작업이나 기준이 바뀐 때에는 연결된 상세 외형과 해당 동작의 자세·표정 절을 읽는다. 매 프레임 문서 전체를 다시 순회하지 않는다. 압축으로 이미지 맥락이 사라졌으면 필요한 원본을 다시 연다.

생성 입력에는 사용한 원본·가이드와 이번 자세·표정·보존 조건을 반영한다. 모델에 첨부한 것만으로 정확히 따라 그렸다고 판단하지 않는다.

## 3. 원본과 나란히 비교하고 고치기

같은 캐릭터 배율로 원본과 결과를 비교한다. 머리/몸·팔다리 비율, 얼굴·눈·문양, 색·외곽선·하이라이트 양, 손 개수·의상·무기, 동세·표정을 확인한다. 연결 장면과 게임 표시 크기, 밝은/어두운 배경도 확인한다. 부분 수정이면 요청 밖 변화도 본다.

차이가 있으면 수정한다. 자동 검사는 보조이며 측정 실패를 통과로 꾸미지 않는다. 첫 샘플 외형이 틀리면 나머지 그림을 쌓지 않는다. 상세 방법은 [작화·검수 참고](ASTRA-DRAW-REFERENCE.md).

작업 폴더에 다음 **한 기록만** 남긴다. 별도 확인서·중복 체크리스트는 만들지 않는다. 관련 파일·실제 생성 지시문을 연결하면 같은 내용을 다시 풀어 쓸 필요 없다.

```text
대상·범위·승인: 캐릭터 / 동작 / 방향 / 프레임 / 바꿀 것·보존할 것
근거: 실제로 연 원본·동세 파일, 해당 명세·표정, 가이드 파일·좌표·각도·배율
생성: 실제 전달한 참고 이미지와 지시문 경로, 출력 파일·해시·기준점
비교: 직접 연 나란히 PNG·확대·연결 GIF·검사 보고 경로
판정: 맞음 / 수정 필요 / 미확인과 구체적인 차이. 사용자 채택 여부·근거
다음: 한 단계
```

끝나면 [현재 작업](ASTRA-DRAW-STATE.md)의 상태와 다음 행동만 갱신한다. 전달·보존 규칙은 [HANDOFF](ASTRA-HANDOFF.md).
