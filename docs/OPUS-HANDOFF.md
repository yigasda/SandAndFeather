# 오푸스 시작 — 작업별 길 안내

여기서 **지금 할 일 → 해당 파트 → 원본 자료 → 완료 검사** 순서로 간다. 사용자의 최신 요청과 지정 범위를 먼저 확인하고, 필요한 파트·절만 읽는다. 매 프레임마다 전 문서를 다시 읽거나 모든 파트를 순서대로 읽지 않는다.

**맵 작업의 최신 공통 기준:** 자연스럽게 입구에서 이어지는 길 위에 착지하고, 출구 트리거 바로 옆이나 임의 빈 바닥에 보내지 않는다. 발 도형·동행·재전환 방지·의도한 귀환을 담당자가 먼저 검수한다. 맵마다 사용자에게 수동 좌표를 다시 지정하게 하지 않는다. 세부 조건은 [맵 공통 기준](OPUS-MAPS.md)에 한 번만 둔다.

**상태 표는 기록 스냅샷이다.** 원문의 2026-10-18 / 0.9.89 상태·대기 목록을 보존했으며, 이번 분리는 현재 게임 상태의 재감사나 새 작업 승인에 해당하지 않는다. 최신 요청과 실제 코드·manifest·작업 기록을 먼저 대조한다. 기존 사막 문서도 작업 기록이므로, 적용 여부는 해당 커밋과 실행 상태를 확인한다.

## 문서 관리

- 작업 규칙은 해당 파트 한 곳에, 상태·대기는 OPUS-CURRENT-STATE에, 버전별 상세는 기존 CHANGELOG·작업 기록에 쓴다. 끝난 작업을 허브에 누적하지 않는다.
- 원문에서 “맨 위/아래”라고 한 절은 각 파트 상단 링크로 찾는다. 파일을 모두 docs/ 같은 단계에 두어 기존 상대 링크를 유지했다.
- 아스트라의 맵·프롬프트 문서는 이번 정리의 수정 대상이 아니다. 역할·채택 상태 확인에 필요한 기존 링크만 유지한다.
- [원문 절 이동표·보존 검사](OPUS-DOC-MAP.md)에서 모든 원문 절의 이동 위치를 확인할 수 있다.
