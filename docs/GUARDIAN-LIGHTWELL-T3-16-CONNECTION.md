# 신전 수호문 전당 ↔ 신전의 빛 우물

## 작업 상태

작업 브랜치의 구현 중 기록이다. **아직 배포하거나 main에 합치지 않는다.**
기준은 `50399fda9ac5193cd8a033610a1973af7662c80d`이며 기존 17↔18, 02↔10 작업을 유지한다.
사용자는 수문장을 처음 처치하면 영구 개방하고 이후 자유 왕복하는 조건을 승인했다.
수문장 그림에 맞는 실제 압착 전투도 이번 범위에 포함하도록 승인했다.

## 문과 착지

원본 이미지의 좌상단을 (0,0)으로 한 발 좌표이며, 두 이미지 모두 1024×1536이다.

- T3 북문 다각형: (416,410), (606,410), (606,440), (415,440).
- T3 북쪽 착지: (512,535), 아래 방향. 기존 남쪽 착지와 출구는 변경하지 않는다.
- 16 남쪽 다각형: (366,1510), (658,1510), (659,1535), (365,1535).
- 16 남쪽 착지: (512,1420), 위 방향.
- T3 네 측면 구멍과 16 북쪽 보상 홈은 출구로 만들지 않는다.
- 원본 바닥 마스크가 이미 연결되어 있으므로 충돌 마스크 확장이나 통로 보정은 없다.
- 기존 actorScale 1.4, cameraScale 0.8, walkSpeed 1.6, pixelsPerTile 52/1.55를 유지한다.

정적 분석에서는 두 문 다각형의 막힌 픽셀이 0이고, 플레이어 및 초기 동행의 발 전체와
좌/중/우 접근, 착지에서 각각 1.7472칸의 상/하/좌/우 이동이 바닥 안이다.
이 결과는 실제 입력, 동행 AI, 전경 가림, 화면, 저장/불러오기 통과를 대신하지 않는다.

## 영구 개방 계약

T3 북문만 `requiresFirstDefeat: "t3.warden.1"`을 요구한다.
기존 `desertFight.first` 기록을 사용하고, 0일차 기록도 유효하다.
`desertFight.killed`는 일별 재출현 기록일 뿐 문을 다시 잠그지 않는다. 별도 중복 플래그는 없다.
16에서 T3로 돌아가는 길과 T3 남쪽 퇴로는 조건 없이 열어 둔다.
잠긴 출구도 기존 입력 중립/출구 이탈 후 재진입 규칙에 남겨 두며,
같은 입력을 누르고 있는 동안 개방되었다는 이유로 자동 이동시키지 않는다.

## 수문장 및 검증 대기

실제 원본은 양손을 벌렸다 정면으로 모으는 압착 모션이다. 돌진이나 거대한 원형 충격파를 붙이지 않는다.
안전한 초기 발 배치는 원본 (512,955), 런타임 (14.761538461538462,27.666346153846153)이다.
초기 후보 y850은 큰 머리가 북쪽 도착 캐릭터를 부분적으로 가려 제외했다. y955는 기존 세 대기 프레임과
세 캐릭터/동행의 도착 그림에 최소 8.179px 여유가 있고, 원본 바닥의 반경250px 전체에서 발 충돌이 없다.
평상시에는 제자리를 지키고 전투 대상이 있을 때만 기존 추적을 사용한다. 무제한 배회로 착지 그림을 가리지 않는다.
HP68, 공격4, 이동1.0, 가드25% 등 초기 수치는 잠정 밸런스이며 실전 검증 후 기록한다.
준비0 0.6초, 준비1 0.5초이며 준비1에서 위치와 좌우를 고정한다. 공격0 시작 뒤 0.22초에
공격1 그림과 함께 한 번만 판정한다. 원본 공격1 양손 아래 중심(199,365), 반폭54/깊이20px를
아틀라스 좌표(103,296)로 옮긴 납작한 타원을 그림·바닥 예고·피해 판정이 함께 사용한다.
거대한 발 중심 원이나 뒤쪽 타격으로 넓히지 않는다. 전투 중 사망하면 남은 타격을 취소한다.
새 아이템/데벤/XP 보상은 추가하지 않고 기존 처치 궁 게이지 충전만 유지한다.

필수 검증: 실제 입력으로 잠김 확인, 실제 전투 처치, 처음 처치 기록 저장, 같은 날 재입장 시 부재,
다음 날 재출현해도 개방 유지, 새로고침 후 영구 개방, 양방향 세 차선 왕복과 동행 발/입력 중립,
기존 T2↔T3 남문 회귀 검사. 생성 결과와 원본 그림/마스크 보존도 별도로 검증한다.
현재 이 문서에 실제 런타임 통과 결과는 없다.
