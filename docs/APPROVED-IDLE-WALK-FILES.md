# 승인 프레임 파일별 목록

정지 12장 + 걷기 36장, 총 48장. 경로는 저장소 루트 기준이다. 파일 ID와 해시는 [JSON 명세](art/chibi-refresh/approved/manifest.json)에 있다. 모든 파일은 투명 RGBA PNG다.

정지 셀은 620×720, 기준점 310,662, 기준 캐릭터 높이 628이다. 걷기 셀은 360×400, 기준점 180,370, 기준 캐릭터 높이 330이다. 크기와 기준점은 원본 픽셀 단위이며 실제 게임 표시 크기가 아니다.
