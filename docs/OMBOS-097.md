# 0.9.7 옴보스 전체맵 새 낮밤 적용

사용자가 아스트라의 옴보스 개선 시안 낮 v1과 밤 v1을 둘 다 승인했다. 게임 배경을 이 두 장으로 바꿨다. 그림은 [OMBOS-UPGRADE-HANDOFF.md](OMBOS-UPGRADE-HANDOFF.md)에 등록된 PNG를 그대로 읽는다. 복사하거나 다시 그리지 않았다.

- 낮: `docs/art/map-expansion/ombos-upgrade-v1-day.png`
- 밤: `docs/art/map-expansion/ombos-upgrade-v1-night.png`. 밤에는 이 그림을 그대로 보여주고, 마을 전체에 덮던 남색 밤 필터는 쓰지 않는다. 다 지은 수로와 밭처럼 코드로 그리는 칸에만 밤 색을 입힌다.
- 이전 승인 배경 `data/art/ombos-approved.png`는 지우지 않고 보존했다.

## 충돌과 출입

- 새 그림은 이전 배치를 거의 그대로 살렸다. 이전 충돌선을 새 그림 위에 겹쳐 하나씩 대조했고, 어긋난 곳만 고쳤다. 신전 탑문, 신전 문, 안뜰 기둥 네 개다. 시장, 집, 부엌, 필사실, 훈련장, 밭, 야자수, 두아트 문, 석상, 강, 선착장은 이전 충돌선과 맞았다.
- 낮과 밤 그림은 116px 칸마다 비교했을 때 어긋남이 1px 이내였다. 그래서 같은 충돌을 같이 쓴다.
- **신전 문으로 걸어 들어가면 안채 우물 마당 입구에 선다.** 안채 마당 아래 큰 문으로 나오면 신전 문 바로 앞 붉은 카펫 위에 선다. 지도 탁자 카드의 `안채로 들어가기` 버튼도 그대로 둔다.

## 검증

- `verify-full-map.cjs`의 13개 항목을 모두 통과했다.
  - 낮과 밤 화면이 승인 그림과 픽셀 단위로 일치한다. 불일치 0.
  - 모든 장소, 인물, 비밀, 오벨리스크에 걸어서 닿을 수 있다.
  - 부엌 벽에서 멈춘다.
  - 시장, 부엌, 필사실, 지도 탁자, 훈련장, 선착장, 세트와 말 걸기가 된다.
  - 신전 문으로 들어가면 안채로 간다.
  - 두아트 문은 낮과 밤에 따로 동작한다.
  - 선착장 끝에서 멈춘다.
  - 건물 뒤 가림이 된다.
  - 다 지은 정비 결과가 표시된다.
  - 저장 위치를 복원한다.
  - 접었다 다시 열 수 있다.
- 폰 화면에서 낮밤 신전 앞, 강가, 안채에서 나온 자리를 찍었다. [게임 화면](consult/ombos-097/game-day-night.png)
