# 작화·검수 상세 참고

## 최우선: 호루스 재작화 입력 제한 (2026-10-14)

- 호루스는 처음부터 다시 그린다. 이전 전투 시안의 동세·표정도 참고하거나 추출·재사용하지 않는다. 기존 전투 출처표는 보관 기록일 뿐 이번 작화 참고가 아니다.
- 생성에 넣을 수 있는 이미지는 채택된 뒷머리 제거 대기 0, 원본 걷기·정지·잠자기, 이 원본들에 근거한 오푸스 전신·머리 가이드뿐이다. 이전 전투 PNG·크롭·비교판·그것을 따라 만든 동세 가이드는 넣지 않는다.
- 동세·표정은 GitHub `ASTRA-PLAN.md`의 호루스 동작별 자세·표정 표 그대로 따른다. 임의로 새 동세·감정을 구성하지 않는다. 이전 전투 그림을 눈으로 보고 재현하지 않는다. 대기 0의 채택 외형은 보존한다.
- 가이드 첨부 자체는 합격 근거가 아니다. 첫 새 그림을 원본과 같은 캐릭터 배율로 비교하고 머리·몸·팔다리 비율, 색, 외곽선, 하이라이트 양이 어긋나면 다음 장을 생성하지 않는다. 실패한 기준으로 묶음을 끝까지 만들지 않는다.
- 실제 생성 참고 경로를 기록하고 호출 직전에 허용 목록과 대조한다. 구 전투 참고를 허용한다는 이전 문구보다 이 지시가 우선한다.


매번 순회하는 절차가 아니다. 실제 작업은 [START](ASTRA-START.md) 세 단계로 한다. 첫 작업이나 기준 변경 때 관련 절을 읽고, 작업 중에는 필요한 절을 바로 찾는다. 상세 외형은 [SPRITE](ASTRA-SPRITE.md), 자세·표정은 [PLAN](ASTRA-PLAN.md).

## 생성에 반영할 조건


- 외형 기준과 동세 참고의 역할을 분리한다. 현재 전투 재작화는 **원본 정지·걷기 = 외형·비율**, **기존 전투 그림 = 동세·표정 의도만**이다. 잠자기는 사용자가 허용한 보조 화풍 참고다.
- 머리/몸·팔다리·손발 비율, 얼굴·눈 형태, 피부·눈·옷·머리색, 외곽선 굵기, 명암 단계와 디테일 밀도를 원본에 맞춘다.
- 하이라이트는 채택 대기 수준의 큰 면과 적은 양. 갈래마다 잔빛줄기를 추가하지 않는다. 동작에 따라 조명·색을 바꾸지 않는다.
- 호루스는 승인된 짧고 두툼한 삐죽머리, 왼쪽 눈에는 문양 없음. 좌우는 캐릭터의 해부학적 좌우로 판단한다. 화면 좌우와 혼동하지 않고 원본의 보이는 볼로 확인한다. 문양 모양이 헷갈리면 채택된 호루스 잠자기 정면을 직접 연다(SPRITE B). 중복 문양·흰 동공 반짝이·가슴천·긴 뒷머리를 추가하지 않는다.
- 자세와 표정은 [PLAN](ASTRA-PLAN.md)의 해당 캐릭터·동작 칸 및 최신 사용자 수정대로 구체적으로 쓴다.
- 팔·손 개수와 관절, 의상, 승인 무기 디자인·길이·날카로움, 투명 여백과 기준점을 지정한다. 무기를 넣으려고 신체를 축소하거나 팔을 늘리지 않는다.
- 부분 수정은 수정 영역과 보존 영역을 명시한다. 요청 밖 변화가 생기면 수정 완료가 아니다.

## 프레임·작화 주의사항


**필수: 정지·걷기와 이어 보기.** 한 장 그릴 때마다 같은 방향의 최종 걷기 0·1·2와 정지를 **같은 배율로 옆에 놓고**, 걷기 → 정지 → 이 그림 → 정지 순서로 넘겨 본다. 걷다가 이 동작으로 넘어가는 게 같은 캐릭터의 다음 움직임처럼 보여야 한다:
- **비율:** 머리 크기, 몸통 길이, 팔다리 길이·굵기, 손발 크기, 옷 길이가 정지·걷기와 같다. 갑자기 길쭉하거나 작아지거나 머리만 커지면 실패.
- **동작:** 관절이 꺾이는 방향, 무게중심, 발이 땅을 디딘 위치가 정지·걷기에서 자연스럽게 이어진다. 정지에서 툭 튀어 다른 사람처럼 보이면 실패.
- **결:** 머리카락·옷자락의 흔들림 방향과 명암·외곽선 굵기가 걷기와 같은 그림체.
- **세밀함:** 머리카락 가닥 수, 명암 단계 수, 하이라이트 크기가 정지·걷기와 같다. **더 세밀하게 그리지 않는다**([나쁜 예: 세트 잠들기 192](art/chibi-refresh/notes/bad-too-detailed.jpg), 오른쪽이 가닥·명암이 너무 잘다). 정지·걷기는 큰 덩어리 몇 개 + 명암 2~3단계다. 가닥을 퍼지게 하라는 말은 큰 갈래를 나누라는 뜻이지 잔 가닥을 늘리라는 뜻이 아니다. 같은 배율로 나란히 놓았을 때 새 그림만 촘촘해 보이면 실패.
- 잠들기처럼 누운 그림은 특수하니 자세 이음은 보지 않되, 머리 크기·팔다리 길이·결은 똑같이 맞춘다.
- `sprite-review.py`가 이것을 `chain` 시트와 GIF 두 개(큰 크기, 게임 크기)로 만들어 준다. **그리는 중에도 돌려 본다.**


- ❌ **정지·채택 그림 조각을 잘라 붙이기.** 머리·얼굴·팔을 오려 붙이지 않는다. 정지는 **밑에 깔고 보는 기준**이고, 그 자세에 맞게 **새로 그린다**. **예외는 뜬 눈 하나:** 같은 방향 정지의 눈(흰자·홍채·안광·속눈썹)은 픽셀 그대로 옮겨도 된다([눈 견본](art/chibi-refresh/palette/eyes.png)). 머리통·얼굴 윤곽·머리카락은 계속 새로 그린다.
- ❌ **머리를 줄이거나 늘리기.** 머리 크기·모양은 어떤 자세에서도 정지와 같다. 그림을 캔버스에 맞추려고 전체를 줄이지 않는다.
- ❌ **머리 결 바꾸기.** 세트 웨이브, 호루스 긴 머리·뒷머리, 소망 생머리 — 전부 실패.
- ❌ **팔다리를 길게.** 굽히거나 올린 팔도 정지 길이·굵기 그대로. 좌우 팔·손도 같은 길이.
- ❌ **프레임 장난질.** 0프레임을 복사해서 늘리거나 옮기거나 비틀거나 색만 바꿔 1프레임을 만들지 않는다. **0과 1은 항상 각각 새로 그린다.** (잠들기 194·195: 1이 0과 픽셀 67~83 % 같음. 당시 픽셀 비율은 사례 수치이며 새 그림의 보편적 합격선이 아니다.) `sprite-review`가 "복사해 변형한 프레임"으로 잡는다. **예외:** 손·발만 움직이는 동작(상호작용 손 뻗기처럼 명세에 그렇게 적힌 것)은 몸을 그대로 두고 움직이는 손·발만 새로 그린다. 이때도 손·발을 늘리거나 비틀어 만들지 않는다.
- ❌ **다음 프레임을 안쪽만 고쳐 만들기.** 움직이는 부분의 **바깥 외곽선**이 움직여야 한다.
- ❌ **누운 정면에서 발바닥을 지나치게 크게.** 발이 보는 쪽을 향하니 원근으로 **정지 신발보다 조금 큰 게 정상**이다. 다만 머리보다 눈에 띌 만큼 커지면 실패. 채택된 소망 180의 발 비율을 기준으로 맞춘다.
- ❌ **몸통·다리를 길게.** 눕든 앉든 머리 아래 몸 길이는 정지와 같다(공통 설계는 호루스 비율이며 실제 작화는 해당 캐릭터 원본으로 확인). 이어 보기 시트에서 정지 옆에 놓고 턱~치마단, 치마단~발끝 길이를 비교한다. **한 방향을 고치면 같은 동작의 다른 방향(정면이면 옆모습도)도 같이 고친다.** 정면만 줄이면 방향을 바꿀 때 몸이 늘었다 줄었다 한다.
- ❌ **누운 정면을 무릎 세워 그리기.** 다리는 곧게 아래로(사용자 예시).
- ❌ **몸이 한쪽으로 쏠리기.** 정면·뒷모습은 머리·배·발 가운데가 한 세로줄.
- ❌ **정지·걷기보다 세밀하게.** 잔 가닥을 늘리거나 명암 단계를 더 쪼개지 않는다. 같은 그림체, 같은 밀도.
- ❌ **색을 생성 결과대로 두거나 새로 만들기.** 색 표의 색으로 다시 칠한다.
- ❌ **피부색을 생성 결과대로 두기.** 정지·걷기에서 뽑은 색만.
- ❌ **좌우를 뒤집어 쓰기.** 왼쪽·오른쪽은 각각 그린다.
- ❌ **효과(씨앗, 물, 김, 줄)를 캐릭터 PNG에 그리기.** 효과는 따로.
- ❌ **어색하거나 민망한 자세.** 실제 게임 스프라이트처럼 자연스럽게 그린다. 특히 **쩍벌 다리**([나쁜 예](art/chibi-refresh/notes/bad-wide-legs.jpg)): 쪼그리거나 앉을 때 무릎은 모으거나 한쪽으로 기울이고, 드레스·치마는 무릎을 덮는다. 사용자가 지적하지 않아도 스스로 알아서 피한다.

## 결과 비교 상세


1. 정지·걷기와 실제 캐릭터 배율을 맞춘 비교 PNG를 만들고 직접 연다. 칸 크기에 각 그림을 따로 맞춰 비율 차이를 숨기지 않는다. 캔버스 크기와 신체 크기를 혼동하지 않는다.
2. 얼굴·머리·손·문양·수정 경계를 확대해서 본다. 원본과 색·선·비율·의상·디테일을 대조한다.
3. 기존 대기 → 새 동작 → 대기 및 필요한 걷기 연결을 확인한다. 정지 화면과 게임 표시 크기, 밝은/어두운 배경을 확인한다.
4. SPRITE의 자동 검사를 실행하고 원본 결과를 보존한다. 측정 실패는 실패로 기록한다. 검사를 통과시키려고 수치를 꾸미거나 그림을 임의로 변형하지 않는다. 자동 통과는 시각적 합격을 뜻하지 않는다.
5. 불일치는 수정하고 다시 확인한다. 같은 부위가 반복 실패하면 해당 부위를 확대해 수정하는 방법으로 전환한다. 같은 반려가 두 번이면 원본·방법부터 재검토한다.
6. 비교 기록을 저장하고 현재 작업의 상태·다음 행동을 갱신한다. 사용자 채택 전에는 검토본이다. 확인하지 못한 항목은 미확인으로 남긴다.

## 자동 검사 사용법


```
python3 tools/art/sprite-review.py docs/art/chibi-refresh/<동작 폴더> --out docs/art/chibi-refresh/<동작 폴더>/review
```

- 묶음이면 묶음 폴더 전체(동작별 하위 폴더 여러 개면 각각)에 돌린다.
- `review/report.md`의 각 지적을 실제 결함·측정 실패·미확인으로 판정하고 근거를 남긴다. 실제 결함은 고친 뒤 재검사한다. 측정 실패를 없애려고 신체를 변형하거나 검사 기준을 낮추지 않는다. 보고서 원본은 보존한다. 미확인이나 결함이 남으면 완료로 보고하지 않는다. 검사 항목: 피부색, 머리색, 머리 크기, 걷기·정지와 이어 보기(chain), 정지 머리를 잘라 붙였는지, 프레임별 키 흐름, 0↔1 외곽선, 몸 쏠림, 좌우, 기준 그림 겹치기, 누운 머리.
- 그 다음 **눈으로** 본다(볼 것 0개는 통과가 아니다):
  - [ ] 정지와 같은 배율로 나란히: 머리 크기·머리 결·팔다리 길이가 같다
  - [ ] 기준 그림·사용자 예시와 나란히: 구도와 자세가 맞다
  - [ ] **이어 보기(필수)** `review/<누구>-<자세>-chain.gif`·`-chain-game.gif`(걷기 → 정지 → 새 프레임 → 정지): 비율이 같고, 동작이 툭 끊기지 않고, 프레임이 달라 보인다. 보고에 이 GIF를 같이 보낸다
  - [ ] 밝은·어두운 배경에서: 틈, 후광, 남은 픽셀, 깨진 경계가 없다
- `review/` 폴더를 같이 main에 올린다.
- 모든 그림 공통 검수(밝은·어두운 배경, 이중선, 경계)는 [HANDOFF](ASTRA-HANDOFF.md) 2절.

## 가이드 한계와 첫 샘플 판정


- `head-check.py --guide`는 620×720에 가이드를 만든다. 전투 1600×720에서 중앙을 맞출 때는 가이드 픽셀을 확대하지 않고 투명 캔버스를 늘려 x에 490을 더한다. 기본 발 기준 (310,662) → (800,662). 새 머리 위치·회전은 동작에 맞춰 따로 기록한다. 머리가 이 기본 캔버스 밖으로 나가면 잘린 가이드를 쓰지 않고, 충분한 캔버스에서 생성하도록 방법을 조정한다.
- 정면·측면 가이드는 3/4 전투 자세의 완성 밑그림이 아니다. 머리 기본 크기, 턱~치마단, 어깨~팔꿈치~손목, 골반~무릎~발의 실제 길이를 원본에서 확인하고 동세에 맞춰 배치한다. 굽힘·원근 때문에 투영 길이가 줄어드는 것과 팔다리 자체가 길어지는 것을 구분한다. 잘못된 전투 몸 윤곽을 그대로 따라 그리지 않는다.
- 가이드가 실제 생성 입력으로 전달됐는지 파일과 요청을 기록한다. 이미지 생성 모델이 가이드와 픽셀 단위 일치를 보장하지 않는다는 한계를 인정한다. 첨부했다는 이유만으로 “대고 그렸다/일치한다”고 보고하지 않는다. 결과 비교로 판단한다.

### 첫 샘플 판정표

각 항목은 **맞음 / 수정 필요 / 미확인**과 비교 이미지 경로를 기록한다. 수치가 자동 통과 범위에 들어가도 육안 차이가 있으면 수정 필요다. 임의의 새 허용 오차를 만들어 적용하지 않는다.

| 항목 | 확인할 증거 |
|---|---|
| 머리·몸 비율 | 고정 배율의 정면·측면 원본과 전투 전신 비교. 머리 폭/높이, 턱~치마단, 팔다리의 관절별 길이, 손발 크기 |
| 얼굴·눈·문양 | 원본과 같은 배율 확대. 얼굴형·눈 형태·색·문양 형태와 해부학적 위치. 호루스 문양은 지정 잠자기 정면도 확인 |
| 색·선·디테일 | 머리 기본/그림자/하이라이트, 피부·옷, 외곽선 굵기, 하이라이트 면적·대비. 어둡게 칠한 것만으로 통과하지 않음 |
| 동세·표정 | 채택된 동세 참고와 대조. 무게중심·회전·무기 방향·감정은 살리고 잘못된 신체 비율은 가져오지 않음 |
| 해부·의상·무기 | 팔 2개·손 2개, 관절 연결, 가슴천 등 없는 옷 추가 여부, 무기 쥠·길이·끝 잘림 |
| 연결·경계 | 원본/전투 연결, 실제 표시 크기, 밝고 어두운 배경. 부분 수정 밖의 변화도 검사 |

수정이 필요한 첫 샘플은 범위를 확인해 고친다. 반복 실패하면 같은 입력으로 전체 재생성을 반복하지 않고 가이드·입력 방식부터 재검토한다. 사용자가 진행 중 결과를 요청하면 즉시 현재 그림을 제공하되 결함·미확인을 숨기거나 완성본이라고 부르지 않는다.
