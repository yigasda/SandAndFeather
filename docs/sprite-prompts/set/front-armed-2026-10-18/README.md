# 세트 무기 든 정면 — 2026-10-18 채택 시안

사용자가 긴 지팡이 재생성 3개 중 **첫 번째**를 채택했다. 이 폴더는 원본 PNG, 실제 생성 프롬프트, 입력 이미지 5장의 재사용용 백업이다.

- [파일별 해시 및 규격](manifest.json)

## 실제 입력 이미지 순서

1. [종합 가이드](references/01-1000483771.png)
2. [왼쪽 전투 대기 0](references/02-set-left-combat-idle-0.png)
3. [왼쪽 찌르기 0](references/03-set-left-combat-attack-0.png)
4. [정면 걷기 트레이싱 가이드](references/04-1000483753.png)
5. [세트 정면 원본](references/05-set-front-original.png), 원출처: `docs/art/chibi-refresh/final/set/idle/set-front.png`

위 5장을 순서대로 생성기에 넣었으며 직전 생성 시안을 수정 입력으로 사용하지 않았다. `transparent_background=true`. 같은 프롬프트로 3번 생성한 결과 중 첫 번째만 이 폴더에 채택본으로 보존한다. 원본 생성 ID: `exec-7d699942-3648-4620-812c-37cbe2a1c605.png`.

## 유지할 핵심

살짝 내려다보는 정면, 기존 얼굴과 좁은 붉은 눈, 짧은 팔다리와 작은 평평한 남성 흉곽, 원본 그대로의 장신구 개수. 와스 지팡이는 굵기와 양끝 크기를 키우지 않고 자루 길이만 길게. 화면 왼쪽 옆머리 끝의 우연히 깨진 픽셀은 복제하지 않고 자연스럽게 마무리한다.

## 상태와 주의

이것은 **승인된 정면 콘셉트 1장**이다. 세 캐릭터 × 앞뒤 × 걷기/대기/찌르기 × 3프레임, 총 54장 세트가 완성된 것이 아니다. 게임 런타임/아틀라스/채택 기존 파일을 이 백업으로 교체하지 않았다. 실제 프롬프트는 재현을 돕는 기록이며 동일 결과를 보장하지 않는다. 가이드에 지정된 비율과 생성 결과가 픽셀 단위로 완전히 일치한다고 보증하지 않는다. 후속 프레임 제작은 별도 지시와 검토를 따른다.
