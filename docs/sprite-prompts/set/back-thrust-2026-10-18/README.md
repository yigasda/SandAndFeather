# 세트 뒷모습 찌르기 0·1 — 채택 (2026-10-18)

사용자가 준비 0·타격 1을 채택하고 원본 및 프롬프트 보존을 요청했다.

## 실제 입력 순서

두 프레임 모두 아래 세 장을 같은 순서로 입력했다. 각 프레임을 독립 생성했고 준비 결과를 타격 생성 입력으로 사용하지 않았다.

1. [채택 뒷걷기 0](references/01-set-back-armed-walk-0.png)
2. [채택 정면 찌르기 1 (v6)](references/02-set-front-combat-attack-1.png)
3. [팔장식 수정 정면 대기 0](references/03-set-front-combat-idle-0.png)

## 구도와 모션

위에서 살짝 내려다보는 뒷모습 3/4 게임 지도 시점을 유지한다. 준비 0에서 무기를 당기고 타격 1에서 같은 찌르기 방향으로 내민다. 캐릭터와 무기의 원래 비율·디자인을 유지하며 과한 영화식 원근이나 휘두르기로 바꾸지 않는다. 정확한 프레임별 요청은 prompts.json 원문을 따른다.

공격은 **0·1의 두 프레임**을 사용한다. 회수 2는 사용자 지시에 따라 의도적으로 생략하며 추가 제작 대기 항목이 아니다.

## 적용 상태

채택 PNG는 1402×1122 RGBA 원본 바이트를 보존한다. docs/art/chibi-refresh/final/set/combat-attack/에도 동일 파일을 저장한다. 기존 정면 찌르기 원본은 변경하지 않는다. 런타임 등록, 앵커·충돌 설정, 아틀라스 작업은 이 백업에 포함하지 않는다. 생성 재현이나 픽셀 단위 일치는 보증하지 않는다.
