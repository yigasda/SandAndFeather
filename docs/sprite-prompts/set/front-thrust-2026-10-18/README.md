## 실제 프롬프트와 입력 이미지

### 당기기 0 (v4)

[실제 프롬프트 원문](prompts/pullback-0-exact.txt)

입력 순서:
1. [사용자가 지정한 기본 이미지](references/1000483782.png)
2. [사용자의 위치 표시 이미지](references/1000483785.jpg)

같은 대각선 방향과 무기 길이를 유지하며 무기를 축 방향 뒤쪽(화면 우상단)으로 당기도록 요청했다. 구체적 이동량은 이 세트 이미지에 사용한 값이며 다른 캐릭터에게 무조건 재사용하지 않는다. 표시 이미지는 위치 지시용이며 화풍 참조가 아니다.

### 찌르기 1 (v6, 채택)

[실제 프롬프트 원문](prompts/impact-1-exact.txt)

입력은 [기본 이미지](references/1000483782.png) **한 장뿐**이다. v4 결과나 표시 이미지를 입력으로 사용하지 않았다. 원래 기본 이미지가 이미 타격 자세에 가까워, 앞쪽 무기 머리와 인접 금색 부분을 약 10%만 키우도록 요청했다. 전체 무기를 확대하거나 캐릭터를 다시 디자인하는 작업이 아니다.

## 호루스 재사용 지침

- 카메라는 살짝 내려다보는 3/4 RPG 지도 시점, 거의 평행 투영이다. 눈높이 영화식 카메라나 과한 원근은 쓰지 않는다.
- 무기는 지면과 평행하게 찌른다. 카메라 정면으로 쏘는 것처럼 만들지 않는다.
- 준비와 타격은 같은 대각선 무기 축을 따라 뒤로 당기고 앞으로 내미는 동작이다. 휘두르기/쓸기나 무기 회전으로 대체하지 않는다.
- 가까운 끝부분의 크기 변화는 약 10% 정도로 절제한다. 무기 전체나 자루 두께를 함께 확대하지 않는다.
- 호루스 제작 시 **호루스 자신의 채택 원본과 무기·위치 가이드로 교체**한다. 세트의 얼굴·머리·장신구·체형을 옮기지 않는다. 호루스의 비율, 화풍, 정체성과 무기 디자인을 유지한다.
- 위 원문은 세트 실제 생성 기록이다. 호루스용은 별도 프롬프트로 작성하고 원문을 덮어쓰지 않는다. 동일 결과 재현은 보장되지 않는다.
