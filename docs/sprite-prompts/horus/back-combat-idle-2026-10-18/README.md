# 호루스 뒷모습 전투 대기 0·1·2 — 금색 창 디자인 최종 채택

approved/의 개별 PNG 3장은 exact-weapon 최종 시트(exec-cfd41867)에서 분리한 채택 원본이다. 원본 바이트와 규격을 그대로 보존하며 final/horus/combat-idle/에도 동일 파일을 저장한다. preview.gif는 해당 미리보기다.

## 최종 생성 입력 순서
exact-weapon-prompt.txt가 실제 최종 프롬프트다.
1. provenance/base-fresh-sheet.png
2. references/1000483614(1).png
3. references/1000483615.png
4. references/1000483616(1).png

무기는 참고의 금색 면 분할 디자인을 기준으로 수정했다. navy slit이 들어간 weapon-fix 결과나 다른 retry/repose 결과는 현재 채택본이 아니다. 최종 시트는 provenance/accepted-exact-weapon-sheet.png다.

## 바탕 시트 계보
base-fresh-prompt.txt는 바탕 시트 생성 원문이다. 당시 입력 순서:
1. references/1000483770.png
2. references/1000483595.png
3. references/set-back-combat-idle-0.png
4. references/set-back-combat-idle-1.png
5. references/set-back-combat-idle-2.png (세트 2-v2 채택본)

바탕 시트는 최종 편집 입력으로만 보존한다. 최종 채택 이미지로 혼동하지 않는다. 다른 반려 시트는 이 폴더에 포함하지 않는다.

## 상태
뒷대기 3장만 신규 채택한다. 기존 호루스 앞모션 8장은 그대로이며 실수로 만든 front attack weapon-design은 채택하지 않았다. 런타임, 아틀라스, 앵커와 충돌 설정은 수정하지 않았다. 해시는 manifest.json을 참조한다.
