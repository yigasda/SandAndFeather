## 정확한 생성 계보
initial-prompts.json에 원문 3개와 최초 입력 5장 순서가 기록되어 있다. references/의 파일명과 대응한다.
1. 1000483688(1).png
2. 1000483731(1).png
3. 1000483733(1).png
4. 1000483726.png
5. 1000483614.png

1·2의 최종 눈썹 수정은 browfix-exact-prompt.txt를 사용했다. 각 입력 순서는 해당 번호의 최초 대기 원본(references/before-browfix/) + 채택 대기 0(approved/horus-front-combat-idle-0.png)이다. 0 자체는 수정하지 않았다.

게임 적용은 별도다. 원본은 docs/art/chibi-refresh/final/horus/combat-idle/에도 동일 바이트로 보존한다. 생성 결과 재현이나 픽셀 단위 일치를 보증하지 않는다.
