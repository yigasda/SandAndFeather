# 호루스 뒷찌르기 0·1 — 색감 재생성 최종 채택

approved/의 두 PNG는 color-redo 최종 시트(exec-a6ac4508-f1c0-44a4-b98d-ceb6d00236b8)에서 분리한 채택 원본이다. 시트는1983×793, 개별 파일은992×793 RGBA이며 1픽셀 패딩을 포함한 전달본 바이트를 그대로 보존한다. 다시 리사이즈하지 않았다. provenance/accepted-sheet.png와 preview.gif도 보존한다.

## 실제 최종 입력 순서
color-redo-exact-prompt.txt의 입력:
1. references/01-v2-preparation.png
2. references/02-user-fixed-impact.png
3. references/03-exact-weapon-back-idle-0.png
4. references/04-front-idle-0.png

references의 이전 공격 두 장은 최종 색감 재생성 입력으로만 보존하며 현재 채택 원본으로 표시하지 않는다. 최종은 approved/의 color-redo 결과뿐이다. 준비 0·타격 1 두 프레임이며 회수는 사용자 지시로 생략한다.

창 양끝과 몸 전체가 크롭 안에 있음을 육안으로 확인했다. 일부 캔버스 가장자리에 알파1의 미세 흔적은 있으나 채택 원본을 임의 정리하지 않았다. 동일 PNG는 docs/art/chibi-refresh/final/horus/combat-attack/에도 보존한다. 런타임·아틀라스·앵커 수정은 없다. manifest.json에 규격과 해시를 기록한다.
