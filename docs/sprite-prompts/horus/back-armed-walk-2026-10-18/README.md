# 호루스 뒷무기 걷기 0·1·2 — 최종 채택

approved/의 세 PNG는 shaft-fix-v2 최종 시트(exec-a5b9b908-5372-41ad-ad20-b4f2037f191d)에서 연결요소별로 분리하고 공통 800×830 투명 캔버스에 보존한 수정된 개별 파일이다. 최초 Library 개별 잘림 파일은 사용하지 않는다. 원본 시트는 provenance/accepted-sheet.png다.

## 정확한 계보
최종 shaft-fix-exact-prompt.txt 입력은 provenance/input-v2-sheet.png 한 장이다.
그 바탕의 base-v2-exact-prompt.txt 입력 순서는 다음과 같다.
1. references/horus-back-combat-idle-0.png — 금색 창 최종 채택 뒷대기 0
2. references/1000483768.png
3. references/1000483769.png
4. references/1000483770(1).png

바탕 시트는 편집 입력 기록일 뿐 현재 채택본이 아니다. 최종 개별 PNG의 창 양끝과 몸 전체 경계를 육안으로 확인했다. 개별 파일을 다시 리사이즈하거나 재인코딩하지 않고 채택된 수정 크롭의 바이트 그대로 업로드했다.

동일 PNG는 docs/art/chibi-refresh/final/horus/armed-walk/에도 보존한다. 게임 적용·앵커·아틀라스는 별도이며 런타임은 변경하지 않는다. manifest.json에 규격과 해시를 기록한다.
