# 호루스 최종 채택 전투 18장

기존 첫 왼쪽 전투 6장과 마지막 4회 생성 중 첫 번째 묶음 12장으로 확정. 사용자가 “첫번째로 채택!! ... 메인에 올려!!”라고 승인했다.

전투 전달은 이 폴더의 png/ 18장을 사용한다. 이전 17장 폴더를 대체하는 최종 작화이며 이전 파일은 보관한다. 게임 런타임 적용은 하지 않았다. 생성 원본에서 픽셀을 추출했으며 재생성·리사이즈하지 않았다. 16px 투명 여백을 추가했다. 맞닿은 첫 열 상하 프레임은 원본 y=350 경계로 분리했다.

사용자가 1000483178.jpg 캡처로 선택본을 재확인했다. 해당 생성 원본은 `exec-433d7d90-0bdb-42bf-a2eb-a19c64cc61ca.png`이며 `sources/combat-final-twelve.png`로 보관한다. 다른 3개 후보는 포함하지 않았다.
