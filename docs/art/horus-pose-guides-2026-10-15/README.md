스크립트와 내부 JSON의 절대 경로는 당시 작업 환경 경로다. 재실행 시 입력 원본·폰트·출력 경로를 현재 환경에 맞춰 지정해야 한다. 재실행 검증은 하지 않았으며, 이번 작업에서는 보관 파일의 SHA-256 동일성만 확인했다.

이 폴더는 제작 참고용이다. 비교 이미지 속 예전 스프라이트를 채택본으로 적용하지 않는다. 이전 전투 12장 전달 폴더는 복구하지 않았다. 게임 전달은 [최신 채택 18장](../horus-combat-approved-18-2026-10-15/README.md), 외형은 [원본·외형 가이드](../horus-appearance-guides-2026-10-15/README.md)를 따른다.
