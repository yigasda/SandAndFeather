호루스 전체 68프레임 선 도식

범위: 게임 data/sprites.json에서 쓰는 50프레임 + 메인2/호루스 채택 전투 18프레임.
전체 runtime id 집합 대조, 파일 SHA256 확인. 중복 수정본/반려본 포함 안 함.
각 프레임 원본 크기·좌표 그대로 자세와 표정 선을 추출. 좌우 반전·포즈 생성·몸 비율 변형 없음.
선 추출은 정확한 좌표 보존용이며 관절이나 얼굴의 의미를 판정하는 모델이 아님.
기존 머리 외곽/디테일도 선으로 남으므로 새 외형을 정하는 기준으로 사용하면 안 됨.
새 비율로 관절 길이를 재설계하는 단계는 아직 하지 않음. 생성용 최종 새 비율 가이드라고 부르지 않음.
기존12개 수동 관절도와 달리 이번68장은 전체 윤곽·내부선 도식. 모든 프레임의 수동 관절점이 찍혔다고 주장하지 않음.
원본 비교시트는 검수용. 신외형 생성 시 원본 컬러 비교시트를 첨부하지 않음.
