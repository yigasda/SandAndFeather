# UI 테마 제작 인수인계

채택 시안을 재사용 가능한 PNG 부품과 실제 조립 화면으로 만드는 기준

## 1. 목표와 필수 입력

채택된 테마의 작화, 재질, 색, 도트 밀도, 장식 비율을 유지하면서 다른 화면에도 재사용할 수 있는 부품을 만든다. 이전 테마의 색이나 장식을 다음 테마에 복제하지 않는다. 한 테마를 끝까지 검수한 뒤 다음 테마로 진행한다.

시작 전에 다음을 확인한다.

- 해당 테마의 채택 시안 원본과 승인된 배치·화면 크기
- 기존 게임에서 그대로 재사용할 아이콘 파일 및 기능별 매핑
- 필요한 부품 목록과 분리 단위: 프레임, 채움, 아이콘, 장식, 게이지 등
- 유지할 요소와 변경할 요소, 생성 허용 여부

첨부 이미지는 실제로 열어 확인한다. 대상이 아이콘 그림인지, 슬롯 틀인지, 실행 버튼인지 불명확하면 작업 전에 한 번에 구분해 질문한다. 기능이 같거나 물건이 비슷하다는 이유로 다른 그림을 동일한 아이콘으로 취급하지 않는다.

## 2. 원본 보존과 부품 분리

원본은 덮어쓰지 않고 작업본·비교본·채택본을 구분한다. 좌표와 크기를 기록하고, 불필요한 리사이즈·보간·색상 변환을 피한다.

부품은 기능별로 독립시킨다.

- 프레임: 외곽선·림·모서리·의도된 그림자를 보존하고 중앙을 투명하게 한다.
- 채움: 프레임과 별도로 둔다. 아이콘이나 글자 자리에 구멍이 남은 상태를 완성 채움으로 제출하지 않는다.
- 아이콘: 버튼 면이나 슬롯 테두리를 붙여 두지 않는다.
- 장식: 늘리면 형태가 깨지는 모서리 문양과 반복 문양은 따로 관리한다.
- 글자와 숫자: 아트 PNG에 포함하지 않고 실제 폰트로 별도 배치한다.

사각형 crop만 하고 누끼라고 부르지 않는다. 확대해서 도트의 계단형 외곽, 내부 빈 공간, 얇은 선을 확인하고 알파 마스크를 정밀하게 만든다. 밝은 배경과 연결되지 않은 흰 하이라이트를 배경으로 잘못 지우지 않는다. 원래의 밝은 림과 잘못 남은 배경선을 구별한다.

합쳐진 이미지에서 원래 알파나 가려진 부분을 완벽히 복원할 수 없는 경우가 있다. 보존한 원본 픽셀과 추정 복원한 면을 기록으로 구분하고, 확인되지 않은 부분을 '원본과 완전히 동일'하다고 말하지 않는다.

## 3. 글자·아이콘이 가린 채움 복원

원본의 깨끗한 안쪽에서 위·아래·좌·우 여러 지점의 색을 확인한다. 프레임, 장식, 아이콘, 문자와 그림자가 섞인 픽셀은 샘플에서 제외한다.

은은한 명암 변화가 있는 면은 다지점 색을 이용한 낮은 차수의 2D 그라데이션 복원을 우선한다. 기존 면과 자연스럽게 이어지도록 하되, 테두리·장식·아이콘·알파 실루엣은 보호한다. 글자 모양이나 사각 패치 경계, 수평 줄무늬, 모자이크 흔적이 남지 않았는지 글자 없는 상태에서 확인한다.

단색 덮기는 원래 평탄한 면이거나 사용자가 단색화를 지정한 경우에만 적용한다. 그라데이션이 있는 면을 무조건 한 색으로 덮지 않는다.

가우시안 블러는 필요할 때 별도의 선택 비교본으로 만든다. 그라데이션과 블러를 한 결과에 섞어 비교를 흐리지 않는다. 내부 채움만 처리하고, 투명 영역의 RGB가 번지거나 프레임과 도트가 흐려지지 않게 보호한다. 비교본은 같은 크기·배경·텍스트 없는 상태로 보여준다.

## 4. 기존 아이콘 재사용과 제한적 생성

기존 게임 파일을 쓰기로 한 아이콘은 실제 파일 그대로 사용한다. 임의 재그림·색 변경·비슷한 대체품 채택을 하지 않는다. 단계별 보상 등은 실제 기능 매핑을 확인한다. 파일이 없으면 해당 항목과 대응 필요를 알리고 임의 대체하지 않는다.

전체 화면 재생성을 기본 작업 방식으로 쓰지 않는다. 필요한 부품에 대한 명시적인 생성 지시가 있을 때만 그 부품과 해당 테마의 채택 시안을 참고해 제한적으로 생성한다. 결과를 원본 추출물로 표시하지 않고, 형태·색·도트·장식 차이를 비교하여 채택 여부를 확인한다.

## 5. 크기 조정과 실제 조립

승인된 배치에 실제 PNG를 합성한다. 완성 시안 스크린샷을 바탕에 붙이거나 전체 화면을 다시 생성해 조립 결과처럼 보이게 하지 않는다.

프레임 크기를 바꿔야 하면 9-slice 등으로 모서리와 선 두께를 유지한다. 테마 장식까지 길게 늘리지 않는다. 아이콘은 종횡비를 유지하고, 크기·중앙 정렬·여백을 일관되게 맞춘다. 반복 칸은 승인된 동일 부품을 재사용하고 칸 규격과 간격을 맞춘다.

텍스트는 원본 내용을 확인한 뒤 실제 폰트로 배치한다. 밝고 어두운 채움에 맞는 대비를 확보하고, 수량·게이지 값·라벨·하단 문구의 누락과 잘림을 확인한다. 미리보기용 표시 크기와 전달할 PNG 원본 크기는 구분한다.

## 6. 검수와 합격 조건

파일 수나 해시 검사만으로 합격 처리하지 않는다. 다음을 모두 확인한다.

- 검은색·회색·밝은색·체커 배경에서 흰 배경선, 혼색 테두리, 구멍, 잘린 그림자 확인
- 확대 화면에서 도트 윤곽·림·모서리·꽃잎 같은 작은 연결부 확인
- 원배율 전체 화면에서 정렬·간격·가독성·겹침·누락 확인
- 수정하지 않기로 한 프레임·아이콘·알파 및 수정 범위 밖 픽셀의 동일성 검사
- 사용 파일과 배치 목록, 중복 재사용, 누락 파일, PNG 및 ZIP 무결성 검사

문제가 있으면 해당 부품만 수정하고 전후 확대와 전체 화면을 함께 다시 확인한다. 남은 혼색 경계나 추정 복원의 한계는 숨기지 않는다.

## 7. 전달과 진행 방식

진행 중에는 완성된 부분, 발견한 문제, 필요한 선택을 짧게 알린다. 부분 결과만 반복해 보내기보다 검토 가능한 묶음과 전체 조립 화면을 보여준다. 애매한 지시는 임의 해석하지 말고, 대상과 변경 범위를 구체적으로 질문한다.

최종 채택·검수 후에 실제 사용하는 개별 PNG만 ZIP으로 전달한다. 폐기 후보, 원본 참고 이미지, 불필요한 중복, 작업 스크립트와 비공개 경로는 제외한다. 파일명·역할·크기·배치·재사용 관계·추정 복원 여부를 담은 이식 가능한 manifest와 전체 미리보기를 포함한다.

완료 기준은 '파일을 만들었다'가 아니라, 채택된 테마의 부품이 독립적으로 재사용 가능하고 실제 조립에서도 깨짐 없이 확인된 상태다.
