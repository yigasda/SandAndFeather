실제 채택 원본 `../well-courtyard-v1.png`와 원본을(193,0)에 배치한 캔버스를 이미지 편집 입력으로 사용했다. 기존 우물·가구·마당 배치를 이어가면서 출구를 옆벽 방향에 맞춰 수정하도록 했다.

**이 세 파일은 형태 선택용 전체 편집 시안이며, 출구 밖 픽셀 동일을 달성한 최종 에셋이 아니다.** 일부 기둥·가구·배경 위치도 생성 결과에서 달라졌다. 국소 합성을 시험했으나 접합부 겹침이 생긴 결과는 전달에서 제외했다. 선택 뒤 해당 입구 부분을 승인 원본에 맞춰 국소 편집하고, 낮밤 구조를 일치시켜 최종 패키징해야 한다. 최종 원본 오프셋과 트리거 좌표도 그 단계에서 확정한다. 현재 `validation.json`은 픽셀 보존 미검증을 명시한다.

기존 채택 연못·동쪽 회랑, 현재 게임 연결 이미지와 충돌 좌표는 변경하지 않았다. 밤 3안·긴 회랑 확장은 이번 단계에서 제작하지 않았다.
