## 검토 및 재현

전체, 양끝 확대, 정적 아바타 배치 확인. 원본 불변 검사는 접합부의 미적 품질을 보증하지 않는다. 특히 확장부 바닥 줄눈과 깔개 연결은 사용자 검토 대상으로 남긴다.

`node build.cjs` → `node refine-edges.cjs`. 원본/생성소스/등록 수치는 이 폴더 및 명시한 원본 경로에서 읽는다. `previews.cjs`는 우물 밤 파일 제작 후 실행한다. 소스와 미리보기는 게임에 연결하지 않는다.
