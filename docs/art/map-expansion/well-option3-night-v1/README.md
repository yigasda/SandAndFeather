# 138 — 확정 우물마당 3안의 밤 검토본

2026-10-11 사용자 “우물마당은 3번 시안(동그란 문)으로 확정…밤도 만들어줘”. **낮3안 확정, 새 밤 검토 대기, 게임 미적용.**

- 낮 기준: `../well-review-three-v3/option-3.png` **2160×887**. `well-courtyard-option3-day.png`는 바이트 동일 복사.
- 새 밤: `well-courtyard-option3-night.png` **2160×887**.
- 기존 낮밤 원본들을 직접 열어 밤 조명 참고. 푸른 주변광, 기존 좌우 문 안 등불의 따뜻한 빛, 읽히는 바닥과 물 반사를 적용했다.
- 편집 입력: 확정3안 낮, 기존 `../well-courtyard-v1-night.png`, 채택 `../exits-v2/courtyard-colonnade-v1-night.png`. 후자 두 장은 조명 참고만.
- 낮밤 문3곳·우물·대야/의자·벤치·앞쪽 기둥 배치를 시각 비교. 특징점1667개 대응에서 위치차 중앙값0.84px/95백분위2.06px. 픽셀 동일이나 모든 기하 일치를 보장하는 수치는 아니다.
- `coordinates.json`은 낮밤 공통 출구/도착점 제안. 기존1774×887 게임맵에 단순 오프셋 적용 불가; 오푸스가 선택3안에 맞춰 충돌/출구/밤 전환을 조정해야 한다.
- `previews/138-well-option3-day-night.png`: 확정낮/새밤 같은 배율 비교.

이번 최신확정에 따라 실제3안 파일로 밤을 만들었다. 과거 문서의 ‘선택 후 옛맵에 입구 재제작’ 문구를 자동 적용해 낮 시안을 바꾸지 않았다. 기존 게임 파일은 보존했다.

재현: `node build.cjs`로 생성원본을 지정크기에 맞춘다. `sources/`는 제작 기록이며 게임용 파일이 아니다.
