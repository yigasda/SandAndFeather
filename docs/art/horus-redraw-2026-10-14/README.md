# 호루스 새 외형 — 채택 PNG 보관

사용자 요청: “일단 채택본들 다 개별 png로 메인브랜치에 올려줘”.

전달 파일은 `png/`의 **51장**이다. 이미지 재생성·리사이즈 없이 채택 시트에서 분리하고 투명 여백 16px을 추가했다. 원본 캐릭터는 `sources/horus-original.png`, 채택 출처·셀·크롭 좌표·크기·기준점·SHA-256은 `manifest.json`에 있다. 기준점은 전달용 하단 중앙이며 게임 적용 시 동작별 정렬 검토가 필요하다.

`png/`만 채택 개별 파일 목록이다. `sources/`는 출처 보존용 전체 시트이므로 미채택 셀이 섞일 수 있다. 전체 시트가 모두 채택되었다고 해석하지 않는다. 이전 생활 묶음의 미소는 교체되었고, 샤이·서프라이즈는 별도 채택본으로 대체했다. 최근 두 번째 전투 묶음 재생성들은 미채택이며 전달 PNG에서 제외했다.

게임 런타임 파일과 기존 메인1/메인2 자산은 교체하지 않았다. 이번 작업은 사용자가 승인한 새 그림의 저장소 보관이다. 좌우 정지·걷기는 추가 첨부 1000482937에서 확정했다. 뒷면 걷기·정지는 이번 개별 PNG 목록에 포함하지 않았다.

검증: 51개 PNG 디코딩, 투명 알파, 파일 해시, 유지된 픽셀의 원본 일치 확인. 잘라낸 셀은 미리보기로 확인했다. 생성 시트 자체의 표현·경계 품질은 채택 당시 상태로 보존했다.
