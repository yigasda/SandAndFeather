# Horus — 채택 전투 17장

최종 미채택 오른쪽 피격(`horus-right-combat-hit-0`) 1장 제외. 사용자 요청으로 생성 원본에서 개별 PNG를 추출했다. 게임 적용은 하지 않았다.

- 왼쪽 첫 전투 묶음: 준비·공격·피격·대기 0/1/2 (6장).
- 1000483172로 재확인한 오른쪽 채택 묶음: 대기 0/1/2·기술·주문·지침 (6장).
- 1000483152 생성 원본: 1번 왼쪽 기술, 2번 왼쪽 주문 (2장).
- 왼쪽 지침: 문양 10% 축소 후 사용자가 채택한 최종 단독본 (1장).
- 오른쪽 준비·공격: 생성 원본에서 문양 제거를 다시 한 뒤 “굿 45번 채택”한 최종본 (2장).

`png/`만 전달 대상이다. `sources/`의 부분 채택 시트에는 미채택 그림도 있으므로 시트 전체를 적용하지 않는다. 원래 색·알파와 픽셀 크기를 보존하고 16px 투명 여백만 추가했다. 원본의 가장자리에서 이미 끝나는 부분은 새로 그리거나 복원하지 않았다. 각 원본 경계·기준점·해시는 manifest.json에 기록했다.
