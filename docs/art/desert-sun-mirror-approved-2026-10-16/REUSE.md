# 태양거울 채택 기준

현재 외형 원본은 approved.png. 사용자가 “씨발 이거다!!!!! 합격!!!”으로 확정했다.

- 가운데가 조이는 금색 세로타원 틀, 각진 하부와 두꺼운 오른쪽 측면. 위에서 내려다보는 3/4 시점, 왼쪽 아래를 향함.
- 닳은 금속과 유리 가장자리 노화. 중성 은빛 유리: 과한 푸른끼·금색 유리 금지.
- 유리 안에 빛바랜 컬러의 매우 오래되고 부서진 신전, 끊긴 계단과 불길한 깊은 입구. 은빛 반사가 겹쳐 실제 거울로 읽힘.
- 팔다리·날개·영혼·눈·받침을 추가하지 않는다. 틀 비율과 반사·부유로 생명감 표현.

prompt.txt는 마지막 색 수정의 **실제 호출문**이며 처음부터 외형을 만든 독립 프롬프트가 아니다. 재개 시 approved.png를 외형 기준으로 반드시 함께 사용한다. 위 설명은 재사용 지침이며 과거 호출문으로 오인하지 않는다.

사용자 요청으로 이전 거울 프롬프트는 삭제했다. 이전 PNG는 보존한다. 현재 외형 prompt.txt와 ../desert-sun-mirror-motion-2026-10-16/prompt.txt가 유효한 실제 프롬프트다.

모션 순서: 윗줄 대기0·1·2 / 방어 / 준비0, 아랫줄 준비1 / 빛 공격0·1 / 피격 / 소멸. 외형 채택과 모션 시트 채택은 별도이며 게임 적용은 미완료.
