# 호루스 최신 채택 전투 18장

최종 사용자 지시: “이제 스프라이트 지랄은 끝이다 메인에 ㄱㄱㄱ”. 추가 생성 종료.

전투 전달은 이 최신 채택 묶음을 사용한다. 혼동을 막기 위해 이전 전투 12장이 들어 있던 구 18장 묶음과 더 오래된 17장 묶음은 삭제했다. 기존 첫 전투 6장은 [원본 채택 폴더](../horus-redraw-2026-10-14/README.md)에 그대로 보존한다.

- [개별 PNG 18장](png/): 좌우 각 9장(대기 3프레임, 공격 준비, 지상 찌르기, 공중 찌르기, 주문, 지침, 피격).
- [전체 미리보기](previews/all-18-contact.png), [18장 움짤](previews/all-18.gif), [좌우 동작 비교](previews/paired-actions.gif).
- [왼쪽 대기](previews/left-idle.gif), [오른쪽 대기](previews/right-idle.gif).
- [출처·채택 기록](manifest.json), [원본 파일](sources/).

좌우 지상 찌르기는 1000483187에 해당하는 생성 원본을 사용했다. 오른쪽 약한 피격은 채택한 후보 2번을 유지한다. 마지막 피격 재시도와 반려된 머리 수정본은 포함하지 않는다.

PNG는 생성 원본에서 원래 해상도로 분리하고 투명 여백 16px만 추가했다. 이전부터 분리되어 있던 왼쪽 5장은 기존 PNG를 보존했다. 모든 분리 영역은 원본과 픽셀 동일성을 검증했다. 원본에 포함된 가장자리 흔적은 재작화하지 않았다. 미리보기만 표시 크기와 발 기준선을 맞췄다.

main 아트 전달용이며 게임 런타임 적용 및 릴리스는 별도다. manifest 기준점은 전달 캔버스 기준이며 게임 좌표 설정이 아니다.
