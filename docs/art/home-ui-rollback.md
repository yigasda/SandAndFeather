# HOME 스킨 복구 검토

사용자 요청: 최근 HOME UI 교체를 전부 이전으로 되돌린다. HOME은 메뉴 팝업이 아니라 날짜·수치·목표·미니맵·메뉴/설정/가방·말 걸기·조이스틱이 놓인 실제 월드 화면이다.

## 원인과 기준

- 회귀는 `3b830b0b977b4a463cc234d12ca62bb854de8932`에서 cozy 공용 스킨 변수를 Lotus로 바꾸고 HOME 전용 스타일을 추가하며 발생했다. 이전 보고의 ‘세계 HUD 유지’는 배치/동작 보존과 시각 스킨 보존을 구분하지 못했다.
- 복구 기준은 바로 이전 main `2e8323ff3a4231bdc2b80f34b29ddab1f475d464`이다. 0.9.93의 세로 상태 정렬, 회전 대응, 날짜 중앙 정렬, 카메라 확대 유지와 중립 출입 수정이 포함된 기준이다.
- 후보는 main `35b8f3d4caf41c28878ab0e57818d345c5f299ce` 위의 별도 브랜치다. main/release 및 버전은 아직 바꾸지 않는다.

## 복구 범위

- HOME의 원래 cozy PNG, 9-slice 값과 밝기별 색 변수를 복구한다. PNG는 기준 Git blob을 그대로 복원하며 다시 그리거나 가공하지 않는다.
- 전체 창 테두리, 날짜/계절, 수치, 목표, 미니맵, 메뉴/설정/가방, 말 걸기, HOME 탐색 목록과 인연 새 문양, 접힌 창 칩, 등반 버튼, 전투 HUD/스킬 버튼, 디버그 안내/버튼의 Lotus 교체 스타일을 제거한다.
- Lotus 변수는 팝업 하위로 한정하고 기존 팝업 글자색을 명시해 이전 HOME 색/그림이 승인 메뉴로 새지 않게 한다. 승인된 가로 인연·일행·임무·지도, 세로 인연 배치, 보조 카드와 설정 화면의 Lotus 스타일은 보존한다.
- 움직임, 카메라, 저장, HUD JavaScript, 맵 데이터, 신규 연결, Lotus 원본/manifest/renderer는 변경하지 않는다.

## 검증 상태

- 정적 비교와 별도 격리 GitHub Actions 런타임 검증 대상으로 준비했다. HOME 테마 검사는 cozy도 원래 메뉴 PNG와 인연 새 마스크를 엄격하게 검사하도록 복구 범위에 맞췄다.
- 팝업 공통 버튼/입력 스타일은 `:where(.sf_pop_wrap)` 경계로 제한한다. 이 경계는 선택자 우선순위를 높이지 않아 승인 팝업의 기존 cascade를 유지한다.
- 런타임 전/후 HOME 캡처, 이전 기준 비교, 팝업 보존 및 입력/회전 검사는 별도 결과가 확인되기 전까지 완료로 간주하지 않는다.
