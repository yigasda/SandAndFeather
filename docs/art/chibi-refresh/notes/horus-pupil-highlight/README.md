# 호루스 동공 위 하이라이트 지우기 — 아스트라 손작업

호루스는 동공 위에 흰 하이라이트가 없다(최종 정지처럼 **아래 안광만**). 아래 그림들의 분홍 테두리 안 하이라이트만 지운다.

- **지우는 법:** 하이라이트 자리를 그 주변 홍채처럼 다시 칠한다. 동공 세로줄은 굵기·모양 그대로 눈꺼풀까지 이어지게, 홍채 금색은 그 높이의 명암대로. [눈 견본](../../palette/eyes.png)의 같은 방향 정지 눈을 옆에 놓고 맞춘다.
- **건드리지 않는 것:** 동공 모양, **아래 안광**, 눈꺼풀선, 흰자, 눈 아래 문양, 그 밖의 모든 픽셀. 분홍 테두리 밖은 픽셀 차이 0.
- **하지 말 것:** 흐리게 문지르기, 평균색으로 덮기(얼룩·링이 남는다), 동공을 옆으로 번지게 하기.
- 같은 파일 이름으로 그 폴더 `png/`에 덮어쓰지 말고 새 버전 폴더에 낸다. 전/후 확대본과 테두리 밖 픽셀 차이 0 확인을 같이 보낸다.
