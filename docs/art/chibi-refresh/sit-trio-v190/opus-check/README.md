# 190 앉기 14장 — 오푸스 확인 (0.9.41 게임 적용)

`sprite-review.py`로 14장을 돌렸다. 사용자가 구글 드라이브로 넘긴 파일이 main의 190과 같다고 확인해 줬다("190 그대로").

- 머리색 "조금 다름" 7장은 ΔE 3~6 범위(밝은 쪽이나 어두운 쪽 한 색만). 다름(6 넘음)은 없다.
- 머리 맞춤은 앉은 그림이라 일치도가 낮다. ×1.03~1.08은 채택된 쪼그린·앉은 그림과 같은 범위(183 확인 정정 참고). 소망 걸상 뒤 ×1.12는 183 확인 때 머리 폭 100%로 정상이었다.
- 게임 자리 시트: [`docs/consult/residence-096/0941-seats.png`](../../../../consult/residence-096/0941-seats.png) (`tools/st-test/seats.js` + `tools/art/fix/seat-sheet.py`).
- ASTRA-PLAN 2-1(호루스 동공 하이라이트 지우기)에 이 묶음 3장(왼쪽 바닥, 오른쪽 의자, 오른쪽 바닥)이 들어 있다. 고친 파일이 오면 manifest sha256을 바꾸고 다시 패킹한다.
