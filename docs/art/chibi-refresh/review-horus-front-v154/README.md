# 154 — 왼쪽 머리·귀 위 투명 구멍 수정

검토본. 153에서 사용자가 지적한 두 구멍만 수정. 정면 정지1장·걷기3장, 게임 미적용.

360×400 native 기준, 머리 안 구멍 `(92,160)` 3×1의3px와 귀 위 `(89,186)` 6×6 범위의14px가 실제로 남아 있었다. 작은 구멍 주변 검은 사각 테두리를 함께 정리하고, 귀 위 구멍에는 바로 위 기존 머리색을 이어 넣었다. 각 그림 변경54px, 수정 영역 밖 차이0. 해당 왼쪽 머리 범위의 내부 투명 연결성분0을 네 PNG에서 검사했다. 이는 전체 미술 품질 통과를 뜻하지 않는다.

`previews/154-left-before-after.png` 왼쪽153·오른쪽154. 사용자 지적 위치를8배 확대해 직접 비교했고 전체 어두운 배경도 확인했다. 얼굴·몸·머리 전체 크기/위치와 걷기 동작 변경 없음. 규격과 발 기준은153과 같고 `manifest.json`에 기록했다.
