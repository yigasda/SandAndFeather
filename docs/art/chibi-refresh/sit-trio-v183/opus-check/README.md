머리 맞춤 ×1.00 = 정지와 같은 크기, ×1.07 = 머리가 약 7% 작다. 앉은 그림은 일치도가 낮아(0.2~0.6) ±3% 정도는 오차로 본다.

- **호루스가 작아 보이는 이유:** 머리가 정지보다 3~8% 작게 그려졌고(다섯 장 모두 ×1.03~1.08, 세트·소망은 대부분 ×0.98~1.04), 무릎 꿇은 자세가 몸을 작게 모아서 같은 자리의 세트·소망보다 키가 7~13% 낮다. 머리를 정지 크기로 키우면(각 장의 배율만큼 앉은 자리 기준점을 중심으로 균등 확대) 거의 맞는다.
- **소망 방석 뒤 ×1.17, 걸상 뒤 ×1.12:** 뒷모습이라 측정이 흔들리지만 시트에서도 머리가 정지보다 좁아 보인다. 같이 볼 것.
