머리 맞춤 ×1.00 = 정지와 같은 크기, ×1.07 = 머리가 약 7% 작다. 앉은 그림은 일치도가 낮아(0.2~0.6) ±3% 정도는 오차로 본다.

- **정정(같은 날): 호루스 머리는 작지 않다.** ×1.03~1.08은 채택된 쪼그린 자세들(×1.03~1.11)과 같은 범위의 측정 오차이고, 머리 폭(위쪽 35% 최대 폭)은 정지와 같다(오른쪽 394/394, 왼쪽 392/392, 뒤 358/364, 긴 의자 383/393). 처음에 "3~8% 키워라"라고 한 것은 틀렸다. 호루스가 작아 보이는 것은 무릎 꿇은 자세가 몸을 작게 모아서다(같은 자리 키가 정지의 90~92%, 세트·소망은 95~106%). 키우려면 크기가 아니라 자세(허리를 더 세운 꿇어앉기)를 바꿔야 한다.
- **소망 방석 뒷모습:** 머리 맞춤 ×1.17, 머리 폭 88%로 둘 다 작게 나온다. 다만 채택된 소망 줍기 뒷모습도 머리 폭 85~88%라 뒷모습은 측정이 흔들린다. 걸상 뒷모습은 머리 폭 100%로 정상. 시트에서 눈으로 볼 것.
