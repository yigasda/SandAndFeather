# 호루스 정면 3안 — 원래3안 선택

2026-10-11. 사용자가 한 번에 하나씩 진행하기로 하고 호루스 시안 3개를 요청했다.

- 비교판: `horus-three-options.png`
- 1안: 얼굴 보정 폭을 작게 잡은 안.
- 2안: 승인 얼굴형에 가까워지도록 얼굴 폭과 높이를 조정한 안.
- 3안: 2안 방향에서 머리 외곽을 더 짧고 작게 잡은 안.
- 승인 `approved/idle/horus-front.png`, 현재 치비 v2 정면, 옛 치비의 짧은 머리 참고를 실제 이미지 편집 입력으로 사용했다.
- 승인 피부의 추출 HEX를 입력했다. 출력 색상의 픽셀 일치 또는 몸의 픽셀 동일은 검증하지 않았으며 확정 스프라이트가 아니다.
- 승인 48장과 게임 적용 파일은 수정하지 않았다. 소망과 맵 작업은 진행하지 않았다.
- 후속 사용자 지시로 원래3안 선택. 119번 추가 머리 수정은 반려.
