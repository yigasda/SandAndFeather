# 151 — 소망 뒤 정지 재작화·옷색 / 세트 최종 정면 GIF

사용자 요청에 따른 검토본. 게임 미적용. 150 소망 정면은 사용자가 “이게 훨씬 낫네”라고 확인했다. 이번 151 뒷모습과 색 수정은 아직 최종 채택 전이다.

## 요청과 기준

- 소망 뒤 정지는 사용자가 “걍 다시 그려”라고 명시했다. 재작화는 임의의 새 디자인을 허용한다는 뜻이 아니다. 최종 정면의 머리/몸 비율, 원피스 폭·길이, 짧은 다리, 신발 크기, 기존 뒷머리 특징과 도트 명암을 함께 기준으로 삼았다.
- 색 방향은 사용자 답변 그대로 **정면·뒷면을 걷기·좌우 원피스 색에 맞춘다.** 걷기와 좌우 PNG를 정면 색으로 바꾸지 않는다.
- 소망 정면: `../selected-front-idle-v150/somang-front.png`의 옷 영역만 색 조정. 원본 실루엣·알파·얼굴·머리·피부·신발 유지. 원본 옷 주색 (247,238,230)과 채택 정면 걷기 주색 (245,233,225)을 채취해 밝은 옷색에 RGB 차이를 적용. 외곽선까지 일괄 색조 변경하지 않음.
- 소망 뒷면: 위 최종 정면, `../review-trio-walk-v5/walk/somang-back-1.png`, 기존 좌측 정지를 이미지 편집 참조로 삼아 한 장으로 재작화. `sources/somang-back-generated.png` 보존. 완성 이미지 전체를 크기 정규화했으며 부위를 잘라 합성하지 않음. 몸·귀·머리 픽셀이 기존 파일과 동일하다는 뜻은 아니다.
- 세트 정면: `../review-trio-walk-v4/idle-reference/set-front.png` **파일 그대로 복사**. 사용자가 요청한 최종 정면 원본이다.
- 호루스 정면: 150 그대로. 걷기 36장과 좌우 정지는 변경하지 않음.

## 파일과 검사

`idle/` 정지 PNG 4장: 620×720, 발 기준 (310,662). 세트·소망 기준 키 628, 호루스 576. `native/`는 표시용 360×400, 기준 키 330, 발 (180,370). 정확한 입력과 해시는 `manifest.json`.

정면 소망은 알파 변경 0, 지정 옷 마스크 외 차이 0. 세트·호루스 전달본은 지정 원본 해시와 일치한다. 밝은/어두운 배경 전체 비교와 목·소매·치맛단·다리 확대판을 직접 확인했다. GIF는 원본 걷기 개별 PNG를 사용: 정지 1200ms → 0-1-2-1 두 번, 각 180ms. 게임 실행 검사는 하지 않았다.
