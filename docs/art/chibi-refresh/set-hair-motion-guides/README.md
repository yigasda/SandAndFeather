# 세트 머리 움직임 가이드

기존 전투 18장을 눈으로 확인하여 **머리 흐름만** 도식화했다. 구 전투 픽셀·윤곽·얼굴·몸 비율·색을 포함하지 않는다. 새 캐릭터 작화는 아직 하지 않았다.

- `png/`: 동작별 1600×720 투명 PNG 18장. 좌우 각 9장.
- `00_세트_머리흐름_18장.png`: 읽기용 전체판. 생성에는 해당 동작의 개별 PNG 사용.
- 파란 점선 2개: 몸 뒤에 놓이는 큰 머리 다발의 흐름. 앞으로 쏠려도 몸 앞 레이어로 옮긴다는 뜻이 아니다.
- 주황 실선 1개: 어깨 앞쪽 옆머리 흐름. 얼굴·손·무기는 가리지 않는다.
- 회색 십자: 흐름을 배치하기 위한 임시 기준점. 머리 중심·크기·윤곽의 측정값이 아니다.
- 화살표의 길이와 간격: 상대적인 움직임과 퍼짐 정도. 머리 길이·머리통 크기·실제 가닥 수로 사용하지 않는다.

## 생성 입력

1. 세트 원본 정지·걷기와 색·눈 견본: 외형, 긴 직모의 굵은 갈래, 길이, 비율, 색, 선, 명암 기준.
2. 오푸스 전신/머리 가이드: 원본 크기와 신체 비율. 동작에 맞춰 배치한다.
3. 해당 동작의 이 머리 흐름 가이드: 방향과 퍼짐·앞뒤 관계만.

**구 전투 시안·크롭·구 전투가 포함된 비교판은 생성 입력 금지.** 몸 동세·표정은 `ASTRA-PLAN.md`의 해당 표 그대로 따른다. 이 화살표로 몸 동작을 정하지 않는다.

전투 시안의 시각적 관찰을 정성적으로 옮긴 것으로 물리 시뮬레이션이나 윤곽 추적이 아니다. 좌우 시안을 각각 확인했고 좌우의 같은 흐름 관계는 화살표 좌표를 대칭 배치했다. 캐릭터 이미지를 반전한 것이 아니다. 새 동작의 실제 머리 위치에 맞춰 가이드를 이동·회전해 쓰되 머리 자체를 늘이거나 기존 전투 몸 비율을 복사하지 않는다.

검수: 원본 머리 크기·길이·갈래·명암 유지 → 방향/퍼짐 확인 → 얼굴·팔·무기와 앞뒤 관계 확인. 첫 결과가 원본과 다르면 묶음 생성을 계속하지 않고 해당 차이를 고친다.

재생성: `python tools/art/set-hair-motion-guide.py`. 곡선 좌표와 관찰 출처 해시는 `manifest.json`에 있다. 스크립트는 기존 전투 PNG를 읽거나 붙이지 않는다.
