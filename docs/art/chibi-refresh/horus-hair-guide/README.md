# 호루스 정면 머리 — 사용자 수정본 기준

2026-10-11, 오푸스가 만들었다. 사용자가 직접 수정한 호루스 정면 머리를 **정답 모양**으로 고정하고, 프레임마다 어디에 와야 하는지와 결과가 얼마나 맞는지를 숫자와 그림으로 보여준다. 그림은 그리지 않았다.

## 사용자 수정본

| 파일 | 내용 |
|---|---|
| `user-edit.jpg` | 사용자 정면 전체 수정본(675×801). 아스트라 153 `sources/user-edit.jpg`와 같은 파일 |
| `user-edit-left.jpg` | 사용자가 나중에 준 **왼쪽 머리 수정본**(482×1111) |
| `user-edit-combined.png` | 위 둘을 합친 **기준**. 왼쪽 수정본을 안 바뀐 귀·눈·팔에 맞춰 전체 수정본 위에 붙였다(배율 0.5175, 위치 48,86, 일치도 0.988, `combine.json`) |

**맞출 것.**
- 머리 바깥 외곽선: 가닥 끝, 꺾이는 지점, 폭, 높이.
- 이마선: 머리와 이마가 만나는 선.
- 왼쪽은 왼쪽 수정본을 따른다.

**맞추지 않을 것.**
- 폰으로 칠한 붓 자국과 색. 선과 명암은 호루스 원래 도트와 팔레트로 정리한다.
- 모양을 새로 디자인하지 않는다.

## 프레임마다 머리가 있어야 할 자리 — `targets/`

채택 걷기 정면 세 장(`review-trio-walk-v5/walk/horus-front-{0,1,2}.png`)에서 두 눈을 찾았다. 사용자 수정본의 두 눈이 그 자리에 오도록 옮겨서, 머리 윤곽을 프레임마다 다시 놓았다. **걷기 머리를 한 장 붙여넣지 말고, 프레임마다 이 자리에 맞춘다.**

| 파일 | 내용 |
|---|---|
| `walk-front-targets.png` | 프레임마다 빨간 선이 머리가 있어야 할 자리. 초록 점은 찾은 눈 |
| `walk-front-<0|1|2>-hair-mask.png` | 360×400 셀 좌표의 머리 실루엣. 바깥 검은 외곽선까지 포함한다 |
| `walk-front-<0|1|2>-hair-blue-mask.png` | 외곽선을 뺀 파란 머리 부분. 아래쪽 경계가 이마선이다 |
| `head-motion.md`, `.json` | 프레임별 머리 위치. 아래 표와 같다 |

| 프레임 | 두 눈 가운데 (x, y) | 1번 대비 이동 | 눈 사이 거리 | 수정본→프레임 배율 |
|---|---|---|---|---|
| 걷기 정면 0 | 171.4, 201.4 | −4.3, −0.2 | 62.0 | 0.4284 |
| 걷기 정면 1 | 175.8, 201.6 | 0, 0 | 62.3 | 0.4304 |
| 걷기 정면 2 | 175.5, 201.9 | −0.3, +0.3 | 60.8 | 0.4201 |

0번에서 머리가 왼쪽으로 4px 넘게 움직이고, 2번에서는 얼굴 폭이 조금 좁아진다(눈 사이 −1.5px). 머리도 그만큼 같이 움직이고 좁아져야 한다.

정지 정면은 사용자 지시대로 **예전 걷기 정면 몸**을 쓰고, 다리 길이만 조금 줄인다. 머리 자리는 그 몸으로 쓴 걷기 프레임의 줄을 쓴다. 걷기 다리, 신발, 치마는 바꾸지 않는다.

## 결과 검사

```
python3 tools/art/check-hair.py <후보.png> [<후보.png> ...] [--out <폴더>]
python3 tools/art/check-hair.py --targets      # targets/ 다시 만들기
```

후보마다 눈을 찾아 기준 머리를 겹치고 다음을 잰다.
- **바깥 외곽선**: 사용자 외곽선 위의 점마다, 후보 머리 외곽선까지의 거리.
- **이마선**: 사용자 이마선 위의 점마다, 후보 이마선까지의 거리.
- **모자람·넘침**: 사용자 머리에는 있는데 후보에 없는 픽셀(빨강), 후보에만 있는 픽셀(파랑).

**통과 기준.**
- 바깥 외곽선: 90% 이상이 2px 안, 최대 4px.
- 이마선: 85% 이상이 2px 안, 최대 5px.
- `<이름>-hair.png`에서 왼쪽은 후보 그대로, 오른쪽은 빨간 선(사용자 외곽선)과 모자람·넘침 칠이 보인다.

**지금 결과.**
- `check-156/`: 156 정지 정면은 이마선이 98% 맞는다.
- 바깥 외곽선은 91%가 2px 안이지만 최대 5px 어긋나 "다름"이다. 어긋난 곳은 비교 그림의 빨강·파랑 칠로 보인다.

**한계.**
- 눈의 금색으로 위치를 찾는다. 정면에서만 쓴다.
- 귀 윗선이 머리에 붙어 있으면 귀 옆에 파란 칠(넘침)이 조금 생길 수 있다. 비교 그림에서 귀 쪽 파랑은 무시해도 된다.
- 숫자를 통과해도 비교 그림을 직접 본다. 최종 판단은 사용자가 한다.
