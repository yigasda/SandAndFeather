# 새 동작 그리기 가이드 — 크기와 비율을 처음부터 맞추기

최종 정지 12장(`../final/`)으로 만든 밑그림 레이어다. **새 동작을 그리기 전에** 캐릭터·방향에 맞는 가이드를 아래에 깔고 그린다. 정지·걷기와 크기와 비율이 처음부터 같아진다.

## 파일

| 파일 | 내용 |
|---|---|
| `<캐릭터>-<방향>-guide.png` | 620×720 투명 레이어. 정지 그림을 흐리게 깔고, 그 윤곽은 빨간 선이다. 머리 위끝과 발끝(발 기준점)에 파란 가로선이 있다 |
| `guides-sheet.png` | 12장 한눈에 보기 |
| `guides.json` | 캔버스, 발 기준점, 키(px), 머리 위끝·발끝 위치 |

캔버스는 정지와 같다. 620×720, 발 기준점 (310, 662), 기준 키 576.

## 지킬 것

1. **머리는 흐린 정지 머리와 같은 크기, 같은 자리.** 머리 크기를 바꾸지 않는다. 고개를 숙이거나 돌리는 동작이면 머리 크기만 같게 한다.
2. **몸 길이는 정지와 같게.** 목, 어깨, 치맛단, 신발 위치를 흐린 정지에 맞춘다. 팔은 자세대로 움직여도 되지만, 팔 길이와 손 크기는 정지와 같게 한다.
3. **발은 발끝 파란 선 위에.** 서 있는 동작이면 발바닥이 이 선에 닿는다. 앉기·눕기처럼 발이 안 닿는 동작은 그 동작에 맞는 자리를 따로 정해 적는다.
4. 다 그리면 `python3 tools/art/fit-scale.py <그림>`으로 확인한다. "맞음"이 나와야 한다. "비율 다름"이면 몸 길이를 고친다.

다시 만들기: `python3 tools/art/pose-guide.py`
