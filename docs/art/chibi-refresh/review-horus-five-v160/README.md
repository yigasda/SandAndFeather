# 160 — 호루스 정면 귀·이마 시안5개 / 사용자 검토 대기

사용자가 159를 반려하고 검사 수치 대신 그림으로 고친5개 시안을 요청했다. 원래 머리 바깥 실루엣과 얼굴·몸을 고정하고, 귀/관자놀이 접합 및 이마 갈래를 새로 그린5안이다. 아직 채택본이 아니고 게임 미적용이다.

## 제작과 그림 확인

귀·이마를 이미지 편집으로 새로 그린 뒤 눈 위치로 정렬하고 해당 부위만 기존159 원본에 반영했다. 이마는 평균 높이만 맞추며 사용자 수정본의 거친 선을 따라 그리지 않았다. 귀와 머리 사이의 옛 빈틈을 그대로 보존하지 않고, 이어지는 귀·관자놀이 그림으로 교체했다. 처음 생성된4번의 긴 곱슬 앞머리는 범위를 벗어나므로 짧은 갈래로 다시 그렸다.

5개 전부 눈·눈썹·눈 아래 얼굴·턱·목·몸통·치마·다리·신발은 원본 픽셀이다. 귀와 이마 외의 캐릭터를 새로 생성한 그림으로 교체하지 않았다. 걷기 원본은 그대로 보존했다.

밝은 배경의5안 확대와 어두운 배경의 정면5장을 직접 봤다. 사용자 지시대로 check-hair/check-sprite 판정을 완성 근거로 쓰거나 수치를 맞추는 수정은 하지 않았다. 선택되지 않은 시안을 최종 목록에 넣지 않는다.

- `160-five-options.png`:1~5번 귀·이마 확대 합본.
- `160-option-1.png`~`160-option-5.png`:720×800 정면 개별 시안.
- `horus-front-option-1.png`~`horus-front-option-5.png`:360×400 투명 원본.
- `160-horus-five-options.zip`:합본과 개별5장, 투명 원본5장 묶음.
- `painted-options-source.png`, `painted-option4-source.png`:부분 편집을 위한 생성 원화. **이 원화의 얼굴·몸이나 전체 머리를 게임에 적용하지 않는다.**

5안은 이마 갈래의 크기·방향·배치와 귀 선 표현의 차이를 보기 위한 비교안이다. 사용자의 선택 후에만 정면걷기3장, 뒤정지1장, 뒤걷기3장 순서로 확대한다.
