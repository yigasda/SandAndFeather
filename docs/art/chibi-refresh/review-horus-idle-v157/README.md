# 157 — 호루스 정지 정면 1장, 사용자 확인 대기

최신 main의 `horus-hair-guide/README.md`와 `user-edit-final.jpg`, 정지 목표선을 기준으로 제작했다. 이전 사용자 도안은 사용하지 않았다. 정지 한 장을 먼저 제시하고, 사용자가 오케이한 뒤에만 정면 걷기3장을 진행한다. 게임 미적용.

- 바깥 머리 윤곽은 `idle-front-hair-mask.png`의 위치/크기를 사용. 색·명암은 채택 걷기 호루스의 원래 그림에서 가져왔으며 폰 그림의 RGB 픽셀은 붙이지 않았다.
- 이마는 목표 높이에 맞춰 갈래와 남청색 경계선, 머리 안쪽 그림자를 새로 정리했다.
- 귀는 목표 머리 실루엣 범위에서 둥근 윗선을 보이게 정리하고, 머리와 사이에 틈을 뒀다. 귀 색과 안쪽 명암은 원래 호루스 귀에서 가져왔다.
- 정지 다리320~328행(9px), 신발329~366행(38px). 치마 끝319·발바닥366 유지. 신발 높이를 늘렸으므로 sprite-check의 ‘신발 높이 다름’은 요청된 변경이다.
- 얼굴 보호 영역·턱·목·몸통·치마·발바닥 픽셀 차이0. 신발 높이는 변했으며 발바닥 위치는 그대로다. 걷기 PNG는 변경하지 않았다.

## 검증

`python3 tools/art/check-hair.py docs/art/chibi-refresh/review-horus-idle-v157/horus-idle-front.png`

**사용자 모양과 같음** — 바깥97%가2px 안, 최대2.8px. 이마86%가2px 안, 최대5.0px. 최신 검사 도구의 가장자리 검은 외곽선 **89%**(기준80%)도 통과. 바깥 검은 선을2px 두께로 다시 그리고 안쪽에 두 단계 도트 그림자를 넣었다. 검사 기준은 변경하지 않았다. 원본 비교 그림과 밝은/어두운 배경, 귀·이마 확대를 직접 확인했다. 수치 통과는 사용자 채택을 대신하지 않는다.

- `horus-idle-front.png`:360×400 투명 작업 원본.
- `157-horus-front.png`:정지 단독 확인용720×800.
- `157-hair-comparison.png`:검사 그림을 잘라 좌우로 배치한 확대 비교.
- `hair-check/`:요청 도구가 만든 원본 검사 그림·보고서.
- `validation.json`:보호 픽셀·몸 기준·채택 걷기 원본 해시.

**후속:** 승인 후 채택 걷기 원본0·1·2를 각자의 빨간 목표선에 맞춰 수정한다.0번의머리−4.3px이동,2번의폭변화를 각각 반영하며 몸·다리·신발·치마는 그대로 둔다. 정지 파일을 같은 좌표로3장에 붙이지 않는다. 최종4장에 check-hair를 함께 실행한다.
