# 직접 확인

- 같은 배율의 정지 비교 시트에서 얼굴 폭·볼·턱의 둥근 바닥, 귀, 눈썹 자리와 머리 크기를 보았다. 195는 몸 길이 기준으로만 사용했다.
- 세트는 몇 개의 굵은 생머리 다발과 넓은 붉은 하이라이트로 정리했다. 귀 앞 다발과 얼굴 옆 경계, 머리 끝을 밝고 어두운 배경에서 확인했다.
- 호루스는 남색 바탕과 파란 하이라이트를 유지하고 귀 밑 목이 드러나도록 했다. 머리 아래와 금 목걸이 사이 연결 및 정면 귀·턱 외곽선을 보았다.
- 정면은 무릎을 세우지 않고 다리를 아래로 뻗으며 작은 샌들 밑창이 보인다. 옆은 오른쪽을 보고 다리를 모아 굽힌다.
- Chromium에서800ms GIF를 실제31px와7배 확대하여 두 위상을 확인했다. 어깨·팔, 세트의 몸에 걸친 머리카락이 움직인다. 발 기준 위치를 유지했다.
- 0·1은 독립적으로 새로 그린 원화여서 머리 끝·치마 주름에 소규모 작화 차이가 있다. 픽셀 단위로 같은 얼굴·같은 발이라는 주장은 하지 않는다.
- 새 작화의 외형에 대한 사용자 채택은 아직 없다. 실제 게임 적용·충돌·침대 가림은 검증하지 않았다.

- 실제 세트 방·호루스 방 침대 그림 위에 같은 배율로 혼자/소망과 함께 배치했다. 얼굴과 몸이 서로 겹치지 않는 자리를 확인했다. 세트의 퍼진 머리는 왼쪽 베개 바깥까지 이어진다. 이불 가림은 생략한 구도 확인용이며 게임 배치 검증은 아니다.
