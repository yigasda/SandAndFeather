# 195 작업 범위 — 머리 전체 다시 그리기

사용자 지시: “머리카락 통째로 다시 그리라고”, “메인 문서 싹다 제대로 확인해서 읽어”. 기존 진행 승인을 이어서 작업한다.

- START → PLAN 전체 → SPRITE 전체 → MAP → HANDOFF, pose-guides, palette 표와 notes의 사용자 기준 그림을 다시 열었다.
- 세트 정면·옆면, 호루스 정면·옆면의 머리는 정수리부터 끝까지 새 원화로 그린다. 세트는 적은 수의 부드러운 큰 생머리 다발, 호루스는 두툼하고 짧은 남색 삐죽머리. 정지 조각을 가져오지 않는다.
- 정지와 같은 방향의 실제 팔레트를 사용하고, 호루스 얼굴·귀·팔의 분홍빛을 확인한다. 피부 기본색을 치마의 아이보리색에서 뽑지 않는다.
- 194에서 명암을 세 색으로 강하게 나눠 얼룩이 된 실수를 반복하지 않는다. 새로 그린 가닥의 연속적인 명암을 유지하고, 전체 머리·얼굴 크기와 짧은 몸 비율을 나란히 확인한다.

원본 PNG는 그대로 보존한다. 소망은 수정하지 않는다. 런타임 적용은 오푸스가 맡는다.
