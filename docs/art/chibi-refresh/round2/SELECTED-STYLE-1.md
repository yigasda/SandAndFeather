# 새 치비 1번 선택 — 앞머리·눈장식·풀어 내린 곱슬 수정

사용자는 round2 1번 그림체를 선택했다. 원 시안을 기준으로 국소 수정:

- 호루스: 기존 세 갈래 금색 눈장식을 아래로 내려오는 직선과 옆으로 나가 위로 말리는 선, 두 갈래로 단순화하고 전체 크기를 축소. 한쪽 눈만 장식.
- 소망: 가르마 앞머리를 가느다란 시스루뱅으로 수정.
- 추가 요청: 리본 쪽으로 모여 반묶음처럼 보이던 머리를 풀고 어깨 양옆으로 자연스럽게 곱슬을 내림. 리본은 옆 장식으로 유지.

현재 검토본은 [style-1-r2.png](style-1-r2.png), [Drive 미리보기](https://drive.google.com/file/d/14xg2xe9b6HCPdCTBi1nmii2pyHDCA0Pw/view). style-1-r1은 앞머리와 눈장식만 수정한 중간본이다. 원본과 중간본 모두 보존했다. 세트 및 의상·전체 그림체 재설계 요청은 없으며 후속 수정도 선택된 원본 기준의 최소 범위로 진행한다.

그림체 선택은 완료됐으나 이번 세부 수정 결과는 사용자 확인 전이다. 게임 방향별 프레임·실제 표시 크기·걷기 애니메이션은 별도 작업이다. 게임 코드와 기존 게임 자산은 변경하지 않았다.

## 세트 하의 후속 정정 — r4가 최신 검토본

사용자는 참고 그림에서 중앙의 긴 금장식과 끝의 술만 가져오도록 했다. 치마는 검은 발목 길이 이집트 복식이며 비대칭 치맛단·허리 보석·메달·체인은 제외한다. 후속 정정으로 한쪽 허벅지 트임 자체는 선호하고, 트임 안쪽 검은 속바지 표현을 빼달라고 했다. 따라서 긴 치맛단과 중앙 금장식은 유지하고 한쪽 트임으로 다리가 보이는 r4를 제작했다. 상체·얼굴·다른 두 캐릭터 재설계 요청은 없다.

- 최신 [style-1-r4.png](style-1-r4.png), [Drive](https://drive.google.com/file/d/1suEEhHU-6DhMeHMIPN0IkkMZdWSxEMhn/view).
- r3은 트임 없이 긴 치마로 만든 중간본으로 보존한다. [중간본 Drive](https://drive.google.com/file/d/1k8yoJyA9rYqNS2ULsiTwPcIiiEfLvl_z/view).
- 이번 수정 결과는 사용자 확인 전. 게임 스프라이트 파일과 코드는 변경하지 않았다.

## r5 — 차콜색 주름 명암과 얇은 금색 허리끈 복구

사용자는 r4의 치마가 지나치게 진하고 단순하다고 지적했다. 55번(r2) 시안에 있는 치마·허리끈의 채도와 명도를 기준으로 복원하도록 요청했다. 얇고 단순한 금색 허리끈은 복구 대상이며, 앞선 '허리 장식 제외'를 허리끈 제거로 해석하지 않는다. 보석·메달·체인 등 추가 허리 장식은 넣지 않는다.

최신 검토본은 [style-1-r5.png](style-1-r5.png), [Drive](https://drive.google.com/file/d/1v0iJPmRdSgtvTqe61st_jQiUsrMgo5Uc/view). 치마는 더 밝고 부드러운 차콜색에 주름 명암을 살렸고 금색 허리끈을 복구했다. 발목 길이·한쪽 트임·속바지 표시 없음·중앙 금장식과 술은 유지했다. 원 시안과의 픽셀 단위 색상 일치를 검증한 것은 아니며 사용자 시각 확인용이다. 기존 버전은 보관하고 게임에는 적용하지 않았다.

## r6 — 55번 원 시안으로 돌아가 최소 수정 (최신 지시 우선)

사용자는 r3~r5에서 바뀐 치마와 다리를 선호하지 않으며, 기존 시안에서 속바지만 빼고 금장식만 자연스럽고 작게 추가하도록 정정했다. 따라서 r5에 추가 수정을 하지 않고 55번인 style-1-r2.png를 직접 편집 대상으로 다시 사용했다. 기존 치마 패널·허리끈·트임·다리 형태를 기준으로, 트임 안 속바지 패치를 제거하고 앞 중앙에 가느다란 금색 줄과 작은 술을 추가했다. 앞선 길게 다시 만든 치마 구조를 후속 작업의 기준으로 사용하지 않는다.

최신 검토본: [style-1-r6-minimal.png](style-1-r6-minimal.png), [Drive](https://drive.google.com/file/d/1F-iKD4BC6VvotaFV0deRKh0Qf1fMs7Zf/view). 기존 r3~r5는 이력 보존용이다. r6 결과는 아직 사용자 확인 전이며 게임 적용·방향별 프레임 제작은 하지 않았다. 이미지 생성 편집 결과이므로 편집 영역 밖의 픽셀 동일성을 보장하지 않는다.
