## 사용자 최신 기준 (이미지의 오류보다 우선)

- 공통: 짧뚱한 치비, 게임에서의 표시 크기는 두아트 전투 비교본 정도. 셋소호 디자인 확인 전 두아트 후속 맵은 대기.
- 세트: 밝은 빨강이 아닌 다크 크림슨. 직모, 허리 바로 아래 길이. 이마 위로 솟은 머리가 아닌 차분히 내려오는 sidelocks. 마른 탄탄한 체형이지만 치비에는 근육선을 드러내지 않는 쪽이 좋음.
- 호루스: 세트보다 밝은 피부, 가르마 앞머리 없는 매우 짧은 머리. 가로로 길고 얇은 차분한 눈매, 화난 표정 아님. 날개 없음, 한쪽 눈장식.
- 소망: 반묶음이 아닌 가슴 길이의 풀어 내린 곱슬머리, 시스루 앞머리. 타레메와 약간 반쯤 감긴 눈, 다문 미소. 넓은 네모형 목선·가슴의 긴 리본·어깨를 덮는 풍성한 긴소매·나팔형 소맷단·허리선·길게 퍼지는 아이보리 드레스·별과 별자리 치맛단·갈색 스트랩 샌들. 리본이 있더라도 반묶음을 만들지 않음.

기존 시안·코드·게임 스프라이트는 유지. 새 이미지와 이 문서만 추가. 2~3번은 그림체 선택을 위한 일러스트 방식 시안이며 실제 작은 화면에 넣을 픽셀 변환/방향별 걷기 프레임은 아직 제작하지 않았다.
