# 164 — 셋소호 최종 정지12장 / 게임 전달용 투명PNG

사용자 지정: **세트148 네 방향, 소망151 네 방향, 호루스 최신 채택본**. 호루스 좌우 재작화는 사용자가 취소했으므로 기존148 좌우를 유지한다. 새 작화·부위 수정 없이 기존 원본을 모았다. 게임 파일은 수정하지 않았다.

## 바로 사용할 파일

- `idle/`: 투명RGBA PNG12장, 모두 **620×720**, 발 기준점 **(310,662)**, **referenceVisibleHeight=576**.
- `native/`: 투명360×400 원본12장. 발 기준점(180,370), referenceVisibleHeight330. 선택 원본과 바이트가 같다.
- `sheets/`: 캐릭터별 투명시트2480×720, 셀620×720. 순서 **뒤(상) → 앞(하) → 좌 → 우**.
- `manifest.json`: 개별 원본 경로·채택 버전·해시·방향·발 기준점.
- `164-trio-idle-12-png.zip`: 위 파일과 밝은/어두운 배경 미리보기.
