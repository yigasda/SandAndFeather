# 소망 상호작용172 — 4방향×2프레임 묶음 채택

171 정면 대표 프레임1은 사용자의 “개굿”으로 채택됐고 바이트 그대로 포함했다. 나머지7장을 같은 방향 정지·가이드와 채택 그림체로 제작했다. 이번 동작 명세의 대상은 소망만이며, 세트·호루스는 장면용 교환 동작을 만들 때 추가한다. 170은 미채택이다.

## 전달 파일

- `png/`: 투명RGBA620×720 PNG8장. `front/back/left/right`는 게임의 `down/up/left/right`에 해당한다.
- `manifest.json`: 파일 해시, 발 기준점(310,662), 기준 키576, 재생 명세.
- 재생은 프레임0(손 뻗기 시작)150ms → 프레임1(닿음)150ms → 같은 방향 정지. 한 번만 실행한다.
- `previews/somang-interaction-four-directions.gif`: 네 방향을 함께 보여 준다. 확인용으로 정지1200ms를 두고 동작을 반복한다.
- `previews/idle-interaction-walk-light.png`, `idle-interaction-walk-dark.png`: 방향마다 최종 정지, 동작0·1, 최종 걷기0·1·2를 나란히 배치했다. 걷기360×400은 기준 키330→576, 발 기준점(180,370)→(310,662)에 맞춰 비교용으로만 확대했다.

## 제작·확인

같은 방향 `../pose-guides/somang-<방향>-guide.png`와 `../final/somang/idle/`의 실제 PNG를 생성 편집 참조로 사용했다. 왼쪽·오른쪽은 별도로 그렸고 뒤집지 않았다. 손을 뻗는 오른팔과 몸 옆의 다른 팔을 방향에 맞게 가렸다. 무릎을 편 서기이며 효과·물체는 포함하지 않았다.

생성 원본은 `sources/`에 보관했다.620×720으로 균등 정규화하고 알파8/255 이하 생성 잔여값을 제거한 뒤 `fit-scale.py`로 정렬했다. 머리를 따로 축소하거나 수치로 팔다리를 늘이지 않았다. 오른쪽 닿음 프레임은 최종 재검사에서 몸 길이 차이가 발견돼 생성 편집으로 몸을 짧게 다시 그렸다.

`checks/delivery-summary.json`은 전달PNG8장을 다시 입력한 결과다. 전체8장에서 “맞음”을 확인했다. 재검사 도구의 출력은 검사용이며, 이미 채택된171을 반복 보정하지 않았다. `*-height.png` 등 도구가 만든 대안은 전달 스프라이트가 아니다.

밝은 배경의 전체 비교, 어두운 배경의 목·소매·손목·치마·다리·신발 연결 확대, 재생GIF의 모든 프레임을 직접 확인했다. 머리와 발의 크기·자리, 팔의 진행 방향, 여분 손, 끊어진 접합과 눈에 띄는 흰 테두리를 함께 봤다. 뒷모습은 오른손이 머리 옆에서 위로 올라가며, 옆모습은 손이 진행 방향으로 뻗는다.

`check-sprite.py --pose free`의 팔레트·외곽선·머리 비율 등은 같은 범위다. 반투명 픽셀 수 차이 판정은 남아 있다. 오른쪽 닿음의 최종 보조검사 결과는 `checks/sprite-right-1-fixed/`에 있다. 이 보조검사의 전체 통과나 원본과 픽셀 동일을 주장하지 않는다. 실제 밝고 어두운 배경의 표시를 별도로 확인했다.

기존 최종 베이스48장과171 대표의 해시는 유지했다.172 묶음은 사용자 “합격!!!”으로 채택됐다. 게임 런타임 적용은 별도다.

재검사 예: `python3 tools/art/fit-scale.py docs/art/chibi-refresh/interaction-somang-v172/png/somang-back-1.png --who somang --view back --out /tmp/interaction172-back1`
