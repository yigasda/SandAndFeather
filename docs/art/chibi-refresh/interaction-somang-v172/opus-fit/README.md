# 172 소망 상호작용 — 오푸스 fit-scale 확인

`tools/art/fit-scale.py`로 전달 PNG 8장을 다시 돌렸다. `fit-all.png`는 장마다 정지 / 머리 맞춤 / 키 맞춤(빨강 = 정지 윤곽).

| 장 | 판정 | 배율 | 키를 맞추면 머리 크기 |
|---|---|---|---|
| front-0 | 맞음 (발 +7px 보정) | ×1.0025 | 99% |
| front-1 | 맞음 (발 +3px 보정) | ×1.005 | 99% |
| back-0 | 맞음 (발 +3px 보정) | ×1.005 | 99% |
| back-1 | 맞음 (발 +8px 보정) | ×1.0 | 98% |
| left-0 | 맞음 (발 +5px 보정) | ×0.9975 | 99% |
| left-1 | 맞음 (발 +6px 보정) | ×1.0 | 99% |
| right-0 | 맞음 (발 +12px 보정) | ×1.0 | 98% |
| right-1 | 맞음 (발 -1px 보정) | ×0.995 | 100% |

8장 모두 "맞음". 배율은 0.995~1.005로 정지와 같은 크기다. 오른쪽 0은 머리를 맞추면 발이 12px(기준 끝) 아래라 몸이 정지보다 약 2% 길다. 눈으로는 차이가 거의 안 보인다.
