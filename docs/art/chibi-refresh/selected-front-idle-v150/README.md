# 150 — 사용자 지정 정면 정지3장과 기존 걷기 GIF

사용자 지시: “최종시안 소망을 정면 정지로 쓰고 호루스랑 세트는 아까 만든걸로 gif 줘봐. 수정할 거 없으니까 빨리”.

그림을 새로 그리거나 부분 수정하지 않았다. 아래 원본을 파일 그대로 복사했다.

| 캐릭터 | 실제 입력 | 기준 키 |
|---|---|---|
| 소망 | `../review-trio-walk-v4/idle-reference/somang-front.png` — 사용자가 올린 최종 시안 |628|
| 세트 | `../review-trio-idle-v1/idle/set-front.png` —148 정면 |576|
| 호루스 | `../review-trio-idle-v1/idle/horus-front.png` —148 정면(146 복구+다리 간격) |576|

세 전달 PNG는620×720, 발 기준(310,662). 원본과 복사본 해시가 같다.149 소망은 사용하지 않는다.

`150-trio-front-idle-walk.gif`:세 명 정면을 나란히 표시. 정지1200ms → 기존 채택 걷기0→1→2→1 두 번(각180ms). 소망은 GIF 표시에서만 기준 키330으로 등비 축소한다. 세트·호루스는148의360×400 native를 사용한다. 발 기준은 동일한(180,370). 호루스 기존 걷기 셀 오프셋도 유지한다. 걷기는 개별 PNG에서 읽었으며 GIF에서 추출하거나 다시 그리지 않았다.

`150-selected-front-idle.png`:GIF 첫 정지 화면.
`manifest.json`:원본 경로·해시·기준 키·재생 순서.

정면3장에 대한 사용자 선택이다. 다른 방향9장의 전체 채택이나 게임 적용을 의미하지 않는다. 게임 미적용.

현재 시안 작업 원칙은 [상위 시안 문서](../README.md)의 ‘시안 수정 지침’을 따른다. 단어 하나에 집착해서 채택 시안의 전체 비율·그림체를 바꾸지 않는다.
