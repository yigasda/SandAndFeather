# 스프라이트 검사 — 채택 시안과 몸·그림체가 같은지

2026-10-11, 오푸스가 만들었다. 후보 그림을 **채택 시안**과 같은 키로 맞춰 놓고 비교한다. 정지, 걷기, 다른 바리에이션 모두에 쓴다. 사용자에게 보내기 전에 먼저 돌린다.

**왜 만들었나.** 149번에서 "목·다리"를 고치다가 목이 막대처럼 길어지고, 다리는 곧은 기둥이 되고, 신발은 작아졌다. 이 도구로 돌리면 그런 결과는 숫자로 바로 "다름"이 나온다. [example-149](example-149/report.md)가 그 예시다.

## 실행

```
# 한 장
python3 tools/art/check-sprite.py --ref <채택 시안.png> --cand <후보.png> [--pose same|walk|free]

# 폴더째. 파일 이름 <캐릭터>-<방향>으로 짝을 짓는다. 걷기 <캐릭터>-<방향>-<0|1|2>.png는 같은 방향 정지와 비교한다.
python3 tools/art/check-sprite.py --ref-dir <채택 정지 폴더> --cand-dir <후보 폴더>
```

결과는 `<후보 폴더>/sprite-check/`에 생긴다. `report.md`와 `report.json`, 그리고 그림마다 `<이름>-check.png`가 하나씩 나온다.

**`--pose`는 기준과 자세가 얼마나 같은지다.**

| 값 | 언제 | 판정하는 것 |
|---|---|---|
| `same` | 기준과 같이 서 있는 그림. 한 장 비교의 기본값 | 전부 |
| `walk` | 걷기 프레임. 폴더 비교에서 `-0/1/2` 파일의 기본값 | 머리, 얼굴, 머리카락, 목, 외곽선, 색, 틈. 다리, 치맛단, 신발은 움직이니까 판정하지 않는다 |
| `free` | 앉기, 눕기, 다른 동작 | 머리, 얼굴, 머리카락, 외곽선, 색, 틈 |

## 재는 것

길이는 모두 그림 키에 대한 비율(%H)로 잰다. 그래서 두 그림의 크기가 달라도 된다.

| 항목 | 허용 차이 |
|---|---|
| 머리 높이 (위끝→턱) | 4%H |
| 얼굴 폭 | 3%H |
| 머리카락 폭 | 6%H |
| **보이는 목 길이**: 턱 밑 외곽선 아래로 보이는 좁은 피부 기둥 (옷깃 안쪽 넓은 살은 제외) | 0.8%H |
| 목 폭 (목이 보일 때만) | 2%H |
| 치맛단 높이 (위끝→치맛단) | 3%H |
| **치마 아래 다리 길이** | 2%H |
| 다리 한 쪽 폭 | 1.2%H |
| **신발 높이**, **신발 한 짝 폭** | 1.5%H, 2.5%H |
| 치맛단 폭 (옆에 붙은 손도 같이 잰다) | 8%H |
| 바깥 외곽선 두께 | 0.6%H |
| 머리카락, 피부, 옷, 신발, 외곽선 색 | ΔE 12 |
| 합성 틈: 몸 안의 가는 투명 줄. 둘레에 외곽선이 그려진 틈(팔과 몸 사이, 머리 가닥 뒤)은 그림이라 제외 | 있으면 실패. 좌표가 리포트에 나온다 |
| 몸 안 반투명 픽셀, 가장자리 흰 후광 | 기준보다 많으면 실패 |

## 비교 그림 읽는 법

`<이름>-check.png`는 다섯 칸이다.
1. **기준**: 잰 선이 표시돼 있다. 위끝, 턱, 목 끝, 치맛단, 신발 위, 발끝.
2. **후보**: 기준과 같은 키, 같은 선.
3. **어두운 바탕**: 기준과 후보.
4. **후보 위에 기준 윤곽(빨강)**: 발을 맞춰 겹쳤다. 몸이 어디서 길어지고 좁아졌는지 바로 보인다.
5. **목, 다리·신발 2배 확대**: 기준과 후보를 위아래로.

## 아스트라 사용법

1. 기준은 **사용자가 채택한 시안 파일**로 한다. 최신 수정본이 아니다. 지금 기준은 다음과 같다.
   - 정면 정지: [selected-front-idle-v150](../selected-front-idle-v150/)
   - 정면 최종 시안 원본: [review-trio-walk-v4/idle-reference](../review-trio-walk-v4/idle-reference/)
   - 걷기: [review-trio-walk-v5/walk](../review-trio-walk-v5/walk/)
2. 보내기 전에 돌린다. "다름"이 나오면 그 항목이 의도한 변경인지 본다.
   - 의도하지 않은 변경이면 고친다.
   - 의도한 변경(사용자가 바꾸라고 한 부위)이면 보고할 때 그 항목과 이유를 적는다.
3. 리포트와 비교 그림을 결과와 함께 보낸다.

**한계.**
- 부위는 색으로 찾는다. 피부는 복숭아색, 신발은 진한 갈색, 머리카락은 캐릭터별 색(파일 이름의 `set`, `somang`, `horus`로 고른다), 외곽선은 아주 어두운 색이다.
- 새 캐릭터처럼 색이 크게 다르면 `parts()`의 색 범위를 고쳐야 한다.
- 도트 크기는 재지 않는다. 확대 칸에서 눈으로 본다.
- 숫자를 통과했다고 완료가 아니다. 숫자는 큰 실수를 잡는 그물이다. 비교 그림을 직접 보고, 최종 판단은 사용자가 한다.
