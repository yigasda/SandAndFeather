# 잠들기187 — 바로 눕기 수정 + 마주 보는 옆잠

사용자 검토 대기. PNG10장 = 수정·추가9장 + 바이트 동일한 소망180 프레임0. 기존184는 반려·대체본이며 사용하지 않는다. 게임 적용은 오푸스.

- 혼자: 셋 각2장, `<누구>-sleep-0/1.png`. 세트 화면 오른쪽 팔을 내림. 호루스 두 손은 배 위. 소망0은 원본 보존.
- 같이: 세트·호루스 각2장, `<누구>-sleep-side-0/1.png`. 화면 오른쪽을 봄. 소망은 오른쪽 베개에서 기존180처럼 왼쪽을 봄. 좌우 반전으로 만들지 않았다.
- 620×720 투명RGBA, 0=날숨,1=들숨,800ms씩 반복. 배 기준점은 manifest 파일별 body-center. 앉기183/186은 이미main에 있으며 이번에도 변경하지 않았다.

## 그림 확인

소망180과 같은 배율로 누운 기울기·짧아진 몸과 발을 비교했다. 발은 바닥에 세우지 않고 침대 평면에 옆으로 놓였다. 세트는 한 팔을 내리고, 호루스는 손을 배 위에 유지한다. 옆잠에서는 얼굴이 소망 쪽을 보고 손과 다리가 몸 앞에 모인다. 머리·목·팔·치마·발 연결을 밝고 어두운 배경에서 확대해 봤다.

들숨에서 가슴·어깨·팔 및 걸친 머리카락이 최대8px 위로 움직이고 몸통 폭이 조금 늘어난다. 머리는1px만 움직이며 감은 눈 그림은 같다. 베개 쪽 퍼진 머리와 발은 고정. 31px 정지 배율(31/576)의 실제 GIF 프레임을 비교하고 확대판도 제공한다. GIF는 두 프레임이 같은 팔레트를 써 색상표 차이가 호흡처럼 보이지 않게 했다.

실제 두 방 침대에 동일 배율160/576로 혼자·둘을 올렸다. 같이 자기 두 프레임 모두 불투명 픽셀 겹침0. 시트는 이불 가림 전이며 캐릭터PNG에는 침대·이불·효과를 넣지 않았다.

## 검사 해석

피부10장 모두 `skin-check.py` 같음. `action-check.py`는 잠들기 파일명을 인식하지 않아 동일한 PNG를 front/right 이름으로 검사했다(바이트 일치 mapping 포함). 세트·호루스 누운 머리는 x2 이상으로 대상을 잘못 잡아 측정불가. 채택 소망180도 x1.25로 나오므로 원본을 줄이거나 키우지 않았다. 요청대로 정지 정면과 같은 배율로 나란히 놓은 비교 시트로 머리를 확인했다. `0이 끝과 같음`은 쪼그리기 단계 기준 경고이며 호흡0·1은 모두 누운 자세다. 검사 수치를 완성 근거로 쓰지 않는다.

주요 파일: `previews/sleep-187-all-light.png`, `sleep-187-breathing.gif`, `sleep-187-game-31px.gif`, `sleep-187-game-31px-8x.gif`, `bed-alone.png`, `bed-together.png`. 배치·피부·눈·호흡 변화의 수치와 원본은 checks에 보관했다.
