# 호루스 상호작용177 — 좌우 수정, 확인 대기

176 묶음에 대한 사용자 후속 수정 요청을 반영했다. 오른쪽0·1은 기존 피부색·톤에 맞추고, 왼쪽0·1은 앞쪽 배와 치마의 끊긴 외곽선을 복구했다. 정면·뒷면4장은 바이트 동일하다. 채택·게임 적용은 아직 별도 확인 대기다.

## 전달 파일

- `png/horus-{front,back,left,right}-{0,1}.png`: 투명 RGBA 8장,620×720. 발 기준점(310,662), 기준 키576.

- `177-horus-interaction-8png.zip`: PNG8장·manifest·비교 시트·GIF.
- `previews/177-correction-comparison.png`: 수정 전후4장, 왼쪽 외곽선 확대, 오른쪽 원본 피부 비교.
- `previews/horus-interaction-four-directions.gif`: 정지1200ms→시작150ms→닿음150ms 반복 확인용.
- `previews/idle-interaction-walk-{light,dark}.png`: 정지 / 동작0·1 / 걷기0·1·2. 걷기는 표시할 때만 키330→576에 맞췄다.

## 수정 범위와 검수

베이스는 `../final/horus/`의168 피부·173 비율이 이미 반영된 채택본이다.173 비율을 다시 적용하지 않았다.176에서 놓쳤던 피부 톤 차이와 배 앞쪽 선 단절을 이번에 수정했다.

오른쪽 두 장은 피부를 선택해 얼굴과 몸을 별도로 원본 색에 맞추고, 원본에서 추출한 피부 RGB 팔레트로 대응했다. 몸 기본색은(252,228,223)이며 그림자·볼·귀의 단계도 함께 보정했다. 알파 및 선택 피부 밖의 픽셀 변화는0이다. `checks/revision177-skin.json`, `sources/revision177/right*-skinmask.png`에 근거를 남겼다.

왼쪽은 팔 아래부터 치마까지 외곽선을 국소 재작화했다. 선 밖의 잔여 점도 제거했다. 변경 범위는 외곽선 마스크와 기존 독립된 갈색1픽셀(217,526)이며, 나머지 영역 픽셀 변화는0이다. `checks/revision177-diff.json` 참조.

수정4장에 `fit-scale.py`를 다시 실행해 모두 **맞음**을 확인했다. 정면·뒷면의 기존 검사와 합친8장 결과는 `checks/delivery-summary.json`에 있다. 검사 도구의 별도 정렬 출력으로 납품PNG를 덮어쓰지 않았다. 보조 `check-sprite.py`도 수정4장 모두 같은 범위다.

밝은·어두운 배경의 전체 비교, 배→허리→치마 외곽선 확대, 오른쪽 원본과 피부 비교, 실제GIF의 정지·시작·닿음 프레임을 직접 확인했다. 팔 모양과 길이, 머리·얼굴·발 위치를 함께 비교했다. 최종 베이스48장과 런타임은 변경하지 않았다.
