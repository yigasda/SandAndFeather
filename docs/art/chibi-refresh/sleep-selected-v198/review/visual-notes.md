# 직접 확인

- 정지 옆과195·198을 같은 배율로 놓고 호루스 볼·턱·등·치마 끝의 선을 보았다. 바깥 선이 끊기지 않고 두꺼운 테두리 띠로 과장되지 않는지 확대 시트와 전체 시트로 확인했다.
- 호루스 차이 그림에서 빨간 픽셀이 외곽 띠에만 있다. 머리 하이라이트, 얼굴 안쪽, 피부·치마 명암, 숨쉬기 두 프레임의 자세는 원본 그대로다.
- 세트는197 정면의 큰 귀 뒤 팔 굽힘을 안쪽·아래쪽으로 당겼다. 귀 아래에 짧은 팔과 금 팔찌가 보이며, 귀·얼굴·앞머리·어깨·가슴·하체는 원본 그대로다. 변경부는76×94px 범위 안에 제한했다.
- 밝은·어두운 배경에서 팔 주변의 머리 연결과 외곽을 보았다. 정지와 같은 배율로 놓고 기존에 멀리 튀어나온 팔꿈치가 줄어든 것을 확인했다.
- 호루스 정면197 두 장과 세트 옆195 두 장은 원본 바이트 그대로이고, 채택 상태를 유지했다. 수정한 나머지4장은 검토 대기다.
- 실제 게임 배치·충돌·침대 가림은 확인하지 않았고 런타임에는 적용하지 않았다.
