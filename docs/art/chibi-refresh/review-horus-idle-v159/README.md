# 159 — 호루스 정면 귀·이마 수정본 / 사용자 검토 대기

2026-10-11.158은 사용자 반려이며, 이 파일은 새 정면 검토본이다. 게임 미적용. 걷기 원본은 변경하지 않았다.

## 그림에서 고친 것

- 귀 윗부분·바깥·아래의 곡선을 각각 연결하고, 위쪽은 가늘고 외측과 아래는 굵은 선으로 다시 그렸다. 귀 피부와 안쪽 명암은 채택 걷기 원본의 팔레트·픽셀에서 가져왔다.
- 이마는 사용자 수정본의 높이만 참고했다. 갈래 모양은 짧고 두툼한 헤어 흐름에 맞춰 새로 디자인했고, 남청색 끝선과 단계형 도트 명암을 넣었다. 사용자 이마선이나 폰 그림 RGB를 붙이지 않았다.
- 머리 바깥 실루엣은 유지하면서 숯색 선과 안쪽 남청색 그림자를 정리했다.
- 얼굴 아래·턱·목·몸·다리·신발은157과 픽셀 그대로다.

전체 전후 비교, 귀·이마 확대, 밝고 어두운 배경을 직접 봤다. 귀 선과 이마 디자인의 최종 채택은 사용자 판단을 기다린다.

## 검증과 남은 제한

요청한 최신 check-hair를 그대로 실행했다. **전체 통과 아님: ‘머리 외곽선 얇음’ 항목이 남아 있다.** 이를 통과했다고 보고하지 않는다. 다른 위치·높이·귀 항목은 기준 안이다. 외곽선 굵기 수치는 후보와 사용자 그림에서 집계되는 경계 픽셀 수가 다르며, 수치를 완성도의 근거로 쓰지 않는다. 도구나 통과 기준은 변경하지 않았다.
