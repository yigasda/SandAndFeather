# 호루스 비율173 — 16장 확인용

사용자 요청: 머리를 조금 키우고 몸통을 세트처럼 조금 줄이기. 정지4장·걷기12장 모두 기존 최종168 파일에서 비율만 수정했다. 생성·재작화·색 변경은 없다.

- 머리(머리카락·얼굴·귀 포함): 가로·세로104%.
- 몸통: 폭96%, 목에서 치맛단까지 길이94%. 목걸이와 치맛단 안쪽에서 폭 변형을 연속적으로 연결한다.
- 치맛단 아래 다리·신발은 보이는 픽셀과 알파 모두 원본 동일. 발 위치, 캔버스, 기준 키는 유지한다.
- 한 장의 머리를 다른 프레임에 붙이지 않는다. 각 프레임의 원본 머리·표정·몸 동세에 같은 비율 변환을 적용한다.
- 최근접 픽셀 참조로 기존 팔레트를 유지한다. 그림 밖 완전투명 픽셀의 숨은RGB만0으로 정리한다.

`horus/idle/`4장, `horus/walk/`12장이 게임용 투명PNG다. 정지620×720·발(310,662)·기준 키576, 걷기360×400·발(180,370)·기준 키330. 걷기0→1→2→1,180ms이며 기존 정면 위치 보정도 manifest에 포함했다.173은 사용자 확인 대기이며 기존 `final/`48장은 아직 변경하지 않았다.

## 확인

`previews/trio-idle-comparison-light.png`의 열 순서는 세트 / 호루스 이전 / 호루스 수정 / 소망이다. 네 방향 정지와 걷기도 같은 열 순서로 GIF에 함께 들어 있다. 밝은·어두운 배경의16장 시트와 목·어깨 연결 확대를 직접 확인했다.

`checks/preservation.json`:16장 모두 새 색0, 다리·신발 픽셀 보존, 최종48장 해시 유지. `checks/idle/`는4장 모두 기준과 같은 범위. 정지 기준과 비교한 걷기검사에서는 왼쪽0·2의 얼굴 폭 차이가 남으며, 이번 머리 확대와 해당 프레임의 측면 모양을 함께 반영한 수치다. `walk-check/`의 뒤·좌·우 동세는 같은 범위. 정면2 머리카락 아래끝 검출값은 달라졌으나 실제 머리는 각 원본 프레임 전체를104%로 변환한 것이다. 검사 전체 통과로 표현하지 않고 실제16장과 목 연결 확대를 함께 확인했다.

이번 요청은 베이스 비율 자체 변경이다. 이전 머리 크기로 되돌려 맞추는 `fit-scale.py`는 적용하지 않았다. 재현: 저장소 루트에서 `python3 docs/art/chibi-refresh/horus-proportion-v173/build.py`.
