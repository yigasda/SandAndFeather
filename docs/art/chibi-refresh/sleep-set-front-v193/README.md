# 세트 잠들기 정면193 — 머리 전체 재작화 2장

사용자: “옆모습은 채택”, “머리카락이 걷기랑 정지 느낌이랑 달라 / 너무 세세해 날카로워졌고”, “정면 머리카락 다시 그리란 말임 싹다”.

정면0·1의 머리카락을 정수리부터 끝까지 새로 그렸다. 가는 선·잔갈래를 줄이고 정지·걷기처럼 큰 다발과 넓은 명암으로 바꿨다. 잠자리 위로 퍼지는 방향은 유지했다. 같은192프레임의 얼굴·몸을 보존한 머리 한정 수정이며 정지 조각을 붙이지 않았다. 새 머리의 등록·마스크 경계는 확대 확인하고 작은 알파 틈을 정리했다.
