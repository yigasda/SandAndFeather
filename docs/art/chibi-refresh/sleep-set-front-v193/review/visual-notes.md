# 직접 본 내용

정지·걷기 정면과 같은 배율로 나란히 놓았다. 192의 가늘고 긴 깃털 같은 갈래와 여러 겹의 가는 내부 선 대신, 193은 굵은 묶음 몇 개와 넓은 자주색 그림자·붉은 하이라이트 면으로 바뀌었다. 넓게 퍼진 누운 흐름과 왼쪽 비대칭 잔머리 고리는 남겼다. 귀 앞 큰 다발은 정수리부터 아래까지 이어진다.

얼굴·귀·목걸이·팔 접합은 전후 확대, 밝은/어두운 배경으로 봤다. 새 머리 등록 때 생긴 작은 알파 틈과 한 점을 정리했다. 두 장 모두 연결된 불투명 성분 하나이고 캔버스 밖으로 잘리지 않는다. 정지 머리 조각을 붙이지 않았으며, 원래192의 같은 프레임 얼굴·몸을 마스크로 보존했다. 보존 마스크의81,614/81,475픽셀은 차이0이다.

검사에서 피부색 두 장 모두 같음, 볼 것0. 이는 시각적 완성 판정과 별개다. 31px와 큰 재생본에서 192의 들숨 팔·어깨 움직임이 유지되고 머리 끝도 바뀌는 것을 프레임별로 확인했다. 정지/걷기 머리와 동일 픽셀은 아니며 잠자리 위로 펼쳐져 외곽 폭은 더 넓다. 이번에는 머리의 세부 밀도·끝 모양만 수정했으므로192에 원래 있던 두 프레임 사이 발·눈선의 차이는 그대로다.

채택된 옆모습192두 장은 SHA256가 원본과 같다.
