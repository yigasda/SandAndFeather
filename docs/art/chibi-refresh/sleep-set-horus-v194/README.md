# 세트·호루스 잠들기 194 — 사용자 반려

**반려:** 머리의 하이라이트·명암이 얼룩처럼 뭉개지고, 호루스 피부색과 얼굴 윤곽이 기준과 달랐다. 적용 대상이 아니다. 후속 재작화는 [195](../sleep-set-horus-v195/README.md).

세트 정면193·옆192, 호루스 정면·옆191을 기준으로 수정한 8장. 620×720 투명 PNG, 날숨0·들숨1, 각 800ms 반복. 사용자 채택 전이며 런타임 적용 대상은 아니다. 기존본·소망은 그대로 보존했다.

정면 몸 가운데 기준점은 (310,450), 옆은 (315,445). 머리 조각을 정지에서 가져오지 않고 새로 그렸다. 새로 그린 날숨 원화의 머리 부분을 확대·축소하지 않고, 턱 아래를 연속적인 세로 좌표 변환으로 줄였다. 머리 명암은 사용자 요청대로 같은 방향 정지의 실제 세 색으로 정리했다. 피부는 해당 방향 최종 정지·걷기 팔레트로 맞췄다.

들숨은 새로 생성한 동작 연구를 참고하되 얼굴·발의 재생 흔들림을 피하도록 이번 날숨 그림에서 연속 변형으로 만들었다. 어깨·가슴·팔과 그 위 머리 끝을 위로 최대8px, 머리를1px 움직였으며 하체는 고정했다. 바깥선도 실제로 달라진다. `sources/*-inhale-study.png`는 연구용이며 게임용 프레임은 `png/`의8장만이다. 과정은 `process/`에 기록했다.

**머리 숫자 주의:** 정면은 세트×0.97, 호루스×0.99. 옆은 세트×0.86, 호루스×0.92로, 전부×1.00이라고 보고하지 않는다. 같은 검사에서 기존192 세트 옆은×0.84, 기존191 호루스 옆은×0.94였다. 이번 사용자 지시가 현재 머리 크기를 바꾸지 말라는 것이므로 검사값에 맞춰 머리를 일괄 확대하지 않았다. 세트 옆의 별도 머리 검사에는 `머리 작음`이 남는다. 통합 검토의 `볼 것0`은 이 별도 판정을 집계하지 않으므로 완성 근거로 삼지 않는다. 비교 그림과 원래 크기 보존 여부를 함께 검토한다.

몸 길이는 실제 PNG의 턱·치마단·발끝에 선을 그어 잰 세로 투영 길이이며 곡선 경계 선택 오차는 약±2px다. 세트에는 자기 정지 대비와 호루스 정지 대비를 모두 적었다. 옆으로 접은 다리를 폈을 때의 해부학적 길이와는 다르다.
