# 작업 확인서 — 사용자 승인 반영

사용자 승인: “OK, 이대로 진행해. 호루스는 191이 최신 맞아, 그걸 베이스로.”

| 묶음 | 기준 | 수정 내용 |
|---|---|---|
| 세트 정면0·1 | 정면193, 최종 정지 정면, 호루스 정지 몸 비율 | 머리색 세 단계·둥근 머리통/볼·짧은 몸·조금 작은 발바닥. 큰 머리 다발 밀도와 팔 자세 유지 |
| 세트 옆0·1 | 옆192, 최종 정지 오른쪽 | 머리 크기 확대 없이 둥근 머리통, 같은 방향 팔레트, 몸·다리 길이 호루스 정지 기준 |
| 호루스 정면·옆0·1 | 최신191, 각 방향 최종 정지·걷기 | 짧고 두툼한 삐죽머리, 둥근 얼굴, 색·몸 길이·정면 발 비율 |

크기와 모양을 혼동하지 않는다. 정지 머리 잘라 붙이기, 긴 몸, 긴 목 머리, 잘게 나눈 세트 머리, 안쪽만 바뀌는 숨쉬기를 조심한다. 같은 방향 정지·걷기와 머리 가이드를 실제로 열어 확인했다. 보고에는 별도 머리 맞춤 수치와8장 각각의 몸 두 구간 비율을 적는다.
