# 194 오푸스 확인 — 정지 선 가이드

`python3 tools/art/line-guide.py`로 만든 그림. 정지 머리의 검은 선(머리 외곽, 볼·턱선, 귀, 눈썹, 눈)을 그 그림의 머리 자리·기울기에 **정지와 같은 크기로** 빨갛게 깔았다.

- `<이름>-lines.png`: 그림을 흐리게 하고 빨간 선만 얹은 것. **이 위에 대고 머리·얼굴을 다시 그린다.** 턱선·볼선은 빨간 선을 따른다.
- `<이름>-lines-sheet.png`: 왼쪽 정지 머리, 오른쪽 지금 그림 + 빨간 선(확대). 빨간 턱선이 그린 턱보다 밖에 있으면 얼굴이 좁고 뾰족해진 것이다.
- `<이름>-head.png`: head-check(머리 크기·기울기).

호루스 정면·옆 모두 빨간 턱선이 그린 얼굴보다 아래·바깥에 있다: 얼굴이 정지보다 좁고 뾰족하다.
