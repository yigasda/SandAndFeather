# 정면 잠들기 201 — 다리 재작화·호루스 턱 복구

상태: 사용자 검토 대기. 게임 적용 대상 아님. 정면 PNG 4장, 620×720, 몸 가운데 기준점 (310,450).

- 세트 0·1: 195 호루스 각 프레임을 기준으로 새로 생성한 다리·신발 그림을 사용했다. 기존 199 다리를 늘이거나 행별로 변형하지 않았다. 새 그림을 기준의 다리 안팎 윤곽에 맞춰 다시 칠하고 외곽을 그렸다. 머리·얼굴·팔·상체는 199를 유지했다.
- 호루스 0·1: 199의 가로 마스크가 지웠던 198 원래 턱 아래 선을 복구했다. 몸은 199 그대로다.
- 옆잠 200과 소망은 수정하지 않았다.

## 직접 확인

`previews/legs-0-comparison.png`, `legs-1-comparison.png`에서 195 호루스와 같은 좌표·배율로 허벅지, 발목, 신발을 보았다. 이전의 잘록하게 꺾인 발목 형태를 제거했다. 발의 안쪽 틈과 바깥쪽 모양을 함께 확인했다. 밝고 어두운 전체 시트에서 치마·손·다리 접합과 턱을 확대 확인했다.

`checks/leg-geometry.json`은 실제 PNG의 발목·신발 영역(y535~634)에서 적갈색 머리카락을 제외한 윤곽을 비교한다. 두 장 모두 해당 영역의 다른 픽셀 0개다. 이는 전체 몸이나 내부 명암이 똑같다는 뜻이 아니다. 피부 영역 가이드는 `checks/guide-skin-*.png`다.

## 제작 기록과 검사 한계

`sources/set-redrawn-guide-body.png`는 새 그림의 작업 소스이며 전달용 PNG가 아니다. 생성 소스에 잘못 그려진 손은 사용하지 않았다. `process/redraw-on-guide.cjs`는 새 그림을 배치하고 가이드에 따라 피부와 외곽을 칠하는 단계다. 195 원본의 피부·신발 RGB를 복사하지 않았다. 요청 부위 밖의 기존 그림은 보존했다.

검사 원문은 `review/report.md`. 요청 부위 밖을 보존한 그림이므로 0·1의 기존 픽셀 중복 경고가 남을 수 있다. 이를 숨기거나 검사를 변경하지 않았으며, 경고가 있으면 전체 검수 완료·채택으로 기록하지 않는다.

최종 검사: 피부색·머리색 4장 모두 같음. 볼 것 2개 — 호루스 프레임 중복 58%, 세트 50%. 현재 요청 부위 외의 그림을 유지했으며, 이 경고 때문에 전체 검사 통과로 표시하지 않는다.
