# 셋소호 상호작용 시안170 — 선택 대기

최종 정지12장·걷기36장을 직접 확인하고 만든 정면 동작 시안5개. 각 안마다 세트·소망·호루스가 왼쪽부터 함께 보인다. 호루스 피부색 기준은168이다. 베이스48장 및 런타임 파일은 변경하지 않았다.

1. 한 손 내밀기
2. 양손 받기
3. 한 손 건네기
4. 문·장치 누르기
5. 대화 손짓

`sources/`는 투명 생성 원본5장, `previews/five-options-light.png`와 `five-options-dark.png`는 번호별 비교표다. `previews/hands-neck-zoom.png`는 손·소매·목 연결 확대 검수용이다. 이번 결과는 정면 자세를 선택하는 단계이며 상하좌우 애니메이션 세트나 기존 베이스 대체 파일이 아니다.

## 확인 범위

- 최신 main의 ASTRA-PLAN, ASTRA-HANDOFF, 캐릭터·검수 지침 확인.
- 참조48장 전체 시트와 개별 정면 원본을 직접 열었다.
- 밝은 배경, 어두운 배경, 손·소매·목 연결 확대를 직접 확인했다.
- 원본48장 SHA-256 유지 확인.
- `check-sprite.py --pose free`15회 결과는 checks에 있다. 검사 전체 통과로 기록하지 않는다. 생성 시안의 머리 폭·외곽선·알파 등에 차이 판정이 남는다. 호루스 기준의 턱을 눈썹 높이로 추정하는 등 자동 부위 추정의 오차도 있어 실제 비교 그림과 함께 봐야 한다. 시안은 기준과 픽셀 동일한 파일이 아니며, 최종 채택·게임 적용으로 표시하지 않는다.

선택된 자세의 방향 확장은 사용자 선택 이후 진행한다.
