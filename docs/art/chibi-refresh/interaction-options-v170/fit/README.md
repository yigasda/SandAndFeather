# 상호작용 시안 170 — 배율·비율 맞춤 결과

`tools/art/fit-scale.py`로 만들었다(오푸스). 시안 그림을 고치지 않고, 캐릭터마다 최종 정지 정면에 맞춰 다시 놓기만 했다.

**방법.**
- 팔다리는 자세마다 달라서, 머리를 기준으로 삼는다.
- 시안을 여러 배율로 바꿔 보며 머리가 정지 머리와 가장 잘 겹치는 배율과 위치를 찾는다.
- 찾은 대로 정지 캔버스(620×720, 발 기준점 310,662, 기준 키 576)에 놓는다.
- 머리를 맞춘 상태에서 발이 정지 발 기준선에서 12px(키의 약 2%) 안이면 "맞음"이다. 발을 기준선에 붙여서 낸다.
- 그보다 멀면 "비율 다름"이다. 시안 그림의 머리와 몸 비율이 정지와 달라서, 크기 조절로는 머리와 발을 동시에 맞출 수 없다. 몸 길이를 정지에 맞춰 다시 그려야 한다.

| 안 | 세트 | 소망 | 호루스 |
|---|---|---|---|
| 1 한 손 내밀기 | 비율 다름: 발 +41px (몸 7.1% 김) | 맞음 | 비율 다름: 발 −14px (2.5% 짧음) |
| 2 양손 받기 | 비율 다름: +51px (8.9%) | 비율 다름: +23px (4.0%) | 비율 다름: +22px (3.9%) |
| 3 한 손 건네기 | 비율 다름: +49px (8.5%) | 비율 다름: +20px (3.5%) | 비율 다름: +49px (8.6%) |
| 4 문·장치 누르기 | 비율 다름: +38px (6.6%) | 맞음 | 맞음 |
| 5 대화 손짓 | 비율 다름: +34px (5.9%) | 맞음 | 맞음 |

세트는 다섯 안 모두 몸이 정지보다 6~9% 길게 그려졌다.

**파일.** `option-<번호>/`마다 다음 파일이 있다.
- `<캐릭터>-front.png`: 머리에 맞춘 그림. "맞음"이면 그대로 게임에 쓸 수 있다.
- `<캐릭터>-front-height.png`: 키에 맞춘 그림. 비교용이다. 머리가 정지보다 작아진다.
- `fit-sheet.png`: 왼쪽부터 정지 / 머리 맞춤 / 키 맞춤. 빨간 선이 정지 윤곽이다.
- `fit.gif`: 정지와 머리 맞춤을 번갈아 보여 준다.
- `fit.json`: 수치.

다시 만들기: `python3 tools/art/fit-scale.py <시안 PNG> --out <폴더>`. 시안에 셋이 함께 있으면 왼쪽부터 세트, 소망, 호루스로 나눈다. `--who`로 순서를 바꿀 수 있다.
