## 그림으로 확인한 것

정지·걷기와 나란히 놓아 머리와 얼굴 크기·피부색·의상을 보았다. 세트는 긴 머리 전체 폭으로 줄이지 않고 정지 얼굴187×185의 면적을 기준으로 맞췄다. 호루스는 정지 짧은 머리 폭368px를 유지했다. 소망은 채택180을 직접 사용했다. 누운 머리의 위치는 발끝 선 대신 배 기준점에 맞춰 기록했다.

세트는 팔을 머리 위로 두고, 호루스는 두 손을 배에 올렸다. 소망은 옆으로 기대 잠든 원래 자세다. 침대 원본에 놓아 머리가 베개 쪽이고 몸이 화면 앞으로 이어지는 원근과 크기를 보았다. 접힌 손·팔, 목과 장신구, 치맛단·다리·신발 연결을 밝고 어두운 배경에서 확대 확인했다.

호흡은 가슴·어깨만 최대3px 이동하며 얼굴·눈·머리와 지정 영역 밖은 두 프레임에서 완전히 같다. 소망180 원본은 파일과 픽셀 모두 바꾸지 않았다. checks/preservation.json 및 캐릭터별 breath.json에 실제 바뀐 영역을 기록했다.
