# 세트 상호작용174 / 팔 수정175 — 4방향×2프레임 묶음 채택

사용자가 소망172 채택 후 “이제 세트 상호작용8장 하자”로 대상 캐릭터를 지정했다. 기존 계획표의 세트 후순위 문구보다 이 요청을 우선했다. 동작 명세는 소망과 동일한 서서 손 뻗기이며 세트의 차분한 무표정을 유지한다.

## 전달

- `png/`의 투명RGBA PNG8장.620×720, 발 기준점(310,662), 기준 키576.
- `front/back/left/right` = 게임의 `down/up/left/right`.
- 프레임0: 한 손을 뻗기 시작. 프레임1: 손이 닿음. 각150ms, 한 번 재생 후 같은 방향 정지.
- `previews/set-interaction-four-directions.gif`: 네 방향 동시 표시. 정지1200ms → 시작150ms → 닿음150ms를 반복하는 확인용.
- `previews/idle-interaction-walk-light.png`, `idle-interaction-walk-dark.png`: 방향별 최종 정지 / 상호작용0·1 / 최종 걷기0·1·2.
- 걷기360×400은 비교 시에만 기준 키330→576·발 기준점(180,370)→(310,662)으로 확대했다.

## 제작과 시각 확인

각 방향 실제 정지148 원본과 걷기163 원본, `../pose-guides/set-<방향>-guide.png`를 직접 열고, 같은 방향 가이드를 생성 편집의 밑그림 참조로 넣었다. 앞머리가 비대칭이므로 좌우는 각각 그렸다. 최종48장을 변경하지 않았다.

정면은 오른손을 앞으로 내밀어 손바닥이 보이고, 뒷면은 긴 머리 오른쪽으로 손과 금색 팔찌가 드러나며 위·앞으로 뻗는다. 왼쪽은 먼 오른팔이 뻗고 가까운 왼팔은 옆에 둔다. 오른쪽은 가까운 오른팔이 뻗으며 먼 팔은 몸과 머리에 가려진다. 무릎을 편 서기이며 물체·효과는 그리지 않았다.

생성 원본 쌍은 `sources/`에 있다. 각 셀을 분리해620×720으로 균등 정규화하고 알파8/255 이하 잔여값을 제거한 뒤 `fit-scale.py`로 정렬했다. 왼쪽은 초안의 긴 몸 길이와 시작 프레임의 팔 자세를 생성 편집으로 수정했다. 결과의 몸이나 머리를 따로 수치 변형하지 않았다.

PNG 내보내기에서 알파0.85 이상을 완전불투명으로 정리해 피부 내부의 옅은 얼룩을 없앴다. RGB와 나머지 가장자리 알파는 유지했다. 최종PNG8장 모두 `fit-scale.py`의 “맞음”을 확인했다(`checks/delivery-summary.json`). 보조검사(`checks/sprite/`)는6장 같은 범위이며 왼쪽0·1은 옷 색 차이 판정이 남는다. 색 분류에는 검은 치마 이외의 노출된 금색 팔찌도 섞이므로 실제 치마·팔찌를 원본과 나란히 비교했다. 보조검사 전체 통과나 원본 픽셀 동일을 주장하지 않는다. 밝고 어두운 배경의 전체 비교, 목·어깨·손목·허리·다리 연결 확대, 실제GIF의 모든 프레임을 직접 확인했다.

175 수정 포함8장은 사용자 칭찬·후속 호루스 작업 요청으로 채택됐다. 0.9.30에 게임 적용됐다. 재검사 예: `python3 tools/art/fit-scale.py docs/art/chibi-refresh/interaction-set-v174/png/set-front-0.png --who set --view front --out /tmp/set174-front0`

## 오른쪽 팔 수정175

사용자 요청으로 오른쪽 시작0·닿음1의 팔과 손을 왼쪽 두 프레임에 맞춰 짧고 둥글게 수정했다. 오른쪽 팔·손과 그 뒤에 드러난 머리카락만 생성 편집하고 국소 영역으로 반영했다. 같은 캐릭터 전체를 좌우 반전하지 않았다. 상단398px(머리·얼굴)과520px 아래(하반신·발)는 수정 전과 픽셀 동일하며, 나머지6개 PNG와 최종 베이스48장도 동일하다. 오른쪽 두 장의 최종 fit-scale 재검사는 모두 맞음이다. 밝고 어두운 배경에서 손목·팔·머리카락 연결을 확대 확인하고, 실제GIF 세 프레임도 확인했다. `175-arm-comparison.png`는 왼쪽 기준 / 오른쪽 이전 / 오른쪽 수정 / 팔 확대다. 현재 전달 ZIP은 `175-set-interaction-8png.zip`. 175 수정 포함8장 사용자 채택 완료.
