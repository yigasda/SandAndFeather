# 174/175 세트 상호작용 — 오푸스 fit-scale 확인

`tools/art/fit-scale.py`로 전달 PNG 8장(오른쪽은 175 팔 수정본)을 다시 돌렸다. `fit-all.png`는 장마다 정지 / 머리 맞춤 / 키 맞춤(빨강 = 정지 윤곽).

| 장 | 판정 | 배율 | 키를 맞추면 머리 크기 |
|---|---|---|---|
| front-0 | 맞음 (발 +6px 보정) | ×1.0025 | 99% |
| front-1 | 맞음 (발 +6px 보정) | ×1.0025 | 99% |
| back-0 | 맞음 (발 +1px 보정) | ×0.9975 | 100% |
| back-1 | 맞음 (발 -1px 보정) | ×1.0 | 100% |
| left-0 | 맞음 (발 +2px 보정) | ×0.9975 | 99% |
| left-1 | 맞음 (발 +2px 보정) | ×1.0025 | 99% |
| right-0 | 맞음 (발 -1px 보정) | ×1.0025 | 100% |
| right-1 | 맞음 (발 +0px 보정) | ×1.005 | 100% |

8장 모두 "맞음". 배율은 0.9975~1.005로 정지와 같은 크기다. 사용자 채택 후 0.9.30에 게임에 넣었다.
