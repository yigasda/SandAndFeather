# 베이스 피부톤 정리와 체형 5종

2026-10-10. 사용자는 호루스 피부톤을 세트와 맞추면 베이스는 끝이라고 했고, 베이스를 바탕으로 스프라이트에 어울리는 귀여운·짧은·둥근 체형 시안 5종을 요청했다. 최신 피부톤 지시는 과거 '호루스가 더 밝다'보다 우선한다.

## 제작 중 추가된 사용자 기준

사용자는 51번 두아트 몬스터·타격 비교본을 다시 보여주며 원하는 체형뿐 아니라 그림체도 정확히 그 방향이라고 강조했다. 따라서 이미 만든 1~4는 비교용이고, **5번은 두아트 전투본을 주 스타일/체형 참고로 제작한 최신 방향**이다. 정밀 SD 일러스트 비율을 계속 확장하지 않는다. 베이스는 캐릭터 디자인 참고, 두아트 비교본은 실제 작은 게임 스프라이트 표현 참고로 구분한다.

모든 PNG는 투명 배경, JPG는 확대 검토용이다. 실제 정규 48x64 또는 64x64 시트가 아니다. 1~4는 체형 변화 위주, 5는 최신 요청대로 화풍과 디테일 표현도 작고 간결하게 바꿨다. 숫자 등신이나 목표 도트 해상도는 생성 방향이지 결과의 정확한 측정값이 아니다.

5번은 아직 사용자 확인 전이다. 실제 방향별 스프라이트 제작 때 소망의 묶이지 않은 가슴 길이 곱슬/타레메, 세트의 다크 크림슨/마른 몸/원래 치마, 호루스의 작은 한쪽 두 갈래 눈장식 위치와 차분한 눈매를 베이스 기준으로 대조해야 한다. 작은 도트로 옮기며 생기는 해석 차이를 확정 변경으로 간주하지 않는다.

이번 작업은 새 docs 이미지와 이 문서만 추가했다. 게임 코드·기존 게임 스프라이트·맵은 유지한다. 두아트 후속 맵은 치비 확인 이후로 대기. 게임 표시 크기는 51번 전투본에서 사용자가 선호한 비율을 실제 폰 화면에서 확인해 결정한다.
