# 호루스 3안 기반 윗머리 미세 수정

사용자가 3안을 기준으로 2안 머리 느낌을 조금 추가해 달라고 요청했다. 3안이 이번 수정의 지정 베이스다. 추가 머리 수정 결과는 사용자 반려. 원래3안(base-option3.png)이 선택됐으며 게임 미적용.

- `base-option3.png`: 118번 비교판에서 자른 실제 3안.
- `horus-front.png`: 정수리 윗머리 두 끝에 위로 뻗는 방향감만 추가한 결과.
- `119-horus-hair-comparison.png`: 왼쪽 3안, 오른쪽 수정본.
- `validation.json`: 입력 크롭 및 수정 영역. 크롭 좌표 y215 아래는 원본과 채널 차이 0. 얼굴·피부·몸·옷은 원본 픽셀 보존.

이미지 편집 도구에 3안과 2안을 입력한 뒤 생성 결과의 윗머리 부분만 3안에 국소 합성했다. 생성 결과 전체를 새 베이스로 사용하지 않는다. 이 결과의 피부는 3안 보존이며 승인 초기 일러스트와 피부색 일치를 별도로 검증한 것은 아니다.
