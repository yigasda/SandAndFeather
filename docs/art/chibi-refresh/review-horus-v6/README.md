# 호루스2안 후속: 외곽선·얼굴/머리 명암·눈

> **후속 반려: 이 버전의 재작화한 머리는 사용하지 않는다.** 사용자는 기존2안(`../review-horus-set-body-v5/option-2.png`) 머리 전체의 실제 복사와 원본 눈90%·귀 소폭 축소만 요청했다. 이미지 생성, 머리카락·얼굴형 재작화 금지. 아래 검토 대기 표현은 제작 당시 기록이며 현재 채택 상태가 아니다.

2026-10-11. 사용자는122번3안 중 **2번을 잠정 베이스**로 선택하고 몸의 잘린 외곽선을 보강, 얼굴/머리 명암 깊이 조정, 눈 크기 소폭 축소를 요청했다. 이번 결과는 검토 대기이며 채택 확정 또는 게임 적용으로 간주하지 않는다.

- 실제 입력: `../review-horus-set-body-v5/option-2.png`.
- 명암 참고: 세트의 실제 `../review-pocket-style-v2/front/set-front.png`.
- `edit-source.png`: 위 입력들을 사용한 이미지 편집 출력.
- `horus-front.png`: 비교/후속 편집용 투명 정면 크롭. 표시 높이626px로 정렬.
- `124-horus-before-after.png`: 왼쪽 선택2안, 오른쪽 후속 수정. 같은 가시 높이626px로 비교.
- `review.json`: 작업 범위와 상태.

어깨·팔·주먹·치마·다리의 끊긴 외곽선을 연속된 어두운 윤곽으로 보강하고 머리의 잡음을 줄였다. 이마 가장자리·귀·턱 아래 명암을 도트 덩어리로 정리하고 전체 눈 크기를 조금 줄였다. 몸/의상과 짧은 머리 디자인을 유지하도록 입력했으며, 생성 편집 결과를 시각적으로 대조했다. 몸이 세트 원본과 픽셀 동일하거나 요청 밖 픽셀이 모두 동일하다고 주장하지 않는다. 이 수정에서 몸을 다시 잘라 합성하지 않았다.

**교훈:** 이전 몸 추출 마스크가 실제 어깨/팔 외곽선을 잘랐다. 몸 형태를 복사할 때 색 면만 남기지 말고 외곽선까지 포함해 확대 검수한다. 부위별 질감이 달라 머리가 붙인 것처럼 보이면 머리와 몸의 픽셀 크기·명암·윤곽선을 함께 맞춘다.
