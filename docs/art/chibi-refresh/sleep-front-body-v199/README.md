# 정면 몸 재작화 199 — 세트·호루스 4장

198을 베이스로 정면 몸만 새로 그린 검토본. 옆모습은 이번 작업에서 바꾸지 않았다.

사용자 최종 지시: “198에서 몸만195대로 다시 그려”, “호루스 정면도”, “대고 그려”, “세트 몸은195 호루스 몸 대고 새로 다시 그려”, “세트 팔은 왼쪽 들고 오른쪽 내리고”.

- 몸 기준: 195 호루스 정면의 프레임별 어깨·몸통·치마단·짧은 다리·발 자리.
- 세트는 왼팔을 들고 오른팔을 내린 자세, 세트의 금장·차콜 치마·피부색으로 그렸다.
- 호루스는 두 손을 배 위에 놓고 팔꿈치를 옆으로 편195 자세로 그렸다.
- 목부터 신발까지 한 번에 새로 그린 몸 원화를198 위에서 편집했다.195 몸의 RGB 픽셀이나 팔다리 조각은 옮기지 않았다. 원화의 목·가슴·손·치마단·발끝 높이는195 기준점에 등록했다. 머리나 얼굴을 다시 생성한 것으로 바꾸지 않았다.
- 머리 위쪽과 얼굴 보존 영역의 픽셀 차이는0. [보존 확인](checks/preserved-regions.json). 몸 주변에 가려진 머리 연결은 새 몸의 경계에 맞춰 마감했다.

최신 검사에는 호루스 정면의 프레임 복사 의심1건이 남아 있다. 요청대로 보존한 머리 영역의 영향과 새 몸 영역 비교를 [직접 확인](review/visual-notes.md)에 기록했다. 이 묶음을볼 것0개라고 보고하지 않는다.
