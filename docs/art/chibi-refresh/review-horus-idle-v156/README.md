# 156 — 호루스 정지 정면 한 장

사용자 요청에 따라 정지 한 장부터 전달. 채택 전, 게임 미적용. 걷기 파일 변경 없음.

- 머리 바깥 윤곽 기준: 사용자 Drive 도안을 얼굴 위치에 정렬한 원본 마스크. 이마 안쪽 거친 선만 정리.154의 눈·얼굴은 보존.
- 몸:151의 실제 정지 정면 몸. 걷기1을 정지로 표시하지 않았다.
- 다리: 정지 그림의 피부 구간만3px 단축. 신발은 같은 모양으로 위로 이동.
- `horus-front.png`:360×400 투명 원본. `156-horus-front.png`:720×800 밝은 배경 확인용.
- sprite-check 결과 같은 범위. 수치 통과는 외곽 모양 사용자 채택을 뜻하지 않는다.
- 정면 걷기에도 같은 사용자 외곽선을 적용해야 하지만 아직 반영 완료가 아니다. 채택 걷기 몸을 유지하며 프레임별 머리 전체 움직임과 접합을 먼저 확인해야 한다.155는 계속 반려본이다.
