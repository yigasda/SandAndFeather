# 줍기182 — 세트·호루스16장

소망181을 자세 기준으로 확장한 새 검토 묶음. 소망181 PNG는 수정하지 않았다. 아트 채택·게임 적용 대기, 게임 적용은 오푸스 담당.

4방향×2프레임×2캐릭터,620×720 투명RGBA.0 내려앉기 시작→1 바닥에 손, 각200ms 한 번 뒤 정지 복귀. 세트는 과한 쩍벌 없이 무릎을 앞으로 모은 편한 자세, 호루스는 단정한 자세.1에서 세트 눈은 작게 변화, 호루스 눈은 가늘게 살피는 형태. 뒷모습은 얼굴 없음.

## 직접 확인

- 최종 정지·걷기와 나란히 보고 머리 폭, 앞머리, 호루스 문양 방향, 피부색을 비교했다. 좌우를 따로 그렸다.
- 밝고 어두운 배경에서16장 전체와 팔·무릎·손·치마 연결을 확인했다. 왼쪽을 비교용으로만 반전한 팔·손 겹침 시트도 만들었다.
- 피부 기본색·홍조·밝은 색은 같은 방향 최종 원본에서 추출했다. 새 색을 쓰지 않도록 재배색했다. 피부 검사 원본 리포트는 checks/skin에 있다.
- 호루스 완성 자세의 높이는 정지 대비 약66~70%. 세트는 바닥에 닿는 머리 길이를 접어 다시 그렸고 완성 자세 외곽 높이는 약64~74%다. 목표65~70%와의 차이는 방향별 수치에 남겼다. 실제 수치는 checks/placement.json. 머리나 전체 캐릭터를 줄여 목표에 맞춘 것으로 표시하지 않았다.
- fit-scale의 서 있는 자세 기준은 쪼그림에서 비율 다름을 표시한다. 검사 결과를 그림 완성의 근거로 쓰지 않는다. 머리·기준점 측정과 비교 시트로 따로 검토했다.
