# 182 세트·호루스 줍기 — 오푸스 확인 (피부색·fit-scale·동작 흐름)

사용자 판정: **호루스 8장 채택**("호루스 줍기는 채택이야"). 세트 8장은 다시 그린다(머리가 줄었고, 0과 1이 차이가 없고, 0이 정지에서 너무 급하게 바뀜).

**피부색** `skin-check.py`: 16장 모두 같음. `skin-horus.png`, `skin-set.png`, `skin.json`.

**동작 흐름** `action-check.py`(머리 맞춤 배율 · 프레임별 키 · 0→1 윤곽 차이). `action-horus.png`, `action-set.png`, `action.json`.

| | 0: 키 · 머리 | 1: 키 · 머리 | 0→1 윤곽 차이 | 판정 |
|---|---|---|---|---|
| 호루스 정면 | 79% · ×1.07 | 70% · ×1.08 | 24% | 볼 것 없음 |
| 호루스 뒤 | 75% · ×1.06 | 68% · ×1.04 | 28% | 볼 것 없음 |
| 호루스 왼쪽 | 81% · ×1.07 | 67% · ×1.10 | 39% | 볼 것 없음 |
| 호루스 오른쪽 | 79% · ×1.10 | 70% · ×1.11 | 33% | 볼 것 없음 |
| 세트 정면 | 69% · ×1.31 | 74% · ×1.11 | 15% | 0 머리 작음, 0이 이미 끝 자세(1보다 낮음) |
| 세트 뒤 | 63% · ×1.21 | 64% · ×1.20 | 6% | 머리 작음, 0이 끝과 같음, 0→1 차이 없음 |
| 세트 왼쪽 | 66% · ×1.29 | 67% · ×1.27 | 7% | 머리 작음, 0이 끝과 같음, 0→1 차이 없음 |
| 세트 오른쪽 | 68% · ×1.24 | 69% · ×1.36 | 5% | 머리 작음, 0이 끝과 같음, 0→1 차이 없음 |

머리 맞춤 ×1.20 = 머리가 정지보다 약 1/6 작게 그려졌다는 뜻이다. 채택된 쪼그린 자세(소망 181, 호루스 182)는 ×1.03~1.11.
세트 수정 방향: 머리를 정지 크기로(×1.00~1.10), 0은 무릎을 굽히며 내려가는 중간(정지 키의 약 80~86%, 소망 181·호루스 182처럼), 1은 완전히 쪼그림(65~75%). 0과 1의 키 차이 최소 6% 이상, 윤곽이 눈에 띄게 달라야 한다.

**fit-scale** `fit-horus.png`, `fit-set.png`: 쪼그린 자세라 "비율 다름"은 당연하다. 머리 크기만 본다(위 표의 머리 맞춤 배율).
