# 182 호루스 줍기 — 오푸스 확인 (피부색·fit-scale·동작 흐름)

사용자 판정: **호루스 8장 채택**("호루스 줍기는 채택이야"). 세트 줍기는 탈락, 이 기록에서 뺐다.

**피부색** `skin-check.py`: 8장 모두 같음. `skin-horus.png`, `skin.json`.

**동작 흐름** `action-check.py`(머리 맞춤 배율 · 프레임별 키 · 0→1 윤곽 차이). `action-horus.png`, `action.json`.

| | 0: 키 · 머리 | 1: 키 · 머리 | 0→1 윤곽 차이 | 판정 |
|---|---|---|---|---|
| 정면 | 79% · ×1.07 | 70% · ×1.08 | 24% | 볼 것 없음 |
| 뒤 | 75% · ×1.06 | 68% · ×1.04 | 28% | 볼 것 없음 |
| 왼쪽 | 81% · ×1.07 | 67% · ×1.10 | 39% | 볼 것 없음 |
| 오른쪽 | 79% · ×1.10 | 70% · ×1.11 | 33% | 볼 것 없음 |

머리 맞춤 ×1.00 = 정지와 같은 크기. 쪼그린 자세는 숙인 머리·퍼진 머리카락 때문에 ×1.03~1.11로 잰다.

**fit-scale** `fit-horus.png`: 쪼그린 자세라 "비율 다름"은 당연하다. 머리 크기만 본다(위 표).
