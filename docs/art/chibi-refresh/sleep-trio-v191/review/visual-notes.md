- 정지·걷기와 같은 배율의 네 비교 시트를 열었다. 세트는 긴 스트레이트 가닥과 붉은 팔레트, 호루스는 위·바깥으로 뻗는 짧은 남색 삐죽머리를 유지했다. 세트 옆 머리는 누운 기울기 때문에 자동 머리 탐색이 불안정하여 정지 오른쪽과 실제 얼굴·정수리 크기를 함께 보았다.
- 사용자 자세 그림과 정면 두 장을 나란히 보았다. 다리가 아래로 펴져 있고, 무릎을 세워 접은 자세가 아니다. 사용자 정정대로 큰 타원형 샌들 밑창이 앞에 보인다. 세트 화면 왼팔은 머리 옆, 오른팔은 내려온 자세다. 호루스 양손은 배 앞에 모였다.
- 호루스 바로눕기 목 양옆은 피부·금 목걸이로 이어지고 어깨에 남색 긴 머리카락이 내려오지 않는다. 밝은/어두운 배경에서 목·팔·치마 접합과 귀 주변을 보았으며 분리된 점이나 빈 구멍은 보이지 않았다.
- 외곽선 차이 시트에서 어깨·팔 및 몸과 닿는 머리 윤곽에 빨강이 나타난다. 네 쌍 모두 윤곽 변화 3% 초과, 바운딩 박스도 다르다. 31px GIF의 0/1을 디코딩한 확대 시트를 직접 비교하여 작은 크기에서도 어깨·팔/몸 주변 변화가 남는 것을 확인했다.
- 각 프레임을 다시 그렸기 때문에 변화가 호흡 영역에만 엄밀히 한정되지는 않는다. 머리·신발에도 작은 선 차이가 남으며, 0/1의 고정 영역이 픽셀 단위로 동일하다고 주장하지 않는다. 전체 픽셀 차이도 previews/*-all-changes-red.png에 포함했다.
- 실제 침대 그림 위에 혼자/함께 올린 시트를 보았다. 두 인물은 서로 마주 보고, 투명하지 않은 픽셀이 겹치지 않으며 베개와 매트리스 안에 들어간다. 이불 가림을 적용하기 전 검토용 합성이다.
