# 제작 기록

sources/의 8장 모두 자세 전체를 새로 그린 이미지 생성 결과다. 정지 머리·얼굴·팔다리 조각을 결과에 합성하지 않았다. references/는 소망 보존본이며 비교 시트에만 사용했다.

후처리: 전체 프레임 균등 크기 조절·회전·이동(최근접 픽셀), 알파 정리, 같은 방향 최종 정지·걷기에서 추출한 피부 팔레트 적용. 부분별 머리/얼굴 붙여넣기 없음.

프레임0 등록: 세트 바로눕기 .52/(-5,-6), 호루스 바로눕기 .54/(-3,-20), 세트 옆 .52/(2,1), 호루스 옆 .52/(2,7). 프레임1 전체 변환은 registration JSON 참조. 정면1에는 global-registration을 추가 적용했다.

스크립트는 제작 당시 작업 기록이다. palette 스크립트의 /workspace/actions191 작업 경로와 설치된 sharp 경로는 환경 의존적이다. 최종 납품 바이트 기준은 manifest의 PNG 해시다. qa.py/previews.py는 저장소 루트에서 최종 PNG를 읽어 비교 자료를 다시 생성한다.
