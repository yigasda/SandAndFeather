# 이전 그림체 — 동작 분석 참고 전용

**게임 적용·최종 아트 사용 금지.** 사용자 요청으로 이전 정지12장과 정지 시트/미리보기를 삭제했다. 필요하면 git 이력에서만 확인한다.

남아 있는 `walk/`는 프레임별 동작 비교 도구의 원본이다. 현재 외형이나 새 정지의 베이스가 아니다. 현재 채택 걷기는 [review-trio-walk-v5](../review-trio-walk-v5/README.md)다. `manifest.json`은 `runtimeEligible: false`다.

새 그림체 정지12장은 아직 없으며, 구버전 정지로 빈자리를 채우거나 새 걷기와 혼합하지 않는다.
