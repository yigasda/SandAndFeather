# 이전 그림체 — 참고 원본 보존

사용자의 최신 지시로 **정지12장·걷기36장과 시트/미리보기를 참고용으로 보존**한다. 파일명 `approved`는 당시 승인 기록이며 현재 최종 적용본이라는 뜻이 아니다.

- `idle/`: 이전 그림체 정지12장. 새 정지 제작 시 방향·자세·발 위치 참고.
- `walk/`: 이전 걷기36장. 프레임별 동작 분석 참고.
- `sheets/`, `previews/`: 위 원본의 참고용 모음.
- 현재 채택 외형·걷기는 [review-trio-walk-v5](../review-trio-walk-v5/README.md)를 따른다.

**구버전 정지와 현재 걷기를 게임에 섞어 적용하지 않는다.** 새 그림체의 별도4방향 정지12장 패키지는 아직 없다. 참고 파일은 삭제하지 않으며, `manifest.json`의 `runtimeEligible: false`는 이 구버전 묶음의 재적용만 막는다.
