# 옆잠 들숨 재작화 200 — 세트·호루스

사용자 지시: 옆잠0을 밑에 깔고1을 새로 그리기. 가운데를 확대·변형해 만드는 방법 금지. 세트는 어깨·팔에 걸친 머리카락과 끝 갈래도 같이 움직이기.

- 기준0: `sleep-selected-v198/png/`의 각 캐릭터 옆잠0. 세트는195 채택 원본, 호루스는195의 외곽선을 수정한198.
- 1은 각0을 직접 참조하여 새로 생성한 원화. 프레임0의 RGB를 복사하거나, 몸통을 확대·이동·비틀어1로 만들지 않았다.
- 원화 전체를620×720 전달 캔버스로 축소하고 투명 배경의 미세 잔여 알파를 정리했다. 호루스 새 원화는 캔버스 전체를15px 아래에 등록했고, 피부의 청색 성분을4 올려 기준 피부톤에 맞췄다. 몸 부분만 별도로 늘리거나 좌표 변형하지 않았다.
- 세트는 접힌 팔·가슴과 함께 앞머리 다발 끝, 어깨·등 옆 큰 갈래의 윤곽을 새로 그렸다. 호루스도 접힌 팔·가슴·목걸이 연결을 새로 그렸다.
- 두0은 바이트 단위로 그대로 보존했다: [해시 확인](checks/frame0-preserved.json).
