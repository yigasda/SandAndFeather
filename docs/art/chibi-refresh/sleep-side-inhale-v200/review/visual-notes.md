# 옆잠200 직접 확인

- 각 캐릭터의198 옆잠0을 열고 같은 방향 최종 정지·걷기와 비교한 뒤0을 기준으로1을 새로 그렸다.0 PNG 두 장은 바이트가 같다.
- 밝은·어두운 배경의0·1 비교, 겹침, 어깨·팔·머리끝 확대를 직접 열었다. 세트 앞머리 끝은 들린 팔 위에서 끝나는 곡선으로 바뀌고, 등 쪽 큰 갈래 끝도 위로 움직인다. 귀 앞 다발은 끊기지 않으며 팔과 머리 사이 사각 경계가 보이지 않는다.
- 호루스는 어깨·목걸이·굽힌 팔이 함께 올라온다. 짧은 머리의 파랑 하이라이트는 남아 있고 목 아래 긴 머리는 추가하지 않았다. 새1의 얼굴·신발 가장자리에서 별도 조각을 붙인 이중 외곽선은 보이지 않았다.
- 같은 배율의 오른쪽 걷기→정지→0·1 chain 시트를 직접 열었다. 세트의 긴 생머리 다발과 호루스의 짧은 삐죽머리, 피부·금장·치마의 구분을 비교했다.0·1을 새로 그렸으므로 감은 눈·머리·다리 픽셀이 전부 같은 것은 아니다.
- 게임 크기 GIF의 두 프레임을 확대해 각각 확인했다. 세트 앞머리 끝과 접힌 팔, 호루스 어깨·팔 쪽 작은 실루엣 변화가 보인다. 실제 게임 실행·침대 배치 확인은 하지 않았으며 게임 적용은 오푸스 담당이다.
- 최신sprite-review는볼 것0개, 피부·머리색은네 장 모두같음이다. 숫자는 위의 그림 확인을 대체하지 않는다.
