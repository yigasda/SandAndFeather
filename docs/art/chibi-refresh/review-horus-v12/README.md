# 130번 — 도트 피부 명암·턱과 귀 아래 외곽선 정리

2026-10-11. 사용자 검토본, 미채택·게임 미적용.

129번을 후속 베이스로 사용한다. 사용자는 턱 아래·귀 아래의 겹치고 깨진 외곽선을 수정하고, 연속적인 피부 그라데이션을 몸/메이플처럼 도트식 명암으로 바꾸라고 요청했다. 턱선·눈썹 아래·눈가는 연하게.

- 피부는 가까운4색 `[254,233,220]`, `[254,229,215]`, `[253,224,209]`, `[251,219,204]`로 단계화. 생성 편집의 연결된 명암 덩어리를 사용하며 블러 그라데이션/잡음 디더링은 사용하지 않는다.
- 턱·귀 아래 중복된 검정/회색 띠만 국소 정리. 얼굴형의 둥근 형태는 계승하며 해당 외곽선 픽셀 수정은 이번에 허용된 범위다.
- 헤어, 기존 눈·눈썹·입·문양의 특징 픽셀, 이미 보강한 몸 실루엣 변경0. 눈 크기/위치 변경이나 재작화 없음. 몸을 다시 합성/축소하지 않는다.
