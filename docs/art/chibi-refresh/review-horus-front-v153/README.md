# 153 — 호루스 정면 이마 경계 정리

**사용자 반려: 왼쪽 머리·귀 위 구멍이 남아 있었다. 현재 국소 수정 검토본은 [154](../review-horus-front-v154/README.md). 이 파일을 적용하지 않는다.**

정면 정지1장 + 정면 걷기3장 검토본. 게임 미적용, 최종 채택 전. 뒤/옆과 새 뒤 몸은 후속 작업이며 이번 납품에 포함하지 않는다. 152 초기 비교/4방향 GIF는 거친 경계와 미완성 접합이 남은 폐기 초안으로, 적용 입력으로 사용하지 않는다.

## 지시 구분

- 사용자 폰 도안의 **바깥 머리 윤곽, 가닥 끝 위치, 폭·높이**를 기준으로 삼는다.
- **이마는 높이만 참고해 다듬는다.** 거친 손그림 모양을 내부 머리카락-피부 경계에 그대로 남기지 않는다. 기존 채택 호루스의 정돈된 머리 경계와 피부 명암을 지정 높이에 맞춰 이어 쓴다.
- 왼쪽 관자놀이의 우발적인 투명 빈틈을 기존 머리색으로 연결한다. 휴대폰의 칠/회색 선/JPEG 질감을 복사해 납품하지 않는다.
- 정면 정지 몸은 최종131 계열 실제 투명 원본 `../review-trio-walk-v4/idle-reference/horus-front.png`를 동일 표시 배율로 사용한다.
- 걷기3장은 각각 기존 개별 PNG를 사용했다. y204 아래는 원본과 차이0. 눈·눈썹·입·표식과 기존 몸 동작을 다시 생성하지 않았다.

## 검수

머리 확대와 어두운 배경 정지/걷기4장으로 이마 경계·왼쪽 연결·각 프레임 잔여 선을 확인했다. 기존 정지와 도구 비교에서 정면 신발 폭·치맛단 폭은 다름으로 표시된다. 이는 사용자 요청에 따라 몸을 최종 시안 원본으로 바꾼 부분이다. 리포트와 비교판은 `native/sprite-check/`. 전 항목 통과나 사용자 채택으로 기록하지 않는다. 기존 승인 원본과 런타임 파일은 변경하지 않았다.
