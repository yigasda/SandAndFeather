# 소망 피부톤 소폭 밝힘 — 검토 대기

기준은 `../review-pocket-style-v2/front/somang-front.png`의 실제 파일. 이미지 편집 도구로 피부 밝기 보정을 만들고, 원본과 생성 결과의 피부 픽셀 RGB 차이를 측정했다. 그 차이를 작은 범위로 제한해 원본 피부 마스크에만 옮겼다. 얼굴형과 이목구비·머리·옷·알파는 원본 유지. 추출 방법과 수치는 `validation.json`에 기록했다.

- `somang-front.png`: 수정 후보. 게임에 연결하지 않았다.
- `121-somang-skin-compare.jpg`: 왼쪽 기존, 오른쪽 피부톤 수정.

호루스와 별개 검토이며 소망의 승인 여부를 추정하지 않는다.
