# 셋소호 정면 검토 v2 — 승인 캐디 유지

2026-10-11. 미채택 검토본, 런타임 미적용. 현행 승인 원본은 `../approved/` 그대로다. 이전 v1의 소망 머리색·폭과 호루스 얼굴은 사용자 반려. 이번 수정은 그 피드백을 반영한다.

- `front/set-front.png`: v1 후보 그대로 복사. 이번 세트 수정 없음.
- `front/somang-front.png`: 머리를 어두운 다크브라운으로, 곱슬 유지하며 옆 폭 축소. 얼굴과 옷은 승인 캐디를 이어간다.
- `front/horus-front.png`: `../approved/idle/horus-front.png`를 얼굴·눈매·눈썹·피부색·옷의 기준으로 편집. 예전 치비는 짧은 머리 참고만. 완만한 수평 눈썹, 작은 동공, 밝은 피부를 기준으로 다시 수정했다.
- `skin-samples.json`: 승인 PNG에서 직접 추출한 피부 RGBA와 좌표. 이마 #FCE4DE, 볼 #FDE4DD, 몸 #FDE7E3, 손 #FBE2DD, 귀 그림자 #FCD3C8. 이미지 편집 입력에 사용한 기준색이며 생성 결과가 모든 픽셀에서 일치한다고 주장하지 않는다.
- `sources/`: 이번 두 캐릭터의 이미지 편집 출력 원본. 투명 여백만 잘라 정면 파일로 분리했다.
- `previews/114_*`: 승인 원본과 새 후보의 동일 높이 비교.
- `previews/115_*`: 실제 맵 이미지 위 같은 발 위치·65px 높이로 합성한 비교. 게임 캡처가 아니다.

정면 검토 단계다. 4방향·걷기·게임용 최종 픽셀 그리드/아틀라스 작업은 아직 하지 않았다. 사용자의 추가 피드백은 이 후보를 자동 승인 처리하지 말고 실제 승인 원본과 함께 대조한다.
