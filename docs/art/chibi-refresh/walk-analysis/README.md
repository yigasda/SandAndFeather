# 최종 걷기36장 분석

분석 대상은 [final/](../final/README.md)의 캐릭터별 `walk/` 원본36장이다. **호루스173 머리·몸통 비율 수정까지 반영된 최종 채택본**이다. 옛 그림체와 이전 검사 예제는 사용자 요청으로 삭제했고, 이 폴더의 분석도 최종 파일을 기준으로 다시 만들었다.

```sh
python3 tools/art/analyze-walk.py
python3 tools/art/analyze-walk.py --candidate <후보폴더>
```

후보는 `<캐릭터>-<방향>-<0|1|2>.png`가 있는 폴더 또는 최종 폴더처럼 `<캐릭터>/walk/` 구조를 쓸 수 있다. 기준 파일은 읽기만 한다. 단독 실행은 이 폴더의 분석표와 비교 그림을 갱신하며 게임에 적용하지 않는다.

- `analysis.json`, `table.md`: 머리·얼굴·몸·발 위치와 각 걸음의 변화.
- `*-walk-marks.png`: 실제3프레임, 외곽선 겹침, 머리 영역 변화.
- `*-head-zoom.png`: 원본 머리3프레임 확대.

중간 포즈1을 기준으로0·2의 머리 결·얼굴 방향·치마·발 움직임을 본다. 정지 머리를 복사해 붙이면 원본의 프레임별 변화가 사라진다. 부위의 위치만 흔드는 방법으로 대체하지 않는다. 숫자 검사는 참고이며 원본PNG와 재생GIF를 눈으로 함께 확인한다. 분석PNG는 별도 시안이나 게임용 프레임이 아니다.
