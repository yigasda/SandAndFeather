# 승인 걷기 36장 분석 — 새 걷기를 그리기 전에 볼 것

2026-10-11, 오푸스가 만들었다. 승인 걷기 PNG(`../approved/walk/<캐릭터>-<방향>-<0|1|2>.png`, 360×400, 발 기준점 180,370)를 프레임마다 재서, 걷는 동안 무엇이 얼마나 움직이는지 정리했다. 승인 파일은 읽기만 했다.

**목적.** 새 그림체로 걷기를 다시 그릴 때 기존 걷기와 똑같이 움직이게 하는 것이다. 그리기 전에 이 자료로 원본의 움직임을 확인하고, 그린 뒤에는 같은 도구로 비교한다.

## 핵심 — 기존 걷기는 프레임마다 머리를 다시 그렸다

- **머리 영역의 5~18%가 프레임마다 바뀐다.** 머리 영역은 그림 위쪽 55%다. 머리카락 끝, 얼굴 윤곽, 눈, 귀가 걸음마다 조금씩 다르게 그려져 있다. 정지 머리를 복사해 붙이면 이 값이 0~2%가 된다. 134번이 그랬다.
- **머리 위끝이 들썩인다.** 호루스는 앞·뒤·오른쪽에서 1~2px 위아래로 움직인다. 세트와 소망은 머리 위끝이 고정이고, 대신 머리카락 옆 끝이 2~5px 흔들린다.
- **얼굴이 걸음 따라 돈다.** 정면에서도 얼굴 중심이 프레임마다 좌우로 1~3px 이동한다(세트 −1.9/+1.9, 호루스 −3.0).
- **얼굴은 몸 위에 바로 있다.** 정면에서 얼굴 중심과 어깨·가슴 중심의 차이는 세트 0~0.6px, 호루스 0.2~1.3px, 소망 2~3px다. 세트 몸이 얼굴보다 오른쪽으로 치우친 134번은 −6.5px였다.
- **몸통, 다리, 치마, 팔은 기존 걷기가 기준이다.** 사용자가 134번 몸통 동작은 괜찮다고 했다.

## 아스트라 사용법

**그리기 전.**
1. 작업할 캐릭터·방향의 `marks`와 `head-zoom`을 연다.
2. 프레임 0·1·2에서 머리카락 끝, 얼굴 방향, 머리 위끝이 어떻게 바뀌는지 위 표의 숫자와 함께 짧게 적는다.
3. 그걸 계획에 넣어 사용자에게 확인받는다.

**그린 뒤.** 후보 PNG를 같은 이름(`<캐릭터>-<방향>-<0|1|2>.png`)으로 한 폴더에 두고 실행한다.

```
python3 tools/art/analyze-walk.py --candidate <폴더>
```

`<폴더>/walk-check/`에 같은 표시를 한 그림과 `report.md`가 생긴다. 리포트는 승인 걷기와 다르게 움직이는 곳을 적어 준다.
- 머리 영역 변화가 승인의 40% 미만이면 → "머리 고정 의심"
- 머리카락·얼굴·머리 위끝의 움직임 방향이나 크기가 승인과 다르면 → 해당 프레임과 값
- 얼굴−몸 중심이 승인보다 6px 넘게 다르면 → "몸이 얼굴 아래에서 어긋남"

캐릭터 크기가 바뀌어도 된다. 키 비율로 맞춰서 비교한다.

**통과 기준.**
- 리포트에 해당 방향이 "승인과 같은 범위"로 나온다.
- 그리고 `marks` 그림을 승인 것과 나란히 놓고 눈으로 봐도 같은 걸음이어야 한다.
- 숫자만 통과했다고 완료라고 하지 않는다. 숫자는 큰 실수를 잡는 그물이다. 최종 판단은 사용자가 같은 속도로 재생해서 본다.

**한계.**
- 부위는 색으로 찾는다. 머리카락은 캐릭터별 머리 색조, 피부는 복숭아색이다. 그림체가 바뀌어 머리색이나 피부색이 크게 달라지면 `masks()`의 색 범위를 고쳐야 한다. 134번 새 그림체에서는 그대로 잘 잡혔다.
- 소망 머리카락과 샌들이 같은 갈색이라, 발 쪽 14%는 머리카락에서 뺐다.
