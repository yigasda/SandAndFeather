# 셋소호 동작 제작

사용자가 81번 공통 베이스를 승인하고 아래 18종 바리에이션 제작을 시작하도록 요청했다. 얼굴·몸·손발·의상 기준은 `../directions/common-body-v2-dress-and-profile/`이며, 이전 거절본으로 되돌리지 않는다. 2026-10-10 첫 묶음은 걷기 동작 시안이다. 게임 런타임 적용은 별도다.

## 제작 목록

모든 동작은 앞·뒤·좌·우를 대상으로 한다. 프레임 수와 재생 시간은 동작 검토 후 정하며, 아래는 제작 순서와 상태다. 공격 무기와 고유 기술 연출은 아직 확정하지 않았다.

걷기 다음은 달리기·상호작용·조사, 이후 전투 동작, 마지막으로 상태 전환을 연결한다. 타격/주술 이펙트는 캐릭터와 분리한다. 손발 크기와 세트의 곧은 측면 몸을 유지하며, 호루스 눈 문양은 캐릭터 왼쪽에만 둔다. 좌우 단순 반전으로 문양을 옮기지 않는다.

## 걷기 1차 시안

`walk-v1`은 생성한 포즈를 잘라 정렬한 검토용 결과다. 완성된 게임 애니메이션으로 취급하지 않는다. 발의 앞뒤 교대, 팔의 반대 움직임, 머리/몸 흔들림, 정지 자세와의 연결은 실제 표시 크기에서 후속 검토가 필요하다. 생성 결과에는 얼굴과 의상 주름의 미세한 차이가 있다.

- 원본 시트 3개와 호루스 정면 문양 수정 원본을 보존한다.
- 개별 프레임 36개와 캐릭터별 투명 시트 3개. 각 셀 360×400, 시트 1080×1600.
- 행 순서 앞·뒤·왼쪽·오른쪽, 열은 발 내딛기 A·가운데·발 내딛기 B.
- GIF는 0→1→2→1을 프레임당 180ms로 반복하는 동작 검토용 미리보기다. 접지선 정렬만 하며 이동 거리나 충돌판정은 포함하지 않는다.
- `manifest.json`에 프레임 경로·방향·순서·미리보기 기준점을 기록했다. 기존 게임의 앞·왼쪽·오른쪽·뒤 순서와 다르므로 적용 시 매핑이 필요하다.
- 재현: 저장소 루트에서 `python scripts/art/compose-walk-study.py`.
