## 시안 수정 지침

### 수정 단어 하나에 매달려 전체 시안을 망가뜨리지 않는다

- **해야 할 일은 사용자가 채택한 그림을 유지하면서 원하는 결과를 만드는 것이다.** ‘곧게’, ‘간격’, ‘깊이’ 같은 한 단어를 기계적으로 구현하는 일이 아니다. 문장 전체, 앞선 요청, 실제 최종 시안을 함께 기준으로 삼는다.
- 수정 전후를 같은 표시 크기로 놓고 **목 길이, 머리와 몸 비율, 치마 실루엣, 노출된 다리 길이·굵기, 신발 크기, 도트 명암·외곽선·연결**을 함께 비교한다. 국소 조건을 맞췄어도 원래 캐릭터의 전체 인상이 달라지면 실패다.
- ‘굴곡 없는 다리’는 원본처럼 아담하고 자연스러운 치비 다리라는 뜻이다. 길고 평평한 사각형 기둥을 그리라는 뜻이 아니다. ‘다리 사이 간격 축소’는 허벅지를 붙이라는 뜻이 아니다. ‘깊이’는 얼굴을 다시 디자인하거나 팔레트를 바꾸라는 뜻이 아니다.
- 원본의 부위를 사용할 때 **온전한 형태·명암·외곽선·접합**을 함께 유지한다. 피부 조각, 외곽선, 신발을 따로 잘라 붙이고 수치만 맞춘 결과를 보내지 않는다. 요청이 없는 크기·위치 이동도 임의로 추가하지 않는다.
- 픽셀 차이0·해시 일치는 보존 여부만 보여 준다. **잘 고쳤다는 증거나 시각 검수를 대신하지 않는다.** 알고 있는 깨짐·틈·부조화를 ‘검토본’이라는 이름으로 넘기지 않는다.
- 이미 원하는 최종 정면 원본이 있으면 그 파일을 우선 사용한다. 사용자가 ‘수정 없이 묶어 달라’고 하면 복사·배치·재생만 한다. 실패한 새 버전을 더 최신이라는 이유로 기준으로 삼지 않는다.
- 149 소망의 실패: 목과 다리를 사각형으로 바꿔 원본의 짧은 비율, 자연스러운 옷·신발 연결과 도트 명암을 잃었다. **149는 반려본이며 재사용하지 않는다.** 이후 작업에서 같은 오류를 반복하지 않는다.

- 재작화 요청에도 사용자가 이미 정한 비율·색·그림체·캐릭터 특징을 함께 유지한다. 재작화 허용을 임의의 디자인 변경으로 해석하지 않는다.
