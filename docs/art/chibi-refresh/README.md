# 셋소호 치비 확대 디자인 시안 3종

2026-10-10. 사용자는 기존 게임 스프라이트가 작다고 느끼며 두아트 몬스터·타격 비교본 정도의 표시 크기를 선호했다. 두아트 후속 맵 제작을 잠시 멈추고 치비 디자인을 먼저 검토한다. 각 이미지 왼쪽부터 세트·소망·호루스.

1. trio-v1: 전투 비교본과 가까운 짧은 몸과 선명한 의상 표현. [Drive](https://drive.google.com/file/d/1JSq9UsUludI_mHOonwIeXp-MTeGYQs8Q/view)
2. trio-v2: 머리가 크고 둥근 인형형 비율, 단순한 색면. [Drive](https://drive.google.com/file/d/17geBLzzSagPas19gj3wqMhMKPBzbUWD5/view)
3. trio-v3: 몸과 다리가 조금 길고 의상 디테일이 세밀한 비율. [Drive](https://drive.google.com/file/d/1AIp1eHHL1IbXvtDzQpCz8mN-gBpVHfUc/view)

각 PNG는 투명 배경의 확대 디자인 검토본, JPG는 보기 편한 밝은 배경의 미리보기다. 실제 정규 셀 크기의 걷기 스프라이트 시트가 아니며 아직 어느 시안도 승인되지 않았다. 시안별 그림 크기 자체를 게임 표시 크기로 사용하지 않는다. 선택 후 두아트 비교본의 지도·캐릭터 비율을 기준으로 실제 폰 표시 크기를 함께 확인하고 방향별 프레임·발밑 기준점·피벗을 제작한다.

세트는 긴 직모와 마른 근육, 소망은 시스루 앞머리와 처진 반쯤 감긴 눈·다문 미소, 호루스는 짧은 머리·날개 없음·한쪽 눈장식을 기준으로 삼았다. 눈장식은 이번 세 시안의 화면 오른쪽 눈 아래로 맞췄으며 방향별 스프라이트 제작 시 실제 얼굴의 동일한 쪽에 유지한다. 최종 프레임 제작 때 머리 길이와 장식 색·의상 디테일도 선택 시안 기준으로 통일한다.

게임 코드, 기존 pocket-chibi.png, 정밀 미니 초상화, 맵 데이터는 변경하지 않았다. 승인 전에 게임에 적용하지 않는다. 새 이미지·새 문서만 추가해 오푸스의 진행 중인 구현과 파일 범위를 분리했다.
