# 셋소호: 새 참고 그림체 시안

2026-10-10. 사용자가 직접 제공한 호루스·세트·소망 세 장을 그림체와 체형의 최신 기준으로 삼은 시안. 이전 `body-trials`의 다섯 체형보다 이 방향이 우선한다. 아직 사용자 검토 전이며 게임 적용 승인이 아니다.

- 큰 둥근 머리, 작고 가는 몸, 짧은 손발, 얇은 선과 부드러운 색면.
- 세트: 다크 크림슨의 차분한 긴 생머리, 근육선을 생략한 몸, 차콜 치마와 얇은 금색 허리끈, 한쪽 트임과 작은 중앙 금장식.
- 소망: 반묶음 없는 느슨한 곱슬머리와 시스루뱅, 레이스 상의와 목선의 흰 끈리본, 긴 아이보리 드레스.
- 호루스: 차분한 눈매와 짧은 남색 머리, 세트와 맞춘 피부색. 작은 두 갈래 금색 눈장식이 목표이나 이 시안의 세로 획은 회색으로 보여 후속 제작에서 금색으로 통일할 필요가 있다.

`trio-v1.png`는 투명 배경 원본, `trio-v1-preview.jpg`는 모바일 확인용 밝은 배경이다. 왼쪽부터 세트, 소망, 호루스. 스프라이트 애니메이션이나 방향별 완성 에셋이 아닌 외형 검토용 시안이다.

## v2: 소망 앞머리와 곱슬 끝 수정

사용자가 v1의 그림체를 좋아하며 소망의 시스루뱅과 가볍고 퐁실한 곱슬 끝을 요청했다. `trio-v2-somang-hair.png`는 해당 머리 부분을 수정한 최신 검토 시안이며, JPG는 밝은 배경 미리보기다. 가는 앞머리 사이로 이마가 비치게 하고 머리 끝을 분리된 느슨한 컬로 표현했다.

## 소망 v3: 사용자 새 참고 우선

소망 v2의 옷, 눈매, 머리가 원하는 모습과 다르다는 사용자 피드백으로 새로 제공된 두 장 중 첫 번째 그림을 기준으로 변경했다. 해당 그림의 나른하고 반쯤 감긴 처진 눈매, 자연스러운 곱슬, 느슨하게 주름 잡힌 아이보리 드레스와 목의 흰 끈리본을 따르되 머리 길이만 가슴까지 줄인 단독 시안이다. 이전 소망의 둥글고 크게 뜬 눈, 머리 리본 장식, 별자리 치맛단을 다시 넣지 않는다. 세트와 호루스 시안은 이번 수정 대상이 아니다.
