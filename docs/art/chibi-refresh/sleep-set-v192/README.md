그리기 전 확인서는 사용자 'OK, 시작해'로 승인되었다. 그 뒤 머리 참조를 같은 방향 정지로 맞추고, 귀 앞 다발의 끊김을 따라하지 않으며 잠자리 위로 갈래가 펼쳐지도록 반영했다. 정지 조각을 붙이지 않고 네 장을 새로 그렸다.

검사 수치와 별개로 프레임 사이 눈선·발의 작은 재작화 차이, 자동 옆머리 크기 탐색과 가이드의 차이는 visual-notes에 기록했다. 완전 일치/채택으로 표시하지 않는다.

최신 검수의 걷기→정지→잠들기 이어 보기: [정면 GIF](review/set-sleep-chain.gif), [옆 GIF](review/set-sleep-side-chain.gif). 같은 이름의 -game.gif는 검사 도구의 nearest 축소이며 previews/31px 재생본은 실제 렌더러 방식으로 축소했다.
