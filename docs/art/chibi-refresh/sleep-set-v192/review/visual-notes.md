# 직접 본 내용과 남은 차이 — 192

- 정면·옆 모두 정지/걷기와 같은 배율로 나란히 열었다. 정면은 가운데 가르마와 붉은 하이라이트 띠, 옆은 귀 뒤로 드러나는 귀와 얼굴 앞 다발을 기준으로 봤다. 잠자리 위로 긴 끝 갈래가 퍼지고, 귀 앞 다발은 끊기지 않는다. 일정한 평행 줄 대신 굵기가 다른 흐름으로 그렸다.
- 호루스191과 실제 RGB 50% 겹침을 열어 확인했다. 정면 허리·허벅지·샌들 위치가 가까우며 세트 치마는 고유 치마 모양 때문에 끝선까지 같지는 않다. 정면 샌들 갈색 영역 좌우는 2~4px, 아래 끝은 2px 차이다. 옆도 무릎과 종아리·발이 가까우며 좌우 3~4px, 아래 끝 2px 차이다. 긴 머리까지 포함한 전체 onion 차이율을 몸 일치율로 쓰지 않았다.
- 밝은 배경·어두운 배경과 목/귀 앞 확대에서 사각 합성 자국·분리된 픽셀을 확인했다. 마지막 발견한 고립 픽셀 2개는 제거했다. 네 PNG 모두 불투명 영역이 한 연결 성분이고 캔버스 끝에 닿지 않는다.
- 정면 x=310 비교선과 배꼽(310,450)을 표시했다. 옆 기준점은 (315,445)다. 정면은 무릎을 세우지 않고 샌들 밑창이 보인다.
- 자동 머리 탐색은 옆모습을 약84%로 잡았다. 펼친 머리 내부 가닥에 맞춰지는 차이가 있어 100% 원본 크기의 기울인 머리 가이드도 직접 겹쳤다. 바깥 정수리와 얼굴 쪽 경계를 비교했지만 픽셀 단위로 정지와 완전히 같은 크기라고 단정하지 않는다. 자동 측정값을 숨기거나 수정하지 않았다.
- 0↔1의 외곽선 변화는 정면9.3%, 옆6.8%이며 박스도 다르다. 31px 렌더링 두 프레임에서 어깨·팔·머리 갈래 변화가 보인다. 다만 이는 외곽선 전체 변화율이지 가슴만6~8px 움직였다는 증거는 아니다.
- 남은 차이: 전체 재작화의 영향으로 감은 눈선·베개 쪽 머리·발도 완전히 고정된 픽셀이 아니다. 정면 발끝은 프레임 사이5px, 옆은3px 차이다. 요청의 '감은 눈/다리는 그대로'를 픽셀 단위로 충족했다고 보고하지 않는다. 또한 원래 정지보다 세부 음영이 매끈한 부분이 있다. 사용자 채택 전 게임 적용 대상에 넣지 않는다.
- 호루스191와 소망의 보존 대상은 SHA256 전후가 모두 같다. 런타임 파일은 고치지 않았다.

최신 main의 chain도 추가했다. 걷기→정지→누운 그림은 전환 중간 자세를 그린 것이 아니라 요청된 누운 두 장으로 전환되므로 서기에서 눕기까지 연속 동작이라고 보장하지 않는다. 정면에서 머리가 퍼지며 외곽 폭이 커지고 세부 음영은 정지보다 매끈해지는 차이를 확인했다.

검사 도구는 side 이름을 chain 생성에서 건너뛰므로, 같은 chain 함수를 right 방향으로 따로 실행해 옆 이어보기 GIF·시트를 추가했다. 검사 본체를 수정하지 않았다.
