# 155 — 호루스 정면 수정 및 걷기 12장 묶음

검토본. 게임 미적용. 사용자의 최신 요청으로 걷기 전 방향 PNG와 GIF를 함께 전달한다.

- `walk/`: 360×400 PNG 12장. 정면3장은 이번 수정본, 뒤·좌·우9장은 채택된 `review-trio-walk-v5/walk/` 원본 그대로다. 뒤·옆 헤어를 이번 정면에 맞추는 후속 작업은 아직 완료가 아니다.
- 정면: 왼쪽 외곽을 사용자 수정도의 굵은 꺾임에 맞춰 수정. 이마 높이를 기준으로 짧고 두툼한 헤어에 맞는 큰 갈래로 안쪽 경계를 정리했다. 예전의 자잘한 이마선을 재사용하지 않는다. 피부 안의 기존 헤어 경계 잔여색을 제거했다.
- 몸: 최신 지시대로 기존 정면 걷기 몸으로 복원. 다리 피부 구간에서2px 축소, 아래 신발은 이동. 얼굴 이목구비는 보존.
- `native/`, `idle/`는 정면 걷기1 몸을 사용한 외형 확인용이다. 승인 정지 자세나 새 정지12장으로 취급하지 않는다.
- 재생: 0→1→2→1, 프레임180ms. 기존 정면 전체 셀 이동(1,0),(0,-1),(-1,0),(0,-1) 유지. 다른 방향 추가 이동 없음.

## 확인

정면 머리·귀 위 확대,12장 밝은/어두운 배경 시트를 직접 확인했다. 정면의 보호된 얼굴 영역 차이0, 왼쪽 머리·귀 위의 작은 내부 투명 구멍0. 뒤·옆9장은 원본 해시와 동일. `validation.json`에 기록했다.

sprite-check는 정면 다리 단축에 따라 다리·신발/치맛단 측정 항목을 ‘다름’으로 출력한다. 자동 품질 통과라고 주장하지 않는다. 리포트는 `walk/sprite-check/`에 있다. GIF는 이12장만을 사용해 생성했으며4프레임/720ms 메타데이터를 확인했다.
