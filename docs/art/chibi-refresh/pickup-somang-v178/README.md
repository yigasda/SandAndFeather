머리카락 폭은 원본 대비 약98.6~101.1%. 발·바닥에 닿는 손을 기준선 위에 놓고 머리는 쪼그린 몸과 함께 아래로 이동한다. 출력에서 손이 발보다 화면 앞으로 오는 위치도 함께 확인했다.

완전히 쪼그린1의 키: 정면437px(75.9%), 뒤411px(71.4%), 왼쪽395px(68.6%), 오른쪽418px(72.6%). **정면은 요청한65~70%보다 높게 남아 있다.** 이 차이를 검사 통과로 숨기지 않는다.0은 내려가는 중간 단계로 정지의 약82~86%다.

## 원본과 직접 비교

`final/somang/`의 정지151·걷기163을 열고 방향별 pose-guides를 밑그림 참조로 사용했다. 좌우를 뒤집지 않고 각각 그렸다. 머리카락 폭을 같은 방향의 원본에 맞춰 전체 그림을 균등 배율로 정렬했으며, 키를 맞추려고 머리만 줄이지 않았다. 머리·얼굴이 움직이는 자세이므로 원본 픽셀과 동일한 그림이라고 주장하지 않는다.

밝은·어두운 배경에서 정지와 걷기를 나란히 놓고 머리 폭·팔 길이·피부와 아이보리 옷 톤을 직접 보았다. 머리 아래 목, 소매, 손목, 치마와 접힌 다리 경계를 확대해 선 끊김·틈·떠 있는 점을 확인했다. 내보낼 때 투명 여백의 별도 조각을 제거하고 낮은 알파를 정리했다. 새 자세의 곡선과 명암은 이미지 생성으로 그렸고, 배율·투명 캔버스 배치와 시트·GIF 제작은 별도 처리했다.

`fit-scale.py` 및 `check-sprite.py`의 원래 리포트를 `checks/`에 보관했다. 모두 서 있는 키·머리 위치와 다른 자세여서 자동 판정을 완성 근거로 삼지 않았다. check-sprite는 두 그림의 전체 키를 같게 정규화한 뒤 머리 폭을 비교하므로 쪼그림·누움에서 머리 비중이 커지는 차이가 포함된다. 머리의 실제 출력 폭·기준점은 별도 JSON으로 남겼다.
