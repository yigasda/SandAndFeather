# 146 — 새 그림체 정지12장 검토 묶음

상태: **셋소호 × 앞·뒤·좌·우 12장 제작. 전체 세트 사용자 검토 대기. 게임 미적용.**

소망 정면 첫 샘플에 대한 사용자 답변: “다리가 걷기보다 굵은 것만 수정하고 나머지 11장 ㄱㄱ”. 정면 다리·샌들 가로폭을14% 줄여 반영했다. 이 답변을 나머지11장 완성본의 최종 채택으로 확대하지 않는다.

## 실제 사용할 파일

- `idle/{set,somang,horus}-{front,back,left,right}.png`: 전달용 투명 RGBA PNG12장,620×720.
- `manifest.json`: 파일별 크기·발 기준점·기준 키·알파 경계·해시. **이 명세를 따른다.**
- `native/`: 위와 같은 그림을 걷기 원본과 같은360×400 캔버스에서 작업한12장. 별도 시안이나 다른 그림체가 아니다.
- `sheets/`: 전달 PNG를 방향 순서대로 모은 시트3장. 편집은 개별PNG에서 시작한다.
- `previews/146-trio-idle-12-review.png`: 전체12장 보기.
- `previews/146-trio-idle-walk-check.gif`: 정지1초 → 채택 걷기0→1→2→1(각180ms) 비교. 호루스 정면의 기존 셀 오프셋도 적용했다.
- `sources/`: 생성·제작 자료. 전달 원본이나 최종 선택지로 사용하지 않는다.

## 그림 기준

기준은 `../review-trio-walk-v5/walk/`의 채택36장(소망·호루스135, 세트136, 소망144 접합 보수). 전 방향·전 프레임을 원본으로 구성된 시트에서 대조하고, 직접 편집하는 중간 프레임12장은 개별PNG를 열어 확인했다. GIF에서 프레임을 다시 추출하지 않았다.

- 얼굴·머리 상단: 방향별 채택 걷기 실제 픽셀을 보존했다. 호루스 머리 크기를 다시 키우거나 눈을 재작화하지 않았다.
- 세트·호루스: 채택된 상체·옷은 보존하고, 두 발을 딛는 정지 다리를 연결했다. 세트는 머리 뒤에 남은 이전 발 외곽선도 정리했다.
- 소망: 정면은 얼굴·머리·상체·팔을 보존하고 치맛단과 두 발을 디딘 다리를 연결했다. 뒤·옆은 가라앉은 옷과 편히 내린 팔의 정지 몸통에 기존 머리를 연결했다.
- 새로 그린 영역의 색은 해당 캐릭터 채택 원본 몸통에서 추출한 실제 색으로 맞췄다.
- 이전 `../approved/idle/`12장은 자세 참고용으로 보존한다. 새 정지나 새 걷기와 혼합 적용하지 않는다.

## 크기와 게임 연결 — 반드시 읽기

| 종류 | 캔버스 | 발 기준점 | referenceVisibleHeight |
|---|---|---|---|
| 이 패키지 전달 PNG |620×720|(310,662)|**576**|
| 이 패키지 native 작업본 |360×400|(180,370)|330|
| 채택 걷기 PNG |360×400|(180,370)|330|

**기존 정지의628을 하드코딩하지 않는다.** 걷기 세트의 세트 긴 머리는 정면x352, 오른쪽 보기x4까지 퍼져 있다.628/330으로 확대하면서620×720·pivot310을 유지하면 머리끝이 잘린다. 외형을 찌그러뜨리거나 방향마다 다른 배율을 쓰지 않기 위해12장 모두 같은576/330 배율로 배치했다. 캔버스는620×720, 발 기준점은310,662를 유지했다.

게임 표시 크기는 `원하는 표시 키/referenceVisibleHeight`로 맞추면 걷기와 동일하다. native12장을 직접 쓰는 경우에는 걷기와 같은360×400·pivot180,370·기준 키330을 사용한다. 두 해상도에서 그림이 달라지는 것이 아니다. 실제 알파 높이로 캐릭터마다 다시 정규화하지 않는다(특히 호루스의 채택된 작은 머리 비율 유지).

아직 검토본이므로 `runtimeEligible:false`다. 사용자가 전체 세트를 채택한 뒤 오푸스가 적용한다. `approved/manifest.json`의 이전 정지 입력을 다시 활성화하지 않는다.

## 확인한 내용

-12장 전부 밝은/어두운 배경, 목·어깨·머리 아래·옷자락·다리 경계를 확대해 확인.
- 같은 배율의 걷기/정지12방향 비교, 발 기준점과 원본 비율 확인.
- 모든 프레임의 보존영역 픽셀 차이0. 범위는 `validation.json`에 프레임마다 명시.
- 원래 채택 걷기36장 해시 전부 일치. 원본 파일은 수정하지 않았다.
- PNG12장 크기·투명도·개수·해시·클리핑 검사. GIF 프레임과 지연 시간 검사.
- 게임 실행 검증은 하지 않았다. 오푸스의 게임 적용 작업은 별도다.

## 재현

순서대로 실행한다.

```sh
node build-sample.cjs
node build-remaining.cjs
node finish.cjs
```

`build-sample.cjs`는 사용자 첫 샘플 확인 후 수정한 소망 정면을 만든다. `finish.cjs`가 최종 전달 크기·명세·전체 비교 이미지를 만든다. 최종 납품은 `idle/`와 그 manifest다.
