# 09 모래에 잠긴 옛 성소 — 낮 시안

1 왼쪽 붕괴·오른쪽 벽화. 2 오른쪽 모래 유입·왼쪽 벽화. 3 넓은 정면 마당·오른쪽 받침. 4 비스듬한 마당·오른쪽 벽화.

모두 미채택. 실제 출력 전체를 직접 확인했다. 지붕·앙크·인물·UI 없음. 기둥과 받침 주변이 열려 있다. 4는 다른 시안보다 회전된 구도이며 요청한 4개 독립 기둥 대신 3개가 두드러진다. 문양은 원·물결·삼각형의 자리표현으로 퍼즐 정답 체계는 미확정. 2의 발굴부는 얕은 구멍 형태로 표시되어 후속 상태 분리가 필요하다. 원문은 공통 1개와 배치 차이만 prompt.json에 보존.

실제 캐릭터 배율·충돌·조사·가림·낮밤·오브젝트 분리는 미검증. Drive 업로드 없음. 다음은 사용자 채택·수정 지시.
