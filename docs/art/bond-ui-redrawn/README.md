# 인연과 유대 — 사용자 채택한 새 UI 파츠

사용자 지시: “그림을 바탕으로 최대한 비슷하고 닮은 ui 하나하나 다시 그려 ... 배경부터 모서리 버튼 아무튼 모든 세세한 거 전부 다”.
채택·적용 지시: “잘 할 수 있었잖냐 하아 자 바꾸렴”.

원본 캡처를 잘라 만든 구버전과 별개로 이미지 생성으로 새로 그린 64개 파츠다. sources/에 생성 원본 두 장을 보존했다. 개별 RGBA PNG는 `data/art/ui/bond/redrawn/`, 출처·크기·해시는 같은 폴더 manifest.json. 원본 시트 분리 시 옆 칸의 작은 고립 조각을 제거했다. 글자와 숫자는 그림에 포함하지 않았다. 게임은 이 개별 PNG들을 직접 사용한다. 종이 바탕은 승인 그림 49의 테두리를 제외한 내부를 별도 타일로 사용한다.

Drive 개별 PNG 64개(압축 없음): https://drive.google.com/drive/folders/1j0lfbXrQ39zYx2-N6Pe6YedeyZTgtwPv

0.9.65: 실제 게임의 제목, 동물 탭, 기록 카드, 게이지, 상자, 슬롯, 버튼, 활동, 깃털·수첩 파츠 교체. 이전 CSS 중복 덮어쓰기를 정리했다. 412px에서 활동 그림과 제목을 나란히 놓고 카드 높이를 줄였다. 320px 활동은 2열, 데스크톱은 기록/유대 2열. 모든 기록·수량·점수·선택 상태는 실제 HTML과 게임 데이터다. 기존 저장 구조와 점수·승인 규칙 변경 없음.

실제 기록에 빵/팔찌/별 내용이 있으면 해당 승인 장식 삽화를 사용하고, 해당하지 않으면 책 아이콘을 사용한다. 삽화 때문에 사실이나 감정을 추가하지 않는다. 선물 화면의 빵·화환·청련은 채택된 새 UI 그림을 사용하고 다른 물건은 기존 아이템 그림을 유지한다. 원래 아이템 파일을 변경하거나 새 아이템을 등록하지 않았다.

## 확인

`docs/bond-ui/0965-screenshots/`에 실제 320/412/1280, 밝음/어두움, 내부 스크롤과 보조 전체 콘텐츠 캡처. verification.json은 다섯 테마×밝음/어두움×세 화면 크기, 탭 전환, 게이지 0/12/100, 선물 소비·재선물 확인. 맵·기존 UI·기존 테마 검사도 실행했다. 예시 기록·점수는 테스트에서만 사용하고 종료 시 복원한다.

직접 본 것: 새 동물·연꽃·책·활동 그림이 읽히고, 제목과 두 탭이 같은 프레임 안에 있으며, 기존 0.9.64의 반복된 종이 테두리와 반쯤 잘린 구분 장식을 제거했다. 새 파츠를 쓰는 재작화이므로 원본 픽셀과 동일하지 않다. 실제 데이터의 내용과 가방 종류는 참조 예시와 다르다. AI 분석·원문 관리 메뉴도 기능 보존을 위해 유지한다.
