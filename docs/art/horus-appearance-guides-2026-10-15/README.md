# 호루스 원본·외형 가이드

사용자 요청으로 작업 중 사용했던 기존 가이드 파일과 원본 그림 한 장을 모았다. 자세·동작 도식은 제외했다. 새로 그리거나 리사이즈하지 않고 원본 파일 그대로 보존했다.

각 폴더에는 기존 눈·머리 크롭과 색상·좌표 기록도 포함한다. 내부 JSON의 절대 경로는 제작 당시 출처 기록이며 현재 실행 경로가 아니다. 최상위 manifest는 이번에 보관한 파일별 경로와 SHA-256을 기록한다. 가이드에 보이는 표정과 동작은 외형·비율 비교를 위한 원본이며, 새 전투 적용 목록으로 취급하지 않는다.

전투 전달본은 [최종 채택 18장](../horus-combat-approved-18-2026-10-15/README.md)을 사용한다. 삭제한 구 전투 12장이나 자세 도식은 다시 추가하지 않았다.

자세 가이드는 후속 요청에 따라 [별도 폴더](../horus-pose-guides-2026-10-15/README.md)에 보관했다.
