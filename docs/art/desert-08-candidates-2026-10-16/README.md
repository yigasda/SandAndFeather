# 08 사막 대상의 쉼터 — 낮 시안 4개

07 시안 2 채택 후 사용자 요청에 따라 08 낮 시안 4개 제작. 모두 미채택·런타임 미적용·Drive 업로드 없음.

1 왼쪽 판매대, 오른쪽 작업대, L형 건물.
2 오른쪽 판매대, 왼쪽 작업대, 긴 후면 벽.
3 중앙 판매대, 오른쪽 작업대, U형 마당.
4 왼쪽 건물과 앞쪽 작업대, 오른쪽 휴식 벤치, 비대칭 마당.

실제 본 참고: 우물마당 낮, 부엌 낮, 04 채택 사막. 화풍·재질·도기·목재 표현과 모래의 연속성을 참고하고 원래 장소의 가구 배치를 복사하지 않았다. 정확한 참고 순서와 호출은 requests.json.

전체 출력 직접 확인: 차양 각 1개, 비어 있는 복원 작업대, 별도 휴식 벤치, 모래 마당과 넓은 출입 틈이 보인다. 앙크·인물·UI는 보이지 않는다. 1의 후면 틈에는 세워둔 판재, 4의 건물 틈에는 짐이 보여 보관용 공간처럼 읽힌다. 건물 내부 진입 기능을 추가한 것은 아니다. 의뢰함은 작은 나무 상자 형태이며 기능·식별성은 아직 미검증이다. 일부 차양 아래 상인 위치의 가림은 실제 캐릭터를 놓고 확인해야 한다. 벽·모래가 비슷한 따뜻한 계열로 그려졌으며 정확한 재질 대비는 채택 이후 필요에 따라 조정한다.

실제 크기 1774×887 PNG. 캐릭터 배율, 서비스 접근·가림·충돌, 낮밤 정렬은 미검증이다. 물품·NPC·차양 전경 레이어는 아직 분리하지 않은 통합 시안이다. 다음은 사용자 선택·수정 지시.
