# 0.9.64 원본 시안의 실제 게임 적용

사용자 요청: “게임 구현 해봐”. 모바일 B 원본과 원본 추출 조립 시안을 바탕으로 기존 기능의 화면을 교체했다. 신규 이미지 생성 없음. 원본 39개 파일은 변경하지 않았다.

- `data/art/ui/bond/exact/`: 원본의 프레임, 종이, 목재, 탭, 슬롯, 버튼, 동물 상징. 출처 좌표와 SHA256은 manifest.json. `tools/bond/extract-runtime.py`로 재현.
- 동물은 탭 장식이다. 승인된 캐릭터 초상화 파일은 변경하지 않았다.
- 모든 글자·기록·수량·점수는 기존 코드와 상태에서 출력한다. 분석·직접 기록은 접이식 메뉴에 보존했다. 저장 구조와 AI·유대 규칙 변경 없음.
- 320/412는 세로와 내부 스크롤, 1280은 기록/유대 2열. 본문을 통째로 이미지화하거나 스크린샷을 클릭 영역으로 덮지 않았다.
- 실제 브라우저 30조합: 5테마×밝음/어두움×3폭. 탭, 가로 넘침, 내부 스크롤, 게이지 0/12/100, 첫 선물 소비와 재선물 확인 검증. `0964-screenshots/verification.json`.

## 직접 확인한 차이와 제한

원본의 나무 제목면, 금빛 바깥틀, 동물 탭, 파피루스 카드와 갈색 버튼이 실제 게임에서 연결된다. 원본보다 글자를 읽기 쉽게 유지해 모바일 내용이 더 길고, 작은 화면의 활동 카드는 아이콘 위·글자 아래다(320에서는 2열). 기록 카드에 임의의 팔찌/빵 삽화나 관계 감정을 추가하지 않고 책 아이콘과 실제 승인 기록을 표시한다. 가방 아이템도 기존 승인 PNG를 사용하므로 시안의 예시 물건과 다르다.

원본 JPEG의 가장자리 번짐은 남는다. 동물 상징은 원본 RGB를 보존하고 외곽 알파를 분리했다. 종이·목재는 글자 없는 부분을 반복하며, 테두리 중앙과 모서리를 분리했다. 반응형이므로 원본 캡처와 픽셀 단위 동일하지는 않다.

스크린샷의 12점·기록·물건은 시험용 메모리 데이터이며 테스트 종료 시 복원한다. 실제 신규 세이브에 넣지 않았다. `*-game.png`는 실제 900/1000px 화면, `*-full-content.png`는 내용 확인을 위해 세로가 긴 브라우저에서 캡처한 보조 이미지다.
