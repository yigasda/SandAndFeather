# 시각 요소 점검표

최종 화면 설계는 Drive 3장. 원본 시트는 제공되지 않아 확보된 원본 추출 PNG를 먼저 대조했다. 단순 선·글자·상태만 코드로 표현한다.

| 요소 | 상태 / 사용 파일 | 차이·품질 |
|---|---|---|
| 나무·금빛 외곽 틀 | 기존 PNG `main_window_frame`의 직선/모서리 분리 조립 `window_border` | 9-slice, 모서리 고정 |
| 제목줄 프레임·질감 | 기존 PNG에서 `header_border`, `header_texture` 분리 | 중앙만 반복, 원본 보존 |
| 제목 양옆 연꽃 | 기존 PNG에서 `title_lotus` 추출 | 제목 폭에 따라 찌그러지지 않음 |
| 제목 새 두 마리 | 미리보기 추가 추출 `header_birds` | 원본 JPEG 가장자리 번짐 |
| 앙크 장식 | 기존 PNG `ornament_ankh` | 종횡비 유지 |
| 닫기 X | 미리보기 추가 추출 `header_close` | 원본 배경 포함, 기능은 버튼 |
| 세트·호루스 탭 프레임 | 기존 PNG에서 `tab_active_frame`, `tab_idle_frame` | 상태와 이름은 코드 |
| 탭 동물 얼굴 | 기존 승인 초상 `portraits/set-bust`, `horus-bust` 사용 | 사용자 지시대로 공식 초상 우선, 동물형 얼굴과 다름 |
| 발자국·새 상징 | 미리보기 추가 추출 `tab_paw`, `tab_bird` | 인물 초상과 별도 장식 |
| 탭 아래 금빛 구분 | 코드 선 + 기존 탭 테두리 | 복잡한 장식 새로 그리지 않음 |
| 인연의 기록 책 | 미리보기 추가 추출 `section_book` | 축소, JPEG 번짐 유지 |
| 오늘부터 쌓는 유대 식물 | 미리보기 추가 추출 `section_plant` | 원본 색 유지 |
| 선물하기 작은 상자 | 미리보기 추가 추출 `section_gift` | 원본 색 유지 |
| 함께하는 활동 나뭇가지 | 미리보기 추가 추출 `section_branch` | 원본 색 유지 |
| 종이 바탕·질감 | 기존 PNG에서 `paper_tile`, `record_texture` | 타일은 원본 무문자 부분 |
| 기록 카드 금빛 코너 | 미리보기 추가 추출 `record_corner_*` | 단순 테두리는 코드, 코너 고정 |
| 기록 날짜·내용·구분 | 코드 | 승인한 기록만, 감정 예문 자동 삽입 없음 |
| 기록 아이콘 배경 | 코드 단색 바탕 | 원본의 직사각 배치 유지 |
| 기록별 팔찌·빵·별밤 예시 삽화 | 실제 기록에는 책 아이콘 사용 | 원문에 없는 물건/장면을 붙이지 않음. 새 아이템 생성 없음 |
| 게이지 하트·틀·채움 | 기존 PNG `bond_heart`, `bond_bar_gray_frame`, `bond_bar_pink_fill` | 실제 0~100 값은 코드 |
| 단계별 상자 | 기존 PNG `reward_gift_red`, `reward_gift_open`, `reward_gift_gold` | 숫자/연결선/달성 상태는 코드 |
| 선물 슬롯·선택 틀 | 기존 PNG `gift_slot_normal`, `gift_slot_selected` | 수량 오른쪽 아래 코드 |
| 슬롯 속 물건 | 기존 승인 `data/art/items/` | 실제 가방 UID, 예시 물건으로 새 등록하지 않음 |
| 선물 버튼 | 기존 PNG `button_brown`, `gift_icon_bow` | 글자 코드, 예시의 흰 상자 대신 원본 컬러 상자 |
| 낚시·요리·공부·탐험 | 기존 PNG에서 `activity_*_icon` 추출 | 주변 카드만 알파 제거 |
| 활동 카드·우측 화살표 | 단순 테두리·간격·화살표 코드 | 320px 2×2, 그 밖 4열 |
| 하단 깃털 | 미리보기 추가 추출 `footer_feather` | 그림 재제작 없음 |
| 하단 작은 파피루스 안내판 | 기존 종이 질감 + 미리보기 코너 + 코드 글 | 고정 감정/관계 서술 없음 |
| 추억 수첩 버튼 | 기존 PNG에서 `memory_border`, `memory_texture`, `memory_book_icon` | 장식과 중앙 분리, 글은 코드 |
| 데스크톱 세로 구분·모바일 가로선 | 코드 | 단순 선, 두 열/한 열 구조 |
| 분석·검토·원문관리 | 코드로 추가 | 미리보기에 없는 승인 절차 기능 |
| 바깥 HUD·맵·미니맵·하단 탭 | 기존 승인 게임 그대로 | 미리보기의 새 배경/HUD로 바꾸지 않음 |

## 추출 한계

`SOURCE_ORIGINAL_UNCHANGED.png` 부재로 전체 시트 재추출은 하지 못했다. 이미 있는 39개 PNG는 전부 보존했다. 미리보기에서 추출한 작은 장식은 원본 JPEG의 가장자리 압축을 포함한다. 단순 확대·필터로 완전한 도트로 만들었다고 보고하지 않는다. 가려진 픽셀을 새로 그리거나 생성 AI로 보완하지 않았다.
