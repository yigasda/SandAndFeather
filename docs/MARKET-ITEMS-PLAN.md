# 시장 새 아이템 설계 (승인 전 — 아직 게임 데이터에 없음)

이 문서는 기획이다. 여기 적힌 id는 `data/items.json`에 아직 없다. 사용자가 승인한 것만 등록한다. 그림은 사용자가 따로 만들고, 받으면 `data/art/items/<id>.png`와 `src/ui/itemart.js`의 `OWN`에 넣는다. 그림이 오기 전에는 이모지로 둔다.

기준: 0.9.60(기존 34종 시장 확대). 선물·호감도 같은 새 시스템은 만들지 않는다. 새 상호작용이 필요하면 아래 「필요한 작은 규칙」처럼 따로 승인받는다.

### 시장 진열(1차)

- 늘 파는 것: 식재료·향신료 10종, 향 3종, 생활 잡화 5종.
- 수량 한정:
  - 향유 2종과 콜(`stock: 2`)
  - 장신구 3종(`stock: 1`, 하루 50% 확률로 1~2종만 들어옴)
- 품절에서 빼는 것: 없음. 새 아이템은 기존 진행에 꼭 필요하지 않다.

## 2. 필요한 작은 규칙 (각각 승인 후 구현)

| 번호 | 규칙 | 바뀌는 곳 | 데이터 |
|---|---|---|---|
| R1 | 요리 재료를 대신 쓸 수 있다: `needs: [{ "any": ["salt", "cumin"] }]`. 같은 요리가 나온다 | `kitchen.js pickFor`, `check.js` | `recipes.json` |
| R2 | 제단 「향 올리기」: 향을 하나 쓰면 신전 일 돕기가 기운 1. 장신구는 「바치기」: 신앙 +1, 하루 한 번(`ledger` once) | `growth.js shrine` | `items.json`의 `offer: { sun, xp, faith }` |
| R3 | 날로 먹는 것: `food` 필드가 있으면 kind가 food가 아니어도 음식이다(두아트 챙김, 거래 모험의 "음식 하나"). 요리 도감 분류는 그대로 | `duat.js prep`, `engine.js bring` | `items.json`의 `food: { heal, fear }` |
| R4 | 두아트 챙김: 음식처럼 두 칸에 넣어 가서 「쓰기」(바르기·감기·켜기) | `duat.js` | `items.json`의 `duat: { heal, fear, onEnter }` |
| R5 | 축제 준비에서 다른 것으로 대신 내기: `need` 하나에 `or`를 둔다 | `festival.js`, `check.js` | `festivals.json` |
| R6 | 필사실 공부 도구: `study: { sun: -1, use: true }`(빈 파피루스, 씀) / `study: { xp: 1 }`(갈대 붓, 안 닳음) | `growth.js scriptorium` | `items.json` |

규칙 하나하나는 기존 기능을 넓히는 데서 그치고, 새 화면이나 새 관계 수치는 만들지 않는다. 동행·추억·업적과는 `facts`/`tally`로만 이어진다(buy, cook, offer 등 행동 이름).
