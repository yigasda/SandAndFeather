# 현재 작업 — 압축 후 먼저 확인

갱신: 2026-10-14. **몹 추가 제작은 보류. 호루스 새 외형 채택본 51장을 개별 PNG로 보관.**

최신 호루스 작업: [채택본·출처·남은 범위](art/horus-redraw-2026-10-14/README.md). 정면 걷기·좌우 정지/걷기·상호작용·앉기·줍기·잠자기·생활·첫 왼쪽 전투 6장이 포함된다. 후속 전투 묶음은 미채택. 게임 적용은 하지 않았다. 사용자가 다시 지시하기 전 재생성을 진행하지 않는다.

| 항목 | 현재 상태 |
|---|---|
| 두아트 맵 | 7장 전부 채택·main 업로드 완료. `세부맵1/두아트/` |
| 고대장치 하위몹 | 고리형·모래시계형 × 5상태 = 10장 채택·main 업로드 완료. `몹/하위몹/고대장치/` |
| 캐릭터 전투 | `메인2/호루스`, `메인2/세트`, `메인2/소망`에 있음. 이전 호루스 17장 재작화 지시는 현재 작업이 아님. |
| 다음 작업 | 사용자 지정 큰 작업으로 이어간다. 몹이나 캐릭터 재작화를 자동으로 시작하지 않는다. |
| 게임 적용 | 별도 필드 전투 계획이 있음. 문서 존재를 적용·검증 완료로 간주하지 않는다. |

**바로 읽기: [두아트 맵·몹 인수인계](ASTRA-DUAT-HANDOFF.md).** 채택 원본, 반려 기준, 디자인·투시·도트, 남은 일과 전달 위치가 정리되어 있다.

게임 적용을 맡았을 때: [두아트 필드 전투 적용 계획](DUAT-FIELD-COMBAT-PLAN.md) → 해당 문서의 시작 절차. 최신 사용자 지시가 작업 범위를 정한다.

그림 작업을 맡았을 때: [MAP](ASTRA-MAP.md) / [SPRITE](ASTRA-SPRITE.md) / [PLAN](ASTRA-PLAN.md)의 해당 절과 채택 원본을 실제로 연다. 오래된 로컬 결과로 최신 main을 덮어쓰지 않는다.
