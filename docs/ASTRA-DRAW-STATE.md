# 현재 작업 — 압축 후 먼저 확인

## 사막 현재 작업

05 시안 1 원본(앙크 포함) 채택. 06은 03에 통합 확정, 03 통합 시안 2 채택. [03 최신 원본](art/desert-03-ridge-approved-2026-10-16/approved-final.png) · [05 원본](art/desert-05-approved-2026-10-16/approved-final.png). 현재 07 오아시스 낮 시안 4개 제작. 채택 그림만 Drive 업로드. 런타임 미적용.

> **압축 후 사막 작업은 [01~04 통합 인수인계](ASTRA-DESERT-HANDOFF.md)부터 읽는다.** 01~04 최종 채택 완료. 정확한 최종 PNG·생성문·참고 원본·실패 교훈·다음 작업 순서는 이 문서가 최신이다. main 전달 대상은 01 최종본, 02 출구 국소 합성본, 03 외곽선 보강본, 04 마지막 시안 채택본이다. 게임 런타임 적용은 미실행.

갱신: 2026-10-15. **몹 추가 제작은 보류. 호루스 새 외형 채택본 51장을 개별 PNG로 보관.**

최신 호루스 작업: 생활·걷기 등은 [기존 채택본](art/horus-redraw-2026-10-14/README.md), 전투는 [최신 채택 18장](art/horus-combat-approved-18-2026-10-15/README.md)을 사용한다. 좌우 지상 찌르기 최종본(1000483187), 새 대기·주문·지침·공중 찌르기와 채택된 약한 피격 후보 2번을 포함한다. 마지막 피격 재시도와 반려된 머리 수정본은 제외한다. 혼동을 막기 위해 이전 전투 12장이 포함된 구 18장 묶음과 구 17장 묶음은 삭제했다. 기존 첫 전투 6장은 원본 채택 폴더에 보존한다. 추가 생성은 종료했고, 게임 런타임 적용은 하지 않았다. 사용자 재지시 없이 재생성하지 않는다.

외형 참고: [원본 그림·비율·색·머리·눈 가이드](art/horus-appearance-guides-2026-10-15/README.md). 자세 도식·표정 분석·제작 스크립트는 [별도 참고 보관함](art/horus-pose-guides-2026-10-15/README.md)에 있다.
