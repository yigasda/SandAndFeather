# 안채 수정본과 낮밤 배경 — 최신 연결 기준

2026-10-10. 사용자의 식사방 창밖·세트 동물·부엌 수정 요청과 빠진 낮밤 버전을 반영했다. 새 8장은 검토용 결과이며 아직 사용자 승인 전이다. 이번 변경은 아트와 문서만이고 실제 게임 연결은 하지 않았다. 이전 PNG·모바일 파일과 기존 게임을 모두 보존했다.

## 최신 성소 v3 — 둥근 코 제거

사용자는 앞선 수정본을 긍정적으로 평가하고 세트 동물 주둥이 끝의 동그란 코만 없애 달라고 요청했다. **성소는 v3을 낮밤 공통으로 사용한다.** 짧은 주둥이 끝까지 같은 석재 면이 매끈하게 이어지며, 별도로 튀어나온 둥근 코와 원형 경계를 제거했다. 귀·꼬리·제단과 성소 구성은 유지하는 국소 보정이다. v3은 새 검토용이며 v2도 이력으로 보존한다.

## 수정 내용

- **부엌 v2 낮·밤:** 중앙 창틀·커튼과 주변 벽 일부를 없애고, 기둥·상부 보·낮은 난간 사이로 넓은 하늘이 보이는 반개방형으로 바꿨다. 화덕의 굴뚝과 오른쪽 선반 지지벽은 남겼다. 사용자가 파란색으로 표시한 앞쪽 왼편에 도마·절구·조리도구 작업대, 오른편에 손으로 물을 채우는 대야·물병·그릇·냄비 작업대를 더했다. 하단 중앙 입구와 중앙 작업대 주위 보행 여백은 남겼다.
- **식사방 v2 낮·밤:** 창문 프레임과 방 가구를 유지하면서 창밖의 빽빽한 야자수 길·회랑 풍경을 없앴다. 넓은 하늘, 낮은 정원 벽, 성긴 초록과 멀리 야자수 한 그루로 간결하게 바꿨다.
- **성소 v2:** 세트 동물 주둥이를 짧게, 끝을 둥글고 뭉뚝하게 수정하고 눈매를 부드럽게 했다. 네모난 귀·갈라진 꼬리·몸·제단은 유지한다. 기존 v1의 긴 주둥이를 복구하지 않는다.
- **우물 마당·열주 계단 밤:** 기존 낮 배치를 바탕으로 밤하늘과 달빛, 주변 따뜻한 빛을 표현했다.
- **지붕 낮:** 기존 밤 배치를 바탕으로 밝은 하늘·낮의 마을과 강 풍경을 표현했다.

## 오푸스 적용 시 유의점

1. 부엌은 v1 대신 **v2 낮/밤 모두 함께** 연결한다. v1 낮과 v2 밤을 섞으면 앞쪽 조리대와 벽이 갑자기 생기거나 사라진다. 식사방도 v2 쌍, 성소는 최신 v3 공통을 사용한다.
2. 기존 부엌 충돌 데이터가 있다면 새 앞쪽 조리대·대야·기둥·낮은 난간에 맞춰 다시 대조한다. 열린 하늘은 이동 출구가 아니다. 난간과 물 대야 내부로 캐릭터가 들어가지 않게 한다. 출입구는 기존 하단 중앙이다.
3. 같은 장면의 시간대 변형은 동일 카메라 배율·충돌·상호작용·출입 좌표를 공유하는 방향으로 연결한다. 이미지 생성만으로 픽셀 단위 정합을 보장하지 않는다. 실제로 겹쳐 비교하고 가구 경계 이동이 있으면 아트 보정이 필요하다.
4. 날짜/시간 상태에 맞는 배경을 선택하되 배경 전환 자체로 날짜·태양 기운·캐릭터 위치·동행 상태를 바꾸지 않는다. 밤 이미지에 전역 어둠 필터를 겹쳐 과도하게 어둡게 하지 않는다.
5. 지붕 ^ 버튼은 기존 규칙대로 열주 계단 앞에서만 사용한다. 낮 계단→낮 지붕, 밤 계단→밤 지붕으로 시간대를 이어준다. 내려오면 같은 계단 위치로 돌아온다.
6. 이미지의 별과 달은 배경 연출이다. 새 달력·달 위상·별자리 퀘스트 조건이 확정된 것은 아니다.
7. 화면 폭 412px에서 캐릭터 배율과 길 폭을 확인한다. PNG를 게임용 가공에 사용하고, 모바일 JPG는 열람용으로만 쓴다.
8. 기존 연결 구조·우물과 연못 분리·성소의 세트 동물·처음 만남 시기 상태는 [기존 안채 연결 지시](MAP-RESIDENCE-NINE-SCENES.md)와 [전체 인수인계](MAP-EXPANSION-HANDOFF.md)를 따른다.

## 확인 범위

각 이미지의 수정 요소와 시간대 표현을 한 장씩 확인했다. 원본 일치·파일 크기·Drive 업로드를 확인했다. 실제 게임에서 낮밤 전환, 충돌, 가림, 저장 복원은 아직 테스트하지 않았다.
