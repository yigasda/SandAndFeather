# 사막 몹 등록표

`python3 tools/maps/desert-mobs.py`가 만든다(손으로 고치지 않는다). 기준: 몹/사막/manifest.json과 종별 manifest(12종 × 10 = PNG 120장, 해시·캔버스 검사함), OPUS 사막 계획서 15·16절, 사용자 보완 지시 1·6·7. 고대장치(몹/하위몹/고대장치, 고리·모래시계 2종 × 10)는 별도 묶음이라 여기 넣지 않는다.

게임 적용 전이다(`runtimeApplied: false`). 아래 피벗·충돌·피격·공격 범위·발사 소켓·표시 배율·가드 규칙은 비워 두고 게임 화면에서 정한다(B3 가죽 방패병부터).

## 별도 효과 그림 (10장에 들지 않음, 120장에 세지 않음)

- 태양거울 beam: [`docs/art/desert-sun-mirror-motion-revisions-2026-10-16/beam.png`](../docs/art/desert-sun-mirror-motion-revisions-2026-10-16/beam.png) 2048×768, sha256 `0b7569d991b5…`, 방향 left-to-right, 발사점 약 [0.13, 0.5](정규화). 별도 레이어에서 발사점으로 위치 정렬 후 공격 방향으로 회전. 길이·충돌·피해·표시배율은 게임에서 설정. 몸 프레임(06·07 light_attack)에는 근접 빛·발사점만 있고 긴 광선은 이 그림이다. 그림을 늘려 벽 뒤까지 보이게 하지 않고, 첫 벽에서 자른다(계획서 16절).

보스 4종: 신전 수문장(T3), 왕면 수문장(P2), 왕좌 수문장(P3, 추천안 P3B 한 개체), 파릉 수문장(P4). 전투 역할 구역 7곳 = 실제 공간 9곳(T1W·T1E, P3A·P3B 분할)이며 34공간에 다시 더하지 않는다. 후보 종은 개체 수·좌표가 아니다.
