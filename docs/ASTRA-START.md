# 아스트라 입구 — 매 작업 여기서 시작

## 읽는 순서

1. 최신 main을 fetch하고 현재 작업과 충돌을 확인한다. 다른 작업을 덮어쓰거나 강제 푸시하지 않는다.
2. [현재 작업](ASTRA-DRAW-STATE.md): 채택·반려 범위, 실제 기준 파일, 완료한 것, 다음 한 단계부터 복구한다.
3. [PLAN](ASTRA-PLAN.md): 이번 동작의 자세·표정·방향·장 수를 읽는다.
4. 캐릭터는 [작화 시작표](ASTRA-DRAW-CHECK.md) → [SPRITE](ASTRA-SPRITE.md)의 해당 외형·실수·채택 자료를 읽고 실제 원본·가이드를 연다. 말풍선·효과도 해당되는 선·색·검수 기준을 적용한다. 맵·배경은 [MAP](ASTRA-MAP.md)을 따른다.
5. [공통 규칙](ASTRA-HANDOFF.md): 요청 범위, 승인, 공통 검수, 저장·전달을 확인한다.

압축 후에는 기억이나 파일 목록으로 확인을 대신하지 않는다. 실제로 본 자료와 사용한 가이드, 생성 요청과 결과 비교를 DRAW-CHECK의 기록에 남긴다.

## 우선순위와 역할

최신 사용자 지시 → 그 범위에 해당하는 최신 채택 기준 → 상세 명세·규칙 순으로 적용한다. 최신 생성본·업로드·main 포함 여부는 채택 증거가 아니다. 구체적인 동작별 예외는 일반 문구보다 우선한다. 실제로 해결할 수 없는 충돌만 사용자에게 확인한다.

| 문서 | 단독으로 관리하는 내용 |
|---|---|
| [STATE](ASTRA-DRAW-STATE.md) | 현재 작업·채택 범위·다음 행동 |
| [DRAW-CHECK](ASTRA-DRAW-CHECK.md) | 실행 절차·작업 카드·생성별 기록 |
| [SPRITE](ASTRA-SPRITE.md) | 외형·작화 상세 기준·실수·채택 파일 |
| [PLAN](ASTRA-PLAN.md) | 동작별 자세·표정·방향·장 수와 향후 명세 |
| [HANDOFF](ASTRA-HANDOFF.md) | 공통 작업 규칙·승인·검수·저장·전달 |
| [MAP](ASTRA-MAP.md) | 맵 규칙·채택 배경 |

이미 승인된 계획은 반복 승인받지 않는다. 지시를 줄이거나 쉬운 작업으로 바꾸지 않는다. 문서 정리 대응표는 [DOC-MAP](ASTRA-DOC-MAP.md). 상세 지침을 이 입구만 읽고 생략하지 않는다.
