# 아스트라 — 여기서 바로 작업

> **압축 후 사막 작업은 [01~04 통합 인수인계](ASTRA-DESERT-HANDOFF.md)부터 읽는다.** 01~04 최종 채택 완료. 정확한 최종 PNG·생성문·참고 원본·실패 교훈·다음 작업 순서는 이 문서가 최신이다. main 전달 대상은 01 최종본, 02 출구 국소 합성본, 03 외곽선 보강본, 04 마지막 시안 채택본이다. 게임 런타임 적용은 미실행.

**현재 작업 → 해당 작업의 채택 원본·명세 → 제작·비교.** 아래 한 경로로 진행한다. 긴 문서를 매번 차례로 순회하지 않는다.

현재 두아트 맵·몹의 채택 상태와 재개 기준은 [두아트 인수인계](ASTRA-DUAT-HANDOFF.md)에 있다. 몹 제작은 사용자 지시로 보류 중이다.

캐릭터 재작화는 사용자 요청이 있을 때만 진행한다. 호루스는 [확정 외형 기준](ASTRA-SPRITE.md#horus-current)과 [현재 원본·가이드](ASTRA-REF-HORUS.md)를 사용한다. 과거 재작화 입력 제한으로 현재 채택본을 되돌리지 않는다.

## 3. 그리기·비교

[짧은 실행 절차와 단일 기록 양식](ASTRA-DRAW-CHECK.md)

최신 사용자 지시가 우선한다. 이미 승인된 계획은 반복 승인받지 않는다. 지시를 축소하거나 최신 생성본을 채택본으로 추정하지 않는다. 원본을 실제로 열지 않았다면 봤다고 기록하지 않는다.

상세 기준은 필요할 때 바로 찾는다: [외형·눈·머리](ASTRA-SPRITE.md) · [자세·표정](ASTRA-PLAN.md) · [가이드 한계·검수](ASTRA-DRAW-REFERENCE.md) · [저장·전달·공통 규칙](ASTRA-HANDOFF.md). 첫 작업·기준 변경 때에는 해당 상세 절을 읽는다. 짧은 입구가 상세 지시의 생략을 뜻하지 않는다.

문서 변경 검토용: [대응표](ASTRA-DOC-MAP.md). 평소 작화에는 읽지 않는다.
