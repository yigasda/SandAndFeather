# 아스트라 — 여기서 바로 작업

**현재 작업 → 해당 캐릭터 원본·가이드 → 작화·비교.** 아래 한 경로로 진행한다. 긴 문서를 매번 차례로 순회하지 않는다.

호루스 재작화는 **채택 대기 0·걷기·정지·잠자기·원본 기반 가이드만** 사용한다. 구 전투 시안은 동세·표정 참고도 금지한다. [입력 제한](ASTRA-DRAW-CHECK.md)을 생성 직전에 확인한다.

## 1. 이번 작업 확인

[현재 작업과 다음 한 단계](ASTRA-DRAW-STATE.md)

## 2. 해당 원본·가이드 열기

| 캐릭터 | 바로 열기 |
|---|---|
| 호루스 | [호루스 원본·가이드](ASTRA-REF-HORUS.md) |
| 세트 | [세트 원본·가이드](ASTRA-REF-SET.md) |
| 소망 | [소망 원본·가이드](ASTRA-REF-SOMANG.md) |

맵·배경이면 [MAP](ASTRA-MAP.md)의 기준 배경과 해당 명세로 간다. 말풍선·효과는 [PLAN](ASTRA-PLAN.md)의 해당 명세와 [SPRITE](ASTRA-SPRITE.md)의 선·색 기준을 사용한다.

## 3. 그리기·비교

[짧은 실행 절차와 단일 기록 양식](ASTRA-DRAW-CHECK.md)

최신 사용자 지시가 우선한다. 이미 승인된 계획은 반복 승인받지 않는다. 지시를 축소하거나 최신 생성본을 채택본으로 추정하지 않는다. 원본을 실제로 열지 않았다면 봤다고 기록하지 않는다.

상세 기준은 필요할 때 바로 찾는다: [외형·눈·머리](ASTRA-SPRITE.md) · [자세·표정](ASTRA-PLAN.md) · [가이드 한계·검수](ASTRA-DRAW-REFERENCE.md) · [저장·전달·공통 규칙](ASTRA-HANDOFF.md). 첫 작업·기준 변경 때에는 해당 상세 절을 읽는다. 짧은 입구가 상세 지시의 생략을 뜻하지 않는다.

문서 변경 검토용: [대응표](ASTRA-DOC-MAP.md). 평소 작화에는 읽지 않는다.
