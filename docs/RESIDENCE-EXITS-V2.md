# 안채 출구 아트 — 오푸스 적용 명세

**동시 작업 반영:** 오푸스의 `be86ecd`(0.9.20)가 기존 9장 출구 아트를 게임에 연결했다. 그 코드·충돌·도착점을 보존했다. 이번 양쪽 확장 우물은 별도 파일 `well-courtyard-expanded-v2.png`, `well-courtyard-expanded-v2-night.png`로 전달하며 **아직 게임 미적용**이다. 게임이 읽는 기존 `well-courtyard-v1(-night).png`는 1774×887 그대로 유지한다. 새 확장본을 연결할 때만 맵 폭과 모든 좌표를 함께 수정한다. [0.9.20 적용 기록](RESIDENCE-096.md).

2026-10-11 최신 후속. **우물 마당은 좌우 확장 검토본**, 연못 낮밤·동쪽 회랑 3장은 `e2a536b` 사용자 채택본을 그대로 유지했다. 나머지 회랑의 기존 상태는 유지한다. 아트 커밋은 게임 적용 완료를 뜻하지 않는다. 이 작업은 런타임을 수정하지 않았다.

우물의 작은 레고 아치, 가구 뒤에 떠 보이는 통로, 잘라 붙인 상단 입구는 반려됐다. 112·113번을 적용 기준으로 쓰지 않는다. 현행 우물은 116·117번이다.

## 우물 마당 — 좌우 확장

- 원본 1774×887 → **2638×887**, 좌우 각각432px 추가. 원본 좌상단은 최종 이미지 **(432,0)**. 기존 랜드마크의 좌표는 **x+432, y 그대로**다.
- 추가한 날개 공간에 부엌·식사 출입구를 각각 배치했다. 대야·의자·벤치 뒤로 들어가는 동선이 아니다. 기둥 앞의 넓은 포석에서 새 문턱으로 접근한다.
- 상단 연못 입구는 기존 좌표 `[1180,0,1550,330]` 구조 영역을 전체 보정했다. 작은 사각 패치 안에 문틀만 붙이지 않고 보·기둥·계단을 함께 연결했다.
- 원본 가장자리 전환 영역과 상단 입구 밖은 원본 픽셀 그대로다. 대야·의자·벤치 보호 영역도 픽셀 동일. `regions.json`의 우물 마스크는 **원본 좌표**, 아래 통행 좌표는 **확장된 최종 이미지 좌표**다. 혼동하지 않는다.
- 0.9.20의 우물 22×11 맵에 더 넓은 이미지를 끼우면 캐릭터 대비 배경 크기가 작아진다. **33×11 제안**: 원래 x 비율1774/22≈80.636px/칸, 새 비율2638/33≈79.939px/칸, y는887/11≈80.636px/칸. 기존 픽셀 위치를 x+432 이동한 후 새 타일 비율로 재계산한다. 배경 표시 배율까지 정확히 유지할 필요가 있으면 런타임에서 함께 검토한다.
- 기존 모든 가구 충돌·우물 조사점·남쪽 출구·스폰도 x+432 기준으로 옮긴다. 원래 남쪽 연결 정보는 `exit-coordinates.json`의 `preservedSouthReference`에 있다. 단순히 좌우 출구만 고치면 충돌 전체가 어긋난다.
- **세 출입구 모두 위로 진입, 복귀 방향 down**. 연결 키 north/west/east와 목적지는 그대로지만 키가 진입 방향을 뜻하지 않는다. 화면 좌우 끝 트리거는 제거하고 새 문턱에 배치한다. 도착점과 이름표 방향도 같이 맞춘다.

## 연못 회랑 — 채택된 오른쪽 확장 유지

1448×1086 →1932×1086, 오른쪽484px. 원본은(0,0) 그대로이며 우물처럼 x+432 이동하지 않는다. 0.9.20에서 이미24×14로 적용됐다. 기존 픽셀 좌표로 타일 충돌을 재계산하고 원래 남쪽 출구를 새 캔버스 중앙으로 옮기지 않는다. east 연결은 새 아치로 위쪽 진입, 복귀down이다. 승인 해시는 `approval.json`에 있다.

## 적용 순서

1. 새 우물 확장안 적용 시 `tools/maps/residence.py`의 day/night를 별도 expanded-v2 파일로 바꾸고 크기·충돌·출구·도착점·조사점·스폰을 함께 변경한다. 연못과 다른 회랑은 0.9.20 적용 상태를 유지한다.
2. 회랑 끝 기둥 받침은 고체로 유지한다. 동쪽 회랑의 제거한 항아리 충돌만 없애고 기둥과 묶인 충돌은 분할한다. 방문 회랑 세 방문과 중앙 아래 계단은 유지한다.
3. `exit_signs`는 연결 키나 화면 끝만 보고 방향을 추정하지 말고 실제 입구 방향을 따른다. 우물 세 곳·연못 새 아치는 위쪽이다.
4. 생성기로 `data/maps/*.json`, `data/scene-art.json` 갱신. 31개 출구 왕복, 낮밤, 즉시 재전환 방지, 가구·기둥 통과 방지, 폰에서 문이 읽히는지 검증한다. 아스트라는 이 통과 테스트를 수행하지 않았다.

## 제작 및 검증

`node scripts/art/package-residence-exits.cjs` (sharp 필요). 국소 편집, 오른쪽 확장, 양쪽 확장+국소 편집 모드를 구분한다. 우물은 생성 레이어만 정렬하고 원본을(432,0)에 합성했다. 상단과 접합부는32px 안쪽 전환, 다른 원본 영역은 그대로 복사했다. `validation.json`, `latest-review-validation.json`에 크기·해시·보존 결과를 기록했다. 연못/동쪽 승인 해시와 승인 캐릭터 원본도 유지했다.
