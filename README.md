# 모래와 깃털 (Sand and Feather)

세트·호루스 RP 채팅 옆에서 돌아가는 이집트 오픈월드 게임 — SillyTavern 확장.

기획서: [SPEC.md](SPEC.md) · 시안: [docs/mockups](docs/mockups) · 다른 AI 상담용 소개서: [docs/CONSULT.md](docs/CONSULT.md)

## 지금 되는 것 — 1단계 엔진과 마을

- 마술봉 메뉴 → **모래와 깃털**, 또는 확장 탭 서랍 → **게임 열기**
- 옴보스 마을을 걸어 다니기: 방향키·WASD, 폰에선 왼쪽 아래 패드
- 장소나 사람 가까이 가면 말풍선이 뜨고, **말 걸기** 또는 E·스페이스로 카드가 열림
- 날짜 카드: 챗의 마지막 트래커에서 날짜·시간대·장소를 읽어 맞춤. 누르면 자세히
- 미니맵을 누르면 큰 지도
- 접기 버튼: 게임이 작은 칩으로 접혀서 채팅을 볼 수 있음. 칩을 누르면 다시 열림
- 프롬프트에 짧은 영어 한 줄: `[Egypt — Hathyr 8, Akhet, evening. Ombos, the west wing.]`
  트래커가 한 번도 없었던 채팅에는 넣지 않음
- 서랍: 손으로 맞추기, 주입 위치·깊이·역할, 미리보기, 트래커 정규식, 달 이름, 테마, 새 판

## 2단계 첫 고리

- 선착장 물가에서 **살펴보기 → 물에서 건지기**: 게임 속 하루에 한 번. 시간대와 계절에 따라 나오는 게 달라
- 건진 건 바로 가방에. **가방** 버튼에서 보고, 항아리나 편지는 **열어 보기**
- **이 일로 말 걸기** → 세트나 호루스를 고르면 게임이 접히고 입력칸에 첫 문장이 들어가. 프롬프트엔 영어 한 줄
- 세트·호루스 앞에서 말 걸기: 그냥 말 걸기, 또는 가방의 새 물건 들고 가기
- 재생성이나 스와이프엔 그 한 줄이 남아 있고, 다음 턴부터는 빠져. 서랍의 "챗에 넘길 일"에서 직접 뺄 수도 있어
- 날짜가 재생성으로 뒤로 갔다 다시 와도 같은 날이 두 번 처리되지 않아
- 고쳐도 되는 데이터: `data/items.json` 물건, `data/finds.json` 건질 거리, `data/talk.json` 첫 문장 모양. 틀리면 어디가 틀렸는지 알려 줘

트래커 예:
```
<tracker> 🌇 05:48 오후 | 하티르 여드렛날, 2년 | 옴보스 → 서쪽 별채 | ☀️ 맑음 </tracker>
```
