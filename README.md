세트·호루스 RP 채팅 옆에서 돌아가는 이집트 오픈월드 게임 — SillyTavern 확장.

## 지금 되는 것 · 0.4 첫 플레이 버전

마술봉 메뉴 → **모래와 깃털**, 또는 확장 탭 서랍 → **게임 열기**. 방향키·WASD, 폰에선 왼쪽 아래 패드. 가까이 가서 **말 걸기** 또는 E.

**하루:** 챗의 하루마다 태양 기운이 차. 기본 12, 서랍 "보기"에서 4부터 30까지 바꿀 수 있어. 걷기, 구경, 말 걸기, 꺼내기는 공짜고 활동만 기운을 써. 모든 활동이 모험 등급 경험치를 줘. 매일 의뢰 둘.

| 놀이 | 어디서 | 하는 것 |
|---|---|---|
| 생활 | 시장 | 재료, 씨앗, 자재 사고팔기 |
| | 선착장 | 타이밍 낚시, 하루 한 번 건지기 |
| | 텃밭 | 씨앗 심고 며칠 뒤 수확 |
| | 부엌 | 요리. 음식은 두아트 회복용이나 선물 |
| 육성 | 필사실 · 훈련장 · 제단 | 지혜 · 체력 · 신앙. 지혜로 기록 해독 |
| 원정 | 두아트 문, 저녁과 밤 | 세트나 호루스와 갈림길, 턴 전투, 사건, 유물. 죽지 않아 |
| 경영 | 신전 지도 탁자 | 수로, 밭, 배 정비. 며칠 뒤 지도가 바뀌어 |
| 탐험 | 마을 곳곳 | 밤에만, 계절에만, 동행과 함께일 때만 보이는 것 |
| | 강 건너 무너진 신전 | 배 수리와 모험 등급 3. 비문, 사당, 발굴터 |
| 작은 모험 | 마을 | 하루 하나. 첫 모험은 숨은 정원. 그다음은 AI가 쓰거나 무작위 조립 |
| RP 연결 | 가방, 임무 탭 일지 | 원할 때 지금 장면에 꺼내기 |

**배움 목표 · 0.5:** 소망 탭에서 비문 읽기, 짐 다루기, 봉인 다루기 중 하나를 골라 이어서 익혀. 익히면 모험 갈림길에 숨은 뜻 읽기, 안전하게 운반하기, 봉인 안정시키기가 생기고, 두아트에 엄호와 보호 주문이 붙어. 매일 의뢰는 넷 중 아무거나 둘.

**게임에 반영하기 · 0.5.1:** 이집트 채팅의 메시지마다 메뉴에 깃털 버튼이 있어. 누르고 문장 하나를 고르면 배움 목표, 모험 소재, 메모 중 하나로 받아. 받은 건 하기로 한 일일 뿐이라 보상은 없어. 그 답장이 재생성으로 사라지면 같이 사라지고, 스와이프로 돌아오면 다시 살아나. 모험 소재는 다음 AI 모험이 바탕으로 쓰고, 메모는 임무 탭에 적혀.

**하루 결산 · 0.5.3:** 챗의 날이 넘어가면 다음에 게임을 열 때 지난 하루의 결산이 떠. 도장, 한 일, 얻은 것, 데벤과 경험치, 일지에 적힌 일. 도장은 ☥ 무사, ✨ 특별한 날, 🩹 죽을 뻔. 날짜 카드의 "달력"에서 날마다 찍힌 도장을 보고, 누르면 그날 결산을 다시 봐.

**축제의 밤 · 0.5.4:** 오페트 축제, 코이악 축제, 웨페트 렌페트. 날짜는 대략이고 `data/festivals.json`에서 고칠 수 있어. 축제 7일 전부터 신전 앞 광장에 축제 기둥이 서. 잔치 음식, 장식, 신전 제물을 하나씩 내놓을 수 있고, 하나에 태양 기운 1. 축제 날 저녁이나 밤에 기둥에서 "축제에 가기"를 누르면, 준비한 만큼 밤이 달라져. 놓쳐도 실패는 없고 내년에 다시 와. 그 밤은 일지에 적혀서 챗에 꺼낼 수 있어.

**도감 · 0.5.5:** 소망 탭 아래 "도감". 물고기, 요리, 작물, 발견한 물건, 유물, 기록, 비밀이 갈래별로 채워져. 모르는 건 물음표고, 칸을 누르면 설명과 처음 얻은 날이 나와.

**오벨리스크 · 0.5.6:** 옴보스에 넷, 강 건너 신전에 하나. 가까이 가서 깨우면 지도 탭에서 깨운 곳으로 바로 갈 수 있어. 공짜야. 지도에는 깨운 건 금빛, 잠든 건 회색 세모로 보여.

**파티 탭:** 세트나 호루스가 뒤따라 걸어. **임무 탭:** 매일 의뢰, 모험 힌트, 일지와 꺼내기. **소망 탭:** 능력치와 모험 등급.

**AI 모험:** 서랍 "작은 모험"에서 쓰는 쪽을 골라: 커스텀 API, Vertex AI, 아카이브 초안 모델, 아카이브 AI 기능 모델, 끄기. 커스텀은 주소, 키, 형식, 모델이고 모델 불러오기와 연결 시험 버튼이 있어. Vertex는 서비스 계정 JSON, 위치, 모델. 새 모험 하나에 한 번 불러. 하루 모험 수는 기본 3이고, 하나 끝나면 다음 게 바로 이어져.

트래커 예:
```
<tracker> 🌇 05:48 오후 | 하티르 여드렛날, 2년 | 옴보스 → 서쪽 별채 | ☀️ 맑음 </tracker>
```

데이터는 `data/` 아래 JSON이라 손으로 고칠 수 있어. 틀리면 어느 파일 몇 번째인지 알려 줘.
