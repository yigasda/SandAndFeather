# 모래와 깃털 (Sand and Feather)

세트·호루스 RP 채팅 옆에서 돌아가는 이집트 오픈월드 게임 — SillyTavern 확장.

기획서: [SPEC.md](SPEC.md) · 시안: [docs/mockups](docs/mockups) · 다른 AI 상담용 소개서: [docs/CONSULT.md](docs/CONSULT.md) · 진행 상황: [docs/PROGRESS.md](docs/PROGRESS.md) · 인수인계: [최신 인수인계](docs/SESSION-HANDOFF.md)

**0.9.6 옴보스 안채:** 신전 지도 탁자에서 안채로 들어가 우물 마당, 부엌, 식사 공간, 연못 회랑, 복도, 세 방, 성소, 열주 계단, 지붕까지 15곳을 걸어 다닌다. 9곳은 밤이 되면 밤 그림으로 바뀌고, 계단 앞 `^`로 지붕에 오른다. [연결과 검증](docs/RESIDENCE-096.md).

**0.9.1 원본 픽셀 UI:** 시안과 다르다는 피드백을 반영해 CSS로 근사한 프레임·버튼·아이콘을 시안에서 직접 추출한 PNG로 교체했다. [원본 대조와 구현](docs/SOURCE-PIXEL-UI.md).

**0.8.14 초미니 등록:** 세트·소망·호루스와 상인에 초미니4방향 PNG를 적용했다. [실제 화면·검증·원본](docs/POCKET-SPRITES.md).

**0.8.13 전체 시안 적용:** 채택한 도보 2번 시안 전체를 원본 그대로 사용한다. 건물·길·절벽·물가를 함께 적용하고 이동·상호작용 위치를 맞췄다. [실제 게임 화면과 검증](docs/OMBOS-APPROVED.md).

**0.8.11 두아트 연결부:** 원본 모래·보도를 마을에 적용하고 부엌 옆 그림자와 절벽 위아래를 연결했다. [실제 낮·밤 화면과 검증](docs/DUAT-SEAMS.md).

## 지금 되는 것 · 0.4 첫 플레이 버전

마술봉 메뉴 → **모래와 깃털**, 또는 확장 탭 서랍 → **게임 열기**. 방향키·WASD, 폰에선 왼쪽 아래 패드. 가까이 가서 **말 걸기** 또는 E.

**하루:** 챗의 하루마다 태양 기운이 차. 기본 12, 서랍 "보기"에서 4부터 30까지 바꿀 수 있어. 걷기, 구경, 말 걸기, 꺼내기는 공짜고 활동만 기운을 써. 모든 활동이 모험 등급 경험치를 줘. 매일 의뢰 둘.

| 놀이 | 어디서 | 하는 것 |
|---|---|---|
| 생활 | 시장 | 재료, 씨앗, 자재 사고팔기 |
| | 선착장 | 타이밍 낚시, 하루 한 번 건지기 |
| | 텃밭 | 씨앗 심고 며칠 뒤 수확 |
| | 부엌 | 요리. 음식은 두아트 회복용이나 선물 |
| 육성 | 필사실 · 훈련장 · 제단 | 지혜 · 체력 · 신앙. 지혜로 기록 해독 |
| 원정 | 두아트 문, 저녁과 밤 | 세트나 호루스와 갈림길, 턴 전투, 사건, 유물. 죽지 않아 |
| 경영 | 신전 지도 탁자 | 수로, 밭, 배 정비. 며칠 뒤 지도가 바뀌어 |
| 탐험 | 마을 곳곳 | 밤에만, 계절에만, 동행과 함께일 때만 보이는 것 |
| | 강 건너 무너진 신전 | 배 수리와 모험 등급 3. 비문, 사당, 발굴터 |
| 작은 모험 | 마을 | 하루 하나. 첫 모험은 숨은 정원. 그다음은 AI가 쓰거나 무작위 조립 |
| RP 연결 | 가방, 임무 탭 일지 | 원할 때 지금 장면에 꺼내기 |

**배움 목표 · 0.5:** 소망 탭에서 비문 읽기, 짐 다루기, 봉인 다루기 중 하나를 골라 이어서 익혀. 익히면 모험 갈림길에 숨은 뜻 읽기, 안전하게 운반하기, 봉인 안정시키기가 생기고, 두아트에 엄호와 보호 주문이 붙어. 매일 의뢰는 넷 중 아무거나 둘.

**게임에 반영하기 · 0.5.1:** 이집트 채팅의 메시지마다 메뉴에 깃털 버튼이 있어. 누르고 문장 하나를 고르면 배움 목표, 모험 소재, 메모 중 하나로 받아. 받은 건 하기로 한 일일 뿐이라 보상은 없어. 그 답장이 재생성으로 사라지면 같이 사라지고, 스와이프로 돌아오면 다시 살아나. 모험 소재는 다음 AI 모험이 바탕으로 쓰고, 메모는 임무 탭에 적혀.

**하루 결산 · 0.5.3:** 챗의 날이 넘어가면 다음에 게임을 열 때 지난 하루의 결산이 떠. 도장, 한 일, 얻은 것, 데벤과 경험치, 일지에 적힌 일. 도장은 ☥ 무사, ✨ 특별한 날, 🩹 죽을 뻔. 날짜 카드의 "달력"에서 날마다 찍힌 도장을 보고, 누르면 그날 결산을 다시 봐.

**축제의 밤 · 0.5.4:** 오페트 축제, 코이악 축제, 웨페트 렌페트. 날짜는 대략이고 `data/festivals.json`에서 고칠 수 있어. 축제 7일 전부터 신전 앞 광장에 축제 기둥이 서. 잔치 음식, 장식, 신전 제물을 하나씩 내놓을 수 있고, 하나에 태양 기운 1. 축제 날 저녁이나 밤에 기둥에서 "축제에 가기"를 누르면, 준비한 만큼 밤이 달라져. 놓쳐도 실패는 없고 내년에 다시 와. 그 밤은 일지에 적혀서 챗에 꺼낼 수 있어.

**도감 · 0.5.5:** 소망 탭 아래 "도감". 물고기, 요리, 작물, 발견한 물건, 유물, 기록, 비밀이 갈래별로 채워져. 모르는 건 물음표고, 칸을 누르면 설명과 처음 얻은 날이 나와.

**오벨리스크 · 0.5.6:** 옴보스에 넷, 강 건너 신전에 하나. 가까이 가서 깨우면 지도 탭에서 깨운 곳으로 바로 갈 수 있어. 공짜야. 지도에는 깨운 건 금빛, 잠든 건 회색 세모로 보여.

**스프라이트 그림 · 0.5.7:** 소망, 세트, 호루스, 상인이 16×16 픽셀 그림으로 바뀌었어. 그림은 `data/sprites.json`에 글자 한 칸이 점 하나로 들어 있어서 직접 고칠 수 있어. 앞, 뒤, 옆 모습이 있고, 그림이 없는 건 예전처럼 코드로 그려. 지도 위 물건도 같은 모양으로 넣으면 바뀌어.

**메모리 · 0.5.8:** 게임을 접거나 닫으면 그림판을 비워서 폰 메모리를 돌려줘. 다시 열면 바로 그려.

**배경과 꾸밈 · 0.6.0:** 바닥을 무늬로 다시 그렸어. 모래알, 돌판 줄눈, 풀 무더기, 물결, 바위, 벽돌. 땅이 바뀌는 곳은 부드럽게 이어지고, 벽과 건물과 야자수에 그림자가 생겼어. 신전은 탑문에 새김 띠와 깃대, 날개 달린 해가 있는 문. 신전 앞마당엔 기둥, 세트와 매 석상, 제물상, 화로, 연못, 붉은 길, 화분, 걸개를 놓았고, 마을엔 항아리, 장바구니, 화덕, 우물, 물 긷는 장대, 짚 인형과 과녁, 꽃과 갈대, 강 위 작은 배가 생겼어. 화로는 불이 일렁이고 밤엔 주위가 밝아. 강 건너 신전엔 비석, 사당, 발굴 구덩이와 무너진 돌들. 꾸밈은 `data/maps`의 decor에서 고칠 수 있어.

**맵 정돈 · 0.7.0:** 포켓몬 맵처럼 정돈했어. 땅은 납작한 바탕에 작은 무늬를 일정하게, 길과 풀밭과 밭은 또렷한 가장자리와 둥근 모서리. 바위와 벽은 밝은 윗면과 진한 옆면으로 층이 지고, 강은 물가에서 멀수록 깊은 색. 건물, 야자수, 석상, 화분, 울타리에는 진한 테두리가 고르게 붙어. 맵 위쪽은 절벽 턱과 야자수 줄, 왼쪽도 야자수 줄. 신전 문 앞엔 계단, 시장 앞엔 돌 광장, 밭과 풀밭 위엔 생울타리, 강가 풀밭엔 줄 맞춘 꽃밭.

**쯔꾸르풍 맵 · 0.8.0:** 땅, 야자수, 작물, 덤불, 바위, 꽃, 갈대, 연잎, 집, 시장, 신전, 두아트 문을 3/4 시점 점 그림으로 다시 그렸어. 그림은 `data/tiles.json`에 글자 한 칸이 점 하나로 들어 있고, 풀과 강은 계절마다 색이 바뀌어. 풀밭은 모래 쪽으로 풀잎이 삐죽 나오고, 강가엔 하얀 물결선. 텃밭은 한 줄 걸러 한 줄만 심겨서 흙이 보여.

**옴보스 건물 · 0.8.2:** OMBOS 시안의 밝은 평지붕, 황토색 앞벽, 얇은 난간과 그늘로 집·필사실·부엌을 맞췄어. 신전은 양쪽 탑과 낮은 중앙 문, 시장은 크림·적갈색 차양과 세 상품 바구니로 정리했어. 야자수와 잔디 경계, 강가의 하얀 물결은 그대로야. [수정 전후와 검증](docs/OMBOS-BUILDINGS.md).

**공간과 깊이 · 0.8.3:** 신전 마당과 앞집 사이에 모래 여백을 만들고, 탑 윗면·처마 그늘·문틀·계단의 두께를 보강했어. 시장은 천막과 상품대 사이 공간을 넓혔어. 북쪽 야자수는 군집 사이를 비우고, 길과 마당 바닥 무늬는 부드럽게 낮췄어. [실제 모바일 수정 전후](docs/OMBOS-DEPTH.md).

**기둥과 입구 · 0.8.4:** 신전 기둥을 양쪽 두 개의 단순한 사암 기둥으로 정리했어. 두아트는 석재 입구와 옆자리 조각상으로 묶고, 시장 발판과 야자수 그림자를 다듬었어. [낮 모바일 화면과 전체 지도](docs/OMBOS-DETAILS.md).

**텃밭 · 0.8.5:** 왼쪽 위에 비어 있던 네 칸을 주변과 같은 밭으로 채웠어.

**두아트 절벽 통로 · 0.8.6:** 부엌 옆에서 이어지는 돌길과 오른쪽 지형에 붙은 암벽으로 두아트 입구를 정리했어. 문 가까운 바닥은 회갈색으로 낮추고 길목에 수호상과 봉인석을 놓았어. [낮·밤 화면과 검증](docs/DUAT-PASSAGE.md).

**사암 두아트 · 0.8.7:** 낮·밤 시안처럼 높낮이가 다른 밝은 바위로 문을 감싸고 듬성듬성한 디딤돌을 놓았어. 비석을 없애고 조각상 뒤 통로를 확보했어. [실제 낮·밤 화면과 검증](docs/DUAT-SANDSTONE.md).

**두아트 원본 시안 적용 · 0.8.10:** 새로 그린 그림 대신 낮·밤 원본 시안을 직접 사용하고 동쪽 지형 경계를 복구했어. [원본과 실제 게임 비교 및 픽셀 검사](docs/DUAT-ORIGINAL.md).

**두아트 절벽·입구 교체 · 0.8.9:** 시안 기반 PNG로 뒷절벽과 입구, 앉은 아누비스상을 교체하고 동쪽 공간과 디딤돌 길을 조정했어. [실제 게임 낮·밤 화면과 검증](docs/DUAT-REBUILD.md).

**두아트 시안 보정 · 0.8.8:** 기둥처럼 보이던 바위를 각기 다른 윤곽과 겹친 밑동으로 다시 그렸어. 입구 안쪽 계단과 문틀 깊이를 보강하고, 수호상을 앉은 아누비스와 사암 받침으로 바꿨어. [전후 화면과 검증](docs/DUAT-REFERENCE-CORRECTION.md).

**파티 탭:** 세트나 호루스가 뒤따라 걸어. **임무 탭:** 매일 의뢰, 모험 힌트, 일지와 꺼내기. **소망 탭:** 능력치와 모험 등급.

**AI 모험:** 서랍 "작은 모험"에서 쓰는 쪽을 골라: 커스텀 API, Vertex AI, 아카이브 초안 모델, 아카이브 AI 기능 모델, 끄기. 커스텀은 주소, 키, 형식, 모델이고 모델 불러오기와 연결 시험 버튼이 있어. Vertex는 서비스 계정 JSON, 위치, 모델. 새 모험 하나에 한 번 불러. 하루 모험 수는 기본 3이고, 하나 끝나면 다음 게 바로 이어져.

트래커 예:
```
<tracker> 🌇 05:48 오후 | 하티르 여드렛날, 2년 | 옴보스 → 서쪽 별채 | ☀️ 맑음 </tracker>
```

데이터는 `data/` 아래 JSON이라 손으로 고칠 수 있어. 틀리면 어느 파일 몇 번째인지 알려 줘.
