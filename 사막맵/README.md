# 사막맵 — 최신 채택 원본 모음

현재 확보한 최종 채택 PNG **29장**. 원본을 재압축·리사이즈하지 않고 그대로 복사했다. 게임 적용·배포와는 별개다.

- 06은 03에 통합되어 별도 파일이 없다.
- 13번은 3번 원본에서 다시 제작한 왼쪽 입구 확장 최종 채택본이다.
- 01은 닫힘·열림, 12는 첫째·둘째 회랑, 17 부속 주거실, 추가 보물방은 닫힘과 개별 상자 개방 5장을 포함한다.
- 전망맵은 최초 원본에서 다시 수정한 오른쪽 오벨리스크 최종본이다. 이전 위치·크기 시안은 제외했다.
- 보물방의 열린 전체 그림은 패치 제작용 원본이다. 전체맵끼리 교체하면 다른 상자의 상태가 초기화될 수 있으므로 그대로 런타임 교체하지 않는다.
- 10번의 별도 보존 후보3은 최종 채택맵이 아니므로 이 폴더에서 제외. 기존 docs/art에 보존돼 있다.
